🔬 推理时计算的"宽度革命"：AI 进入并行验证时代——从 OpenDeepThink 到 TFGN，看 LLM 如何兼顾推理深度与遗忘边界

📌 核心摘要：本周 arXiv 涌现了多篇极具突破性的 AI 论文。OpenDeepThink 提出基于 Bradley-Terry 聚合的群体并行推理框架，将 Gemini 3.1 Pro 的 Codeforces Elo 拉升 405 分。TFGN 以读/写分离架构首次在 LLM 规模实现无重放持续预训练，遗忘率低至 -0.007。SDAR 将自蒸馏与强化学习结合，在 Agent 任务上刷新 GRPO 基线。

一、研究背景与动机

1.1 推理时计算的"深"与"广"

自从 OpenAI o1 系列带火"推理时计算扩展"（test-time compute scaling）以来，业界主流思路集中在延长单次推理轨迹（深度扩展）。这类方法直观但面临显著瓶颈：计算成本线性增长，边际收益持续递减，且难以利用并行硬件加速。

而"宽度扩展"——让模型同时生成多个候选答案再择优——虽高度可并行，却长期受困于一个致命难题：没有真实验证器时，模型作为自我评判者充满偏差与噪声。

1.2 持续学习的"遗忘诅咒"

持续预训练的经典方案依赖重放缓冲区、任务标识符或 Fisher 正则化。但在数十亿参数的 LLM 规模上，这些方法要么存储开销过大，要么无法在 无任务边界（task-free） 的真实场景中工作。

1.3 Agent 训练的稀疏奖励困境

GRPO 等 RL 算法虽已成为 LLM 后训练主流，但其轨迹级别奖励信号过于粗糙——每次交互长达数百步，却只有最终成功/失败信号能提供训练梯度。

二、核心方法

2.1 OpenDeepThink：用群体智慧组织并行推理

OpenDeepThink 构建了一个基于种群的推理循环：

  1. 初始化种群：生成 N 个候选答案（实验中 48 个）
  2. 配对比较：LLM 对随机配对的候选答案从多个维度进行比较，输出判断+自然语言评语
  3. Bradley-Terry 聚合：将两两比较结果聚合为全局排名——这一统计框架最早用于竞技体育选手排名
  4. 演化迭代：保留排名靠前者，对前 75% 用评语引导变异，丢弃最低 25%
  5. 收敛判定：重复至稳定或预算上限

关键洞察在于将推理视为搜索过程而非生成过程。实验数据：仅 8 轮 LLM 调用（约 27 分钟），Gemini 3.1 Pro 的 Codeforces Elo 提升 405 分。分析还揭示：在客观可验证领域（编程、数学），群体验证效果显著；在主观领域（创意写作），群体投票可能稀释多样性。

2.2 TFGN：读/写分离的持续学习

TFGN 的架构智慧来自一个极简洞察："忘记"的本质是参数被后续更新覆盖。前向传播需要所有参数参与（全连接），但反向传播却会不加区分地修改所有参数。

解决方案是在架构层面将"读取"和"写入"解耦：

  • 前向传播（读取）：保持全密连接，保证模型表达力
  • 反向传播（写入）：结构化参数更新，新旧领域更新作用在正交子空间
  • 实验显示域间梯度正交性 ≥99.59%

在 LLaMA 3.1 8B 上跨 6 个异构领域后，HellaSwag 准确率稳定在 0.504-0.510。后向迁移低至 -0.007。一个意外收获：仅靠 Python 训练让 JS 困惑度下降 26.8%。

2.3 SDAR：用门控机制驯服 Agent 强化学习

SDAR 将即时策略自蒸馏（OPSD）视为门控辅助目标，而非替代 RL 主线。通过 sigmoid 门控：教师认可时放大蒸馏，教师拒绝时软性衰减。在 Qwen2.5 和 Qwen3 系列上，ALFWorld +9.4%、Search-QA +7.0%、WebShop +10.2%。

四、技术启示与发展方向

4.1 广度推理的商业价值

OpenDeepThink 证明在固定预算下，并行采样+群体验证可能比长链推理更高效，对延迟敏感场景（搜索、推荐）有直接的部署启示。

4.2 TFGN 打开了持续学习的想象空间

架构级读/写解耦可能是持续预训练的根本解法，有望催生"持续预训练即服务"（CPTaaS）生态。

4.3 Token 级精密信号重塑 RL

SDAR 中的 sigmoid 门控回答了 RL 的核心问题：当老师信号有噪声时，多大程度上信任它？这与人类学习中"选择性指导"的思想高度一致。

4.4 三条路线正在交汇

  • OpenDeepThink：推理阶段 → 群体比较替代个体判断
  • TFGN：训练阶段 → 架构解耦替代经验重放
  • SDAR：微调阶段 → 门控蒸馏替代纯 RL

共同指向：AI 研究正从"大力出奇迹"转向"精巧设计换效率"的黄金时代。

五、总结

本周 arXiv 精读呈现振奋人心的趋势：前沿焦点从"如何更贵"转向"如何更巧"。OpenDeepThink、TFGN、SDAR 三项工作没有依赖千卡集群或万亿参数——它们靠的是优雅的架构设计和深刻的理论洞察。

对于 AI 从业者而言，这些工作的真正启示或许不在于具体的算法细节，而在于一个更底层的判断：这波大模型技术的成长空间远未被耗尽——不是通过堆参数，而是通过"想得更多、忘得更少、训练更巧"。在推理计算预算日益成为瓶颈的当下，那种能够在给定算力约束下最大化模型潜力的策略，将比单纯追求更大更强的基座模型具有更高的工程回报。

最佳实践建议：推理质量受限 → 尝试并行推理；持续学习后性能回退 → 关注 TFGN；Agent 训练不及预期 → 参考门控蒸馏；推理成本过高 → 试试 DDC 的 10 倍压缩。
