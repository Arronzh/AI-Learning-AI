🧠 三篇 ICML 2026 论文速览
稀疏注意力 · 潜空间推理 · 扩散检索

📌 核心摘要
本周 arXiv 涌现三篇来自 ICML 2026 的佳作。微软亚研院提出的 Cross-Layer Sparse Attention (CLSA) 通过跨层共享路由索引，将稀疏注意力的路由开销摊薄到极致，在 128K 上下文下实现 17.1 倍吞吐提升。宾大和 UC San Diego 联合提出的 NF-CoT 将归一化流引入 LLM 潜空间推理，在代码生成任务上超越显式 CoT 的同时大幅降低推理成本。而来自德国的 SARDI 则发现了扩散语言模型在检索增强生成中的独特优势——"丢弃"的低置信 token 反而为多跳检索提供了关键路径信号。

一、研究背景与动机

1.1 长上下文推理的效率困局

2026 年的 LLM 生态中，长上下文推理已从"卖点"变成"标配"。但随着 Chain-of-Thought 推理链越来越长（动辄数千甚至上万 token），模型在解码阶段需要反复访问庞大的 KV 缓存，预填充、缓存存储、解码延迟三大瓶颈同时爆发。

稀疏注意力被寄予厚望——与其让每个 token 都关注所有历史 token，不如只关注一个"精挑细选"的子集。然而现有方案陷入了典型的效率‑质量两难：

结构化块稀疏：加速效果好，但粗粒度的裁剪导致质量明显下降；
Token 级稀疏：精度更高，但每层独立计算 top-k 路由的开销在 GPU 上高度不规则，端到端加速有限。

1.2 推理的"语言学困境"

Chain-of-Thought 有效，是因为它在 prompt 与答案之间引入了中间推理变量。但问题在于，这些变量被强制表示为离散的文本 token——每一步推理都必须"说出口"才能继续，好比一位数学家每次推导都必须朗读出声。

潜空间推理试图突破这一限制：在连续向量空间中完成推理后，再将最终结果转译成文本。但现有方案（如 Coconut、LaDiR）或丢失了原生自回归采样能力，或需要迭代去噪无法使用 KV 缓存，始终未能完美替代显式 CoT。

1.3 扩散模型遇上检索增强

扩散语言模型通过迭代去噪一次性生成完整响应，天然支持并行解码。然而，并行解码在实践中面临一个棘手问题：同时采样多个 token 容易产生矛盾、错乱的片段。如何驯服这种"并发"生成的不确定性？

二、核心方法

2.1 CLSA：一次索引，处处复用

CLSA 基于 YOCO（You Only Cache Once）架构搭建。YOCO 的核心思想是将传统 Transformer 的层分为两种角色——自解码层与交叉解码层——其中交叉解码层共享同一份 KV 缓存。

CLSA 在此基础上提出了一个优雅的洞察：既然交叉解码层读的是同一份缓存，为什么路由索引不能也共享？

具体实现：

1. 一个轻量级的 indexer 模块对完整 KV 缓存执行一次 token 级 top-k 选择；
2. 选出的路由索引被所有交叉解码层复用；
3. 各层只需对被选中的"活性 token"子集计算注意力。

这意味着：CLSA 同时保留了 token 稀疏的细粒度选择性，又通过一次性路由摊薄了计算开销。预填充、KV 缓存和解码三大瓶颈在一个统一架构中得到了联合优化。

💡 一句话直觉：一个信息量足够大的 token，对上层和下层的注意力决策同样重要——何必每层都替它重新考试？

2.2 NF-CoT：用归一化流给潜思想"上户口"

NF-CoT 的核心设计是在 LLM 的因果流中嵌入一个 TARFlow 风格的归一化流，使其与原生语言模型头并列工作：

文本位置 → 标准 LM head 输出离散 token；
潜思想位置 → NF head 输出连续向量，由归一化流定义可计算的精确对数似然。

这个设计带来的四个关键优势：

1. 原生左到右采样：保持自回归生成范式，与 KV 缓存兼容；
2. 概率评分：潜思想具有可计算的精确似然，而非黑盒隐向量；
3. 策略梯度优化：在连续推理空间上可直接应用 RL 训练；
4. 紧凑高效：将冗长的显式 CoT 蒸馏为紧凑的连续表示。

2.3 SARDI：让"被丢弃的 token"发光发热

扩散模型在每一步去噪中，会为每个掩码位置预测 token，然后只保留高置信度的预测，丢弃其他。传统观点认为这些被丢弃的预测是"垃圾"。

SARDI 反其道而行之：即使低置信度的 token，也常常在去噪早期就浮现出关键实体。

以多跳 QA 为例："展示《蒙娜丽莎》的博物馆所在的城市是哪里？"——第一跳需要识别出"卢浮宫"这个桥梁实体，而静态检索器在不知道桥梁实体的前提下无法检索第二跳信息。SARDI 利用扩散路径中的中间状态提前捕获"卢浮宫"信号，在答案被最终确认之前就完成了第二次检索。

SARDI 框架是训练无关、检索器无关的，可即插即用于任何具备推理能力的离散扩散语言模型。

三、实验结果

CLSA：17 倍加速且几乎无损

基准指标CLSA vs Dense
128K 上下文解码吞吐tokens/s+7.6×
128K 整体吞吐tokens/s+17.1×
短上下文（MMLU、GSM8K）准确率持平
长上下文（RULER、Needle）准确率<1% 损失

关键结果：路由索引跨层共享不仅节约了计算，而且几乎不改变最终的注意力分布——这从实验上验证了 CLSA 的核心假设。

NF-CoT 与 SARDI

NF-CoT：在 MBPP、HumanEval、LiveCodeBench v6 等代码生成基准上全面超越显式 CoT 和此前所有潜推理方案，推理成本（中间 token 数）大幅降低。

SARDI：在 MuSiQue、2WikiMultihop、HotpotQA 等数据集上超越所有免训练扩散检索基线和 AR 检索基线，吞吐提升高达 8×。

四、技术启示与发展方向

4.1 架构创新的"垂直整合"趋势

CLSA 的贡献不仅在于某一点上的优化，而在于将 KV 共享、稀疏路由、跨层复用三个维度统一到一个架构中。这种垂直整合的思路可能代表了下阶段 LLM 架构演进的方向——当上下文窗口走向百万 token，这种联合优化的设计哲学可能成为标配。

4.2 潜推理：从"要不要"到"怎么要"

NF-CoT 的工作标志着潜空间推理正从概念验证走向实用化。它证明了：连续推理可以同时拥有效率、兼容性和可训练性。后续方向包括扩展到更通用的推理任务、与多模态潜空间融合等。

4.3 扩散模型的"非对称优势"

SARDI 揭示了一个反直觉的事实：扩散模型中的"错误"预测——那些被丢弃的低置信 token——恰恰是其相对于自回归模型的结构性优势。这提示我们：非自回归范式的潜在价值远未被充分挖掘。

4.4 三个方向的可组合性

有趣的是，这三篇论文的技术路线是正交且可组合的：CLSA 优化推理效率，NF-CoT 让推理更紧凑，SARDI 为扩散模型带来 RAG 新范式。三者结合的空间值得期待。

五、总结

本周的 arXiv 贡献了三篇风格迥异但同样精彩的工作：

🔹 CLSA（微软 + 清华）：用"一次索引，处处复用"的优雅设计，将长上下文 LLM 推理效率推向新高度——17.1 倍吞吐提升是当前稀疏注意力领域的 SOTA。

🔹 NF-CoT（宾大 + UCSD + Meta）：为潜空间推理正名——归一化流赋予了连续思想与离散 token 同等的"公民身份"，在代码生成上同时赢得质量和效率。

🔹 SARDI（德国团队）：视角清奇——扩散模型中的"垃圾"预测是多跳检索的金矿，8 倍吞吐超越同类方案。

三篇论文均已被 ICML 2026 接收，代表了当前 LLM 效率优化的三个完全不同的切入点。
