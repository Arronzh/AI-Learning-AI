RASFT：用"策略感知"的监督微调，激活大模型的推理潜能

📌 核心摘要
传统 SFT 在推理任务中本质上是一种"轨迹模仿"——模型被强制跟随单条专家解题路径，反而可能抑制其自身推理分布。来自港中大（深圳）和上海 AI Lab 的研究团队提出 RASFT（Rollout-Adaptive Supervised Fine-Tuning），通过引入策略回滚（rollout）机制，让模型在训练中动态评估自身对每道题的解决能力，进而自适应地调节专家监督的强度。在数学推理和代码生成共 8 个基准测试上，RASFT 全面超越 SFT、DFT、ProFiT 等基线，甚至在部分任务上优于 GRPO 等在线强化学习方法。

一、研究背景与动机

1.1 SFT 的"盲点"：推理不是简单的路径模仿

监督微调（SFT）是目前将大语言模型适配到推理任务最主流的方法。其基本范式是：给定一组专家标注的解题过程，让模型通过最大化似然来学习"模仿"这些轨迹。OpenAI 的 InstructGPT 开创了这一范式，此后几乎所有主流推理模型的训练都沿用了这一思路。

但这里有一个根本性的矛盾：一道数学题可以有多种正确的解法，而一份离线数据只提供了其中一条路径。当模型被迫严格遵循单条专家轨迹时，会发生两件令人担忧的事情：

  • 过拟合表面形式：模型记住了专家答案的措辞模式而非底层推理逻辑。在测试时遇到措辞变化但本质相同的问题，模型可能无法泛化。
  • 抑制自身分布：预训练阶段赋予模型的潜在推理能力被"覆盖"而非被"激活"。这就像让一个本来会走路的孩子，硬要按特定步态走路——反而走得别扭了。

已有研究证明，预训练模型本身就蕴含着丰富的推理潜力。如果后训练阶段过于刻板地模仿单一路径，反而会限制这些潜力的释放。

1.2 现有改进方法的局限

近期的研究试图弥补这一缺陷。2026 年涌现出一批 SFT 变体：

  • DFT (Dynamic Fine-Tuning)：根据模型对各 token 的置信度动态缩放学习信号，让模型在"不太确定"的位置多学一些
  • ASFT (Adaptive SFT)：引入参考模型的 KL 散度约束来稳定训练，防止分布漂移
  • ProFiT (Probability-Guided Fine-Tuning)：通过概率门控屏蔽低置信度 token，减少对无关紧要表面表达的过拟合

这些方法在 token 级别或目标函数层面做了有价值的调整，但它们的自适应仍然局限于离线演示内部，而非根据当前策略的实际能力进行校准。用大白话说：不管模型对这道题"会不会"，专家路径的监督权重都一样。

这正是 RASFT 想要解决的关键问题——让监督信号"看人下菜碟"。

二、核心方法

2.1 整体思路：让模型"自我评估"

RASFT 的核心洞察非常直观：对于一道题，如果模型自己已经能正确解答，就不需要再强制模仿专家路径；如果模型还不会，则需要专家提供更强的引导。

⚙️ 实现这一思路需要解决两个核心问题：
1. 如何评估——怎么知道模型对一道题当前"会不会"？
2. 如何调节——根据评估结果，怎么（以数学上合理的方式）调整监督信号？

RASFT 的做法可以概括为三步：回滚 → 评估 → 加权。

2.2 策略回滚与可解性评估

对于训练集中的每个问题，RASFT 让当前模型自己生成 K 条推理轨迹（即"回滚"），然后通过任务验证器（如答案匹配）判断每条轨迹是否正确，据此计算问题级可解性分数：

ζᵢ = (1/K) · Σᵏ₌₁ᴷ cᵢₖ

其中 cᵢₖ ∈ {0,1} 表示第 k 条回滚是否正确。ζᵢ 越接近 1，说明模型对该问题已经具备较好的解决能力；越接近 0，则说明模型仍在挣扎。

⚡ 效率优化：RASFT 并不对每个训练样本都做回滚。它维护一个基于当前 expert loss 的滑动窗口，只对窗口内的实例进行回滚采样。理由也很直觉——过于简单的题目"探索价值"有限，过难的题目则很难产生正确回滚，都不值得投入计算资源。

2.3 自适应加权策略

对于需要进行回滚的样本，RASFT 构建一个局部候选池 𝒢ᵢ：

𝒢ᵢ = { 专家轨迹 } ∪ { 模型自生成的成功回滚轨迹 }

然后根据可解性分数动态分配权重：

  • 专家轨迹的权重：W(yᵢᵉ) = Wₑᵐⁱⁿ + (1−ζᵢ) · (Wₑᵐᵃˣ − Wₑᵐⁱⁿ)
    → 模型不会的题（ζᵢ低），专家权重就高；模型会了的题（ζᵢ高），专家权重自动降低
  • 自生成轨迹的权重：固定值 Wᵣ

2.4 逆重要性采样比：防止策略漂移

光有自适应加权还不够——模型可能在一味学习专家轨迹的过程中，逐渐偏离了预训练阶段积累的推理先验知识。为此，RASFT 引入了一个序列级的逆重要性采样比：

rᵢⱼ(θ) = (π_ref(yᵢⱼ | xᵢ) / π_θ(yᵢⱼ | xᵢ))^(1 / |yᵢⱼ|)

这个比率的意义很直观：

  • 如果当前策略 π_θ 对候选轨迹的概率远高于参考模型 π_ref，说明模型已经过度拟合了该轨迹，此时比率 < 1，会"踩刹车"减弱梯度
  • 如果两者接近，比率 ≈ 1，正常更新
  • 经过长度归一化，保证了短轨迹和长轨迹之间的公平比较

2.5 最终目标函数

综合以上设计，RASFT 的最终优化目标为：

ℒ(θ) = −𝔼ᵢ [ Σⱼ Σₜ ωᵢⱼₜ · log π_θ(yᵢⱼₜ | xᵢ, yᵢⱼ₍ₜ₎) ]

其中复合权重 ωᵢⱼₜ 整合了三个信号：轨迹级自适应权重、逆采样比约束、以及 token 级置信度。这个目标函数仍然属于监督微调框架，但监督信号已经不再是均匀的模仿压力，而是策略自适应的、由模型自身能力调节的精细化引导。

三、实验结果

3.1 全面超越 SFT 变体

在数学推理（MATH-500、Minerva Math、OlympiadBench、AIME2024、AIME2025、AMC2023）和代码推理（HumanEval、MBPP）共 8 个基准上，RASFT 在所有测试模型上取得了最佳平均成绩：

值得注意的是，RASFT 在小模型上的收益尤其显著——Qwen2.5-Math-1.5B 在 OlympiadBench 上从 24.11 提升到 27.10，AIME2024 从 4.79 提升到 7.92。Llama-3.2-3B 在代码生成上的 +26.9% 更是直接证明了"小模型更需要精细化训练策略"的直觉。

3.2 消融实验的启示

为了理解每个组件的贡献，作者进行了详尽的消融实验：

① 去掉自适应权重：对所有问题统一分配专家和回滚轨迹的权重，而不考虑难度估计。结果平均分从 27.72 降至 25.53，六个子基准全部下降。OlympiadBench 下跌 3.49 个百分点、AIME2024 下跌 2.70 个百分点——说明"一刀切"的权重分配对于竞赛级难题尤其有害。

② 去掉在线回滚：不使用在线回滚，仅使用静态权重分配专家轨迹。平均分降至 25.05，下降更为明显。这证明回滚并非可选项，而是 RASFT 的核心——没有在线反馈，就回到传统的"盲目模仿"模式。

③ 去掉逆采样比：去掉序列级逆重要性采样比约束后，平均分从 27.72 降至 27.30。虽然降幅不如前两者大，但在 MATH (+2.15%) 和 Minerva Math (+1.06%) 上的贡献仍然扎实。

3.3 与强化学习方法的对比

更引人注目的是 RASFT 与 GRPO（当前最主流的在线 RL 方法之一、DeepSeek-R1 训练的核心方法）的对比：

  • RASFT 平均准确率 23.47% vs GRPO 20.25%——高出 15.9%
  • 在超难基准 AIME2025 上，GRPO 几乎"崩盘"（准确率接近 0），而 RASFT 保持在了 4.17%
  • 在 Minerva Math 上，GRPO 通过无约束探索偶尔找到更好的路径（33.03 vs RASFT 的 30.88），但整体方差大、不稳定

原因在于：纯在线 RL 方法在极端难题上会因为探索冷启动而陷入优化停滞，而 RASFT 通过保留专家引导的"安全网"避免了这一陷阱。这不是单纯的 RL vs SFT 之争，而是证明了"专家引导 + 策略自适应"的组合优势。

3.4 训练动态分析

RASFT 的参数更新密度（被显著修改的参数比例）在各方法中最低（0.248），而 SFT 为 0.255、DFT 为 0.257、ASFT 为 0.254。这说明 RASFT 更精准地保留了预训练推理先验——它不像传统方法那样对所有参数一视同仁地更新，而是只做必要的最小改动。

四、技术启示与发展方向

4.1 "策略感知"范式：SFT 的下一个进化方向

RASFT 的最大启示在于：后训练阶段的监督信号不应是"一刀切"的。 SFT 的发展经历了三个阶段：

  • 第一阶段（2022-2024）：以标准 SFT 为代表——大家相信"更多数据 + 更多 ime"就能解决问题
  • 第二阶段（2025-2026）：以 DFT/ASFT/ProFiT 为代表——在 token 级别做精细化调节
  • 第三阶段（RASFT 开创）：策略-数据协同驱动——利用模型自身的实时行为来校准外部监督信号

这种范式转变的影响可能超出后训练本身，甚至影响到数据筛选、课程学习等更广泛的训练流程设计。

4.2 与小模型对齐：边缘部署的加速器

该研究对边缘部署场景有直接意义：在小模型（<3B）上，RASFT 的提升最为显著。这与"小模型更需要精细化训练策略"的直觉一致——参数有限的小模型对训练信号的质量更为敏感，粗放的 SFT 更容易伤害其脆弱的推理能力。对于想要在手机、IoT 设备上部署推理模型的团队来说，RASFT 是一个值得考虑的训练策略。

4.3 局限与开放问题

  • 回滚计算开销：尽管有滑动窗口优化，但回滚特别是对于较长推理链的采样，仍带来 2-3 倍的训练时间增加
  • 验证器依赖：RASFT 依赖可靠的验证器来判定回滚正确性。对于数学和代码这类有"标准答案"的任务没问题，但对于创意写作、对话等开放任务缺乏清晰的正确性标准
  • 规模化收益递减：随模型规模增大，RASFT 的收益递减（7B 模型上的增益显著小于 1.5B）。这可能是因为大模型预训练已经包含了更强的推理先验，对后训练策略的敏感度较低

4.4 未来方向

可以预期，RASFT 的思路将向以下方向延伸：

  • RL + RASFT 融合：将可解性分数引入 reward 设计，或者用 RASFT 做 RL 的 warm-start
  • 跨领域迁移：能否用一道数学题的可解性分数来预测模型在同一推理领域的其他任务上的表现？
  • 多模态推理：在视觉-语言推理任务上，回滚评估和自适应加权的方案同样适用
  • 在线持续学习：在部署阶段持续采集回滚数据，实现推理能力的在线进化

五、总结

RASFT 提出了一种简洁但强大的思路：不要让你的模型盲目模仿专家——而是让专家在模型需要时才出手。

通过在线回滚评估、难度自适应加权和逆重要性采样约束三管齐下，RASFT 在多个推理基准上刷新了 SFT 变体的最佳成绩，甚至不输于 GRPO 这样的在线 RL 方法。对于正在做模型后训练的研究者和工程师来说，RASFT 提供了一个即插即用的改进方案——只需在现有 SFT 流程上增加回滚采样和加权逻辑，即可获得显著的性能提升。

代码已开源，推荐在 Qwen2.5、Llama-3.2 等主流小模型上验证效果。
