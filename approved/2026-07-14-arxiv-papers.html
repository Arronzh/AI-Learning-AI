时间就是信息：自我生成训练数据如何突破模型压缩的理论极限

每日 AI 论文精读 · 2026 年 7 月 14 日
  • Requential Coding（重点）：新型模型压缩范式，将万亿参数模型描述长度从数据量级压缩至信息量级，首次为千亿 LLM 提供非平凡泛化界
  • FactorDiff：离散扩散模型因子级组合框架，在 ARC-AGI 推理基准上超越全局标量权重方案
  • LLM 元认知综述 + 趣味发现：系统梳理 LLM 元认知能力 + 邮件语气实验
    • 📌 核心摘要

    模型压缩不仅是部署优化的技术手段，更是理解智能本质的理论透镜。来自 NYU 的 Shikai Qiu 等人提出的 Requential Coding 彻底颠覆了模型压缩的基本范式：不是压缩参数，也不是压缩训练数据，而是让学生模型从自己的分布中生成候选样本，仅记录教师模型"选中"了哪一个。这种看似简单的视角转换产生了一个惊人的结果——编码长度与参数量和数据熵无关，在千亿参数 LLM 上首次给出了有意义的泛化保证。与此同时，多伦多大学团队提出的 FactorDiff 为离散扩散模型的专家组合开辟了新路径，通过像素级路由让不同专家在各自擅长的空间区域发光。

    一、研究背景与动机

    1.1 压缩即泛化：一个古老而深刻的洞察

    压缩与泛化的内在联系可以追溯到奥卡姆剃刀原则——最简单的解释往往是最有可能的。在机器学习中，如果一个模型能够将其训练数据压缩成很短的编码，说明它发现了数据中真正的规律性，而这种规律性恰恰是泛化的基础。

    然而，现有的模型压缩方法在大规模场景下遭遇了根本性瓶颈：

    参数级方法（量化/剪枝）：代码长度随模型大小线性增长，完全不关心参数实际存储了多少信息。一个函数远比参数量简单的模型和一个真正"学会"了复杂模式的模型，编码长度几乎一样。

    前序编码（Prequential Coding）：通过压缩训练轨迹来绕过参数量问题，但它必须无损编码精确的数据序列。即使模型已经学会了所有能学的信息，面对高熵数据（如图像噪声）时编码长度依然随数据量线性增长。

    这两种方法都编码了与"学到多少信息"无关的内容——前者编码参数冗余，后者编码数据冗余。

    1.2 现有方法的理论困境

    更严重的是，这些压缩方法的理论估计与大规模模型的实际行为直接冲突：

    • 经验事实：扩大模型和数据规模会提升泛化性能
    • 无限极限理论：大规模网络会收敛到确定性的极限行为
    • 但量化压缩给出的界随着模型增大而变松
    • 前序编码给出的界随着数据增多而变松

    这让泛化理论陷入了一个尴尬的局面：我们用来解释模型能泛化的工具，在规模变大时反而预测泛化会变差。

    1.3 离散扩散模型的组合生成挑战

    在扩散模型领域，另一类问题吸引了研究者。多专家组合生成（即把多个预训练模型的能力拼在一起解决新问题）虽然潜力巨大，但现有方法在组合时给每个专家分配一个单一的全局标量权重。这在结构化推理任务中造成了根本性错配——一个擅长形状的专家对颜色区域的预测同样是"自信的错误"，但全局权重无法区分哪个专家在哪个位置值得信任。

    二、核心方法

    2.1 Requential Coding：把"教什么"编码，而不是"教的内容"

    Requential Coding 的核心洞察可以概括为：我们不需要编码模型从数据中学到了什么，只需要编码数据和模型知识之间的差异。

    其运作机制精巧而优雅，借鉴了相对熵编码（REC）的核心思想：

    1. 学生-教师双模型架构
    学生模型（Student）是被压缩的对象，一个可生成样本的生成模型。教师模型（Teacher）是辅助方，通常通过对真实数据进行标准训练获得。两者共享相同的架构和初始化。

    2. 自生成训练样本
    在每个训练步，学生从自己的分布中生成一组候选样本（使用伪随机数生成器，种子双方共享）。教师从这些候选中"选中"一个样本。学生在该样本上训练一步。

    3. 极其高效的编码
    双方共享伪随机种子，所以候选样本序列是确定性的。编码器只需传送"第几个候选被选中"——即一个整数索引。由于教师倾向于选中学生本来就可能生成的样本，这个索引的编码空间非常小，约等于 KL(教师∥学生) 比特。

    4. 关键创新：教师平滑与等损投影

    • 教师平滑（Teacher Smoothing）：使用教师检查点的指数移动平均（EMA）来生成合成数据，减少教师轨迹中的噪声
    • 等损投影（Iso-loss Projection）：周期性地将教师重置为当前学生，短暂训练至恢复原始损失，从而在保持性能的同时降低教师与学生的 KL 散度
    💡 一个直观的理解

    想象你在教一个学生。传统方法（前序编码）要求你把所有教科书（训练数据）原封不动地复印一份给他。参数方法要求你把学生大脑的所有突触连接精度描述出来。

    而 Requential Coding 的做法是：让学生自己先试着回答，你只记录"哪里答错了"。当学生已经能答对 95% 的问题时，你只需要花极少的比特来描述那 5% 的修正。

    2.2 FactorDiff：像素级的专家路由

    FactorDiff 的核心理念同样基于一种分解思维：把样本空间分解为独立的因子，在每个因子上路由到最适合的专家。

    具体来说，利用掩码扩散模型的变量级条件分解，引入路由变量 z_v ∈ {1,...,M}，将每个变量分配给最合适的专家。置信度路由选择每个位置上 top-2 概率间距最大的专家。这种设计让组合超越了"全选A或全选B"的二选一困境，实现了真正的空间级专家协作。

    三、实验结果

    3.1 Requential Coding：压倒性的压缩优势

    在 OpenWebText（文本）、CIFAR-5M（图像）、FineWeb（大规模文本）三个基准上，100M 参数 Transformer 训练 2B token 的实验结果：

    指标 前序编码 Requential Coding
    每 token 编码成本 ≈ 3.5-5 bits（交叉熵损失） ≈ 0.02-0.08 bits（KL 散度）
    编码长度 vs 参数规模 超出 FP32 参数大小，无效压缩 远低于 4-bit 量化参考线
    相对效率 — 高 1-2 个数量级

    Requential Coding 在损失 vs. 压缩大小的帕累托前沿上具有支配性优势。即使 4-bit 量化（当前实际部署中的黄金标准）也被明显超越——因为后者付出了 4 比特/参数而不考虑参数实际蕴含了多少信息。

    3.2 最先进的泛化保证

    将 Requential Coding 嵌入 PAC-Bayes 框架后，在计算最优（Chinchilla 最优）的千亿参数 LLM 上，首次给出了非平凡的泛化界：

    • 泛化差距随模型规模呈幂律衰减（模型越大→越可压缩→界越紧）
    • 超越了基于 4-bit 后训练量化的最优理论界（即使假设量化误差为零的情况）
    • 随着模型和数据规模的同步增长，界持续变紧——与经验观察完全一致

    3.3 更多有趣的发现

    Requential Coding 还揭示了其他方法无法触及的现象：

    • 大模型更可压缩：在固定损失下，更大的模型尽管参数更多，但编码长度反而更短
    • 集成更可压缩：模型集成比单个模型更可压缩，因为它们的知识共享了更多冗余
    • 多 epoch 过拟合的量化预测：编码长度精确预测了多 epoch 训练下的性能下降
    • "可学习信息"的隔离：低熵文本蕴含远比高熵图像数据更多的可学习结构

    3.4 FactorDiff 在 ARC-AGI 上的表现

    方法 全局路由 组合类型 推理质量
    SuperDiff ✅ 加权混合 基线
    RNE ✅ 加权乘积 略优
    Feynman-Kac Correctors ✅ 加权乘积 + 粒子滤波 接近因子路由
    FactorDiff ❌（像素级） 置信度路由 持续最优

    实验表明，在需要局部逻辑一致性和空间解缠的任务中，即使是简单的置信度路由也显著优于复杂的全局标量加权方案。

    四、技术启示与发展方向

    4.1 压缩理论的范式转换

    Requential Coding 的意义远超"又一种压缩方法"。它实际上提供了一个新的理论透镜：

    • 信息流重新定义：压缩不再是参数的函数，也不仅仅是数据的函数，而是"学到了什么"的函数
    • 计算最优性与可压缩性的统一：Chinchilla 最优模型恰好是最可压缩的——这个发现暗示信息论可能是理解最优规模法则的统一框架
    • 数据选择的新维度：通过测量数据中的"可学习信息"，可以为课程学习和对齐提供理论指导

    4.2 实际部署的潜在影响

    虽然 Requential Coding 目前主要用于理论分析，但其思路可能催生新的实际技术：

    • 更高效的蒸馏流程：既然压缩等价于蒸馏，最优蒸馏策略可能是尽可能压缩学生和教师的 KL
    • 模型评估的新指标：可压缩性本身可以作为模型保留了多少"有用知识"的代理
    • 训练策略的优化：等损投影等技巧可能直接用于改进实际训练

    4.3 尚未解决的问题

    • Requential Coding 的实际编码/解码时间在理论上可能达到 2^KL 次采样，虽然块划分可以缓解，但距离实用仍有距离
    • FactorDiff 目前依赖先验已知的空间分解，如何自动发现因子结构仍是开放问题

    五、总结

    今天的论文精读聚焦于一个核心主题：从信息的视角重新理解 AI。

    Requential Coding 用优雅的数学证明了一个直觉上正确但长期未被严格证实的猜想：模型的真正复杂度不取决于它有多大、训练数据有多少，而取决于它从数据中提取了多少结构信息。这一发现不仅提供了最优的泛化界，更重要的是为"规模扩展为何有效"这一基础问题提供了信息论的统一解释。

    FactorDiff 则从另一个角度展示了"分解"的力量——当全局表达不够时，细粒度的局部路由可以释放模型的组合潜力。

    两者都指向同一个方向：AI 系统正在从"更大的黑箱"走向"更清晰的结构化信息处理"。在这个意义上，压缩不仅是工程优化，更是理解智能本质的钥匙。
