TRACE：让长程AI智能体学会"记功"
——来自微软研究院的密集信用分配新方法

📌 核心摘要

多轮交互的AI智能体在执行复杂任务时，往往需要调用数十次工具（搜索、打开网页、查代码等），但传统强化学习只在最终答案正确时才给奖励，无法区分哪些中间步骤真正有价值。微软研究院与威斯康星大学麦迪逊分校提出了 TRACE（Turn-level Reward Assignment via Credit Estimation），一种无需训练额外评论家模型或过程标签的密集信用分配方法。通过在工具调用边界上使用时序差分（TD）学习，TRACE 让 Qwen3-4B 在 BrowseComp-Plus 基准上从 7.2% 飙升至 35.6%，Qwen3-30B-A3B 从 8.4% 提升至 42.6%，且学习曲线收敛更快、起步更早。

一、研究背景与动机

1.1 智能体强化学习的核心困境

当前，基于大语言模型的 AI 智能体（Agent）正在完成越来越多复杂的多轮交互任务：网页导航、软件工程、通用计算机操作。这些任务的核心范式是 ReAct（推理+行动）—— 智能体在给出最终答案之前，需要反复调用搜索、打开、查找等工具，与环境进行数十轮乃至上百轮交互。

然而，信用分配（Credit Assignment）问题始终困扰着智能体的训练。

1.2 为什么传统 RL 对智能体不够用？

强化学习与可验证奖励（RLVR）在数学推理和代码生成等单轮推理任务中表现出色——因为一个确定性检查器就能判断最终答案是否正确，并提供明确的结果奖励（Outcome Reward）。

但对多轮智能体来说，情况完全不同：

  • 奖励稀疏：一个 rollout 可能包含几十次工具调用，但奖励信号只在最后出现
  • 方差巨大：同样的轨迹，早期操作可能已经收集了关键证据，但由于后期某一步出错，整条轨迹被判负
  • 误判风险：一条失败的 rollout 中可能包含许多有价值的行为（如找到了正确的文档但最后推理错了），而结果奖励给所有这些行为标记了相同的负优势
💡 一个直观的例子
一个搜索智能体在第一个搜索中找到了正确的文档，在打开文档时看到了关键信息，但在最终推理时犯了错。传统结果奖励认为这条轨迹完全失败，而实际上前几步是非常有价值的。

二、核心方法

2.1 TRACE 的整体框架

TRACE 的核心理念非常优雅：用一个冻结的参考模型作为"稳定探针"，度量每个轨迹前缀使标准答案更可预测的程度，从而为每个工具调用分配信用。

其工作流程可以概括为：

  1. 将 rollout 在工具调用边界切分为一系列前缀状态
  2. 用冻结的参考模型计算每个前缀下标准答案的对数概率
  3. 将对数概率转换为对数比率状态值（Log-Ratio State Value）
  4. 使用时序差分（TD）学习计算相邻状态值的变化作为该次工具调用的信用
  5. 将密集的轮次信用与标准的结果奖励结合，进行联合优化

2.2 关键技术创新

🔬 对数比率状态值

这是 TRACE 最核心的设计。为什么不能用原始的对数概率变化？因为同样的绝对增益在不同置信水平下意义完全不同：

  • 当剩余差距从 0.2 缩小到 0.1：去掉了剩下一半的不确定性 → 重要
  • 当剩余差距从 5.1 缩小到 5.0：几乎没变化 → 可以忽略

TRACE 的解决方案是相对闭合度量：

V(S_k) = log(d₀ / d_k)，其中 d_k = -ℓ̄_k + ε

这样 V(S₀) = 0，后续的值越大意味着该前缀已经闭合了更大的初始差距比例。

🔬 TD 信用传递与望远镜效应

TRACE 的一步 TD 信用定义为：

δ_k = V(S_{k+1}) - V(S_k) = log(d_k / d_{k+1})

关键性质——望远镜效应（Telescoping）：

Σδ_k = V(S_T) - V(S₀)

这意味着总信用只取决于端点状态，中间冗余的工具调用不会膨胀总信用，智能体无法通过拖长轨迹来骗取奖励。

🔬 K 步信用回溯

但一步 TD 可能遗漏延迟效应。TRACE 使用截断的 K 步 TD 备份（K=3, γ=0.8），将后续几步的 TD 进度回溯到当前工具调用。

四、技术启示与发展方向

4.1 核心启示

💡 启示一：信用密度比模型大小更重要
TRACE 使用 4B 参数的模型加上密集信用信号，就能超越某些 32B 的深度搜索智能体。这表明在智能体训练中，训练信号的质量比模型规模更关键。
💡 启示二：冻结参考模型是一个被低估的工具
TRACE 使用初始检查点作为冻结参考模型——而不是使用更强大的模型。实验证明，初始化检查点和 200 步后的检查点效果几乎相同。说明参考模型的主要作用是提供一个稳定的价值锚点，而不是充当强评判者。
💡 启示三：纯 RL 可以教会智能体工具使用
全部实验直接使用纯强化学习，不需要冷启动 SFT、不需要智能体中训练阶段、不需要直播数据。这说明基础模型已经具备了推理和工具使用的基本能力，只是需要更密集的信用信号来组织这些能力。

4.2 未来方向

  • 更广泛的任务场景：当前验证集中在搜索任务，未来可扩展到软件工程、计算机控制等更多领域
  • 自适应信用分配权重：α_turn 的超参数调节目前需要人工选择，未来可设计自动化调节机制
  • 与过程奖励模型的结合：TRACE 不需要 PRM，但也不排斥——两者可以互补

五、总结

TRACE 提出的基于对数比率 TD 信用的密集信用分配方法，是当前 AI 智能体后训练领域一个重要的方法论突破。它证明了一个简单而深刻的道理：在长程任务中，给智能体"记功"的方式比是否给奖励更重要。

正如论文所说："Results reward says whether the trajectory succeeded, but it does not reveal which intermediate actions gathered necessary evidence, which were redundant, or which derailed the agent."

TRACE 的关键贡献可以浓缩为三点：

  1. 方法论：用冻结参考模型的对数比率 + TD 学习实现了无需额外训练的密集信用分配
  2. 实证证明：信用密度比模型规模更关键，纯 RL 即可教会复杂工具使用
  3. 实用特性：望远镜效应防止奖励膨胀，无需过程标签，基础检查点即足够
