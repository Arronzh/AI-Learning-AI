### 核心发现更新

#### 1. 量子学派
- **核心方法**：用思想实验承载抽象概念
- **可借鉴点**：科学史叙事 + 悖论引入 + 保留开放性
- **新增发现**：结尾不给出"标准答案"，展示科学的未解之谜，引发读者思考
- **适用场景**：解释复杂技术概念时，先构建可想象的场景

#### 2. 差评
- **核心方法**：人格化写作 + 节奏控制
- **可借鉴点**：段落短小（2-4 句）、金句意识、态度鲜明
- **新增发现**：用多个受访者原话构建叙事，每人一个核心观点，避免单一信源
- **适用场景**：热点技术新闻、需要快速传播的内容

#### 3. 机器之心
- **核心方法**：信息分层 + 权威背书
- **可借鉴点**：背景→核心→细节→延伸的清晰结构
- **新增发现**：标准化的专家履历呈现模板（学历、职位、成就、研究方向），可复用于论文作者介绍
- **适用场景**：专业论文解读、技术报告

#### 4. 棱镜
- **核心方法**：场景先行 + 深度叙事
- **可借鉴点**：用具体场景代替抽象概括、多方信源验证
- **新增发现**：每节小标题都是一个待解答的问题，形成阅读驱动力；结尾用一句凝练的话升华（"说到底，取舍之中，无非都是生意"）
- **适用场景**：深度分析、产业观察

### 小织风格定位（更新）

**推荐组合**：机器之心（框架）+ 量子学派（解释）+ 差评（节奏）+ 棱镜（小标题设计）

**人格设定**：温和专业，适度人格化（用"小织"自称）

**文章结构建议**：
```
1. 场景/思想实验/共情引入（量子学派/差评/棱镜）
2. 技术背景 + 问题重要性（机器之心）
3. 核心方法/技术细节（机器之心）
4. 复杂概念比喻解释（量子学派）
5. 用小标题划分章节，每节一个核心问题（棱镜）
6. 开放性问题 + 资源链接（量子学派 + 机器之心）
7. 凝练收尾（棱镜）
```

**新增技巧**：
- 论文作者介绍采用机器之心的标准化模板
- 用多个"受访者"（论文作者原话/推特点评）构建叙事
- 小标题设计为待解答的问题，形成阅读驱动力
- 结尾用一句凝练的话升华主题
