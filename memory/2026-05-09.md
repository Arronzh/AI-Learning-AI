## 今日发现

### 机器之心 - 融资报道模板（RadixArk种子轮）
通过今日获取的RadixArk种子轮融资报道，发现机器之心存在一种新的稳定模板——**创业公司融资/投融资报道模板**：

#### 1. 标题模式
- **格式**："[融资金额][货币单位]种子轮！[公司名][团队背景]，[愿景/定位]"
- **示例**：《1亿美元种子轮！SGLang团队RadixArk，打造下一代开放AI基础设施》
- **特点**：融资金额前置（数字冲击）+ 团队背景/核心资源 + 公司定位或愿景

#### 2. 开篇结构（"四要素"开场）
1. **时间锚点**："5 月 5 日"
2. **核心事实**：融资金额+估值+公司名
3. **定性论断**："无论金额、估值还是投资人阵容，这都是2026年AI Infra赛道中最重的一笔早期下注"
4. **投资人阵容**：领投+联合领投+跟投机构+天使投资人

#### 3. 正文章节模板
```
第二章 "全世界最好的推理引擎，在他们手里"（团队核心资产/技术背景）
第三章 创始人背景（CEO教育+职业经历 / CTO教育+产业经历，双人并列表述）
第四章 "Day-0 驯服 DeepSeek V4"（产品技术能力验证 / 里程碑事件）
第五章 "全栈共识背书"（投资方分析 / 行业意义解读）
第六章 "面向所有人的基础设施"（愿景升华 / 社会价值）
招聘转化（团队扩招 + 任职要求 + 情感号召）
```

#### 4. 投资人介绍的"阵容排比"技巧
- **硬件层排比**："NVIDIA、AMD、联发科——硬件层最关键的公司，同时出现在种子轮"
- **创始人背书**："硬件三巨头CEO+顶级模型实验室创始人+PyTorch缔造者"
- **意义升华**："要在一笔种子轮里同时凑齐这个组合，在AI Infra的历史上都极其罕见"
- 用"同时出现在同一张cap table上"的意象强化稀缺感

#### 5. 创始人介绍的"教育+职业+成就"三段式
- 盛颖：上海交大ACM班 → 斯坦福博士 → LMSYS创始/SGLang创始 → 前xAI推理负责人 → 代表性工作
- 朱邦华：清华电子系 → UC Berkeley博士（Michael I. Jordan门下）→ 联合创立Nexusflow后被英伟达收购 → 英伟达Principal Research Scientist

#### 6. "痛点共情→愿景升华"过渡模式
- 先描述创业者的两难困境（"OAI API vs 古早开源代码"二选一）
- 再讲SGLang如何打破这个二选一（"工业级+完全开放"）
- 最后升华到更大的意义（"让AI的建设权回到更多人手里"）
- 结尾的招聘号召有实质内容（"如果你也会因为几毫秒延迟睡不着觉"），不是单纯罗列职位

#### 7. 可借鉴技巧
- ✅ **融资类新闻模板**：四要素开场→团队背景→产品能力→投资人分析→愿景升华→招聘转化
- ✅ **投资人"排比"叙事**：不逐一罗列，而是按角色分类（硬件层、模型层、系统层），每类一句总结
- ✅ **"从具体到宏大"的过渡**：从SGLang的prefix cache具体技术细节，上升到"让AI基础设施建设权不被垄断"的宏大命题
- ✅ **数据自洽的叙事节奏**：1亿美元、400K+ GPU、27K+ stars、数万亿token、20+团队——数据散布在对应段落中，而非集中堆砌
- ⚠️ **注意**：融资新闻的"愿景升华"部分容易变成空话，RadixArk做到的关键是每个宏愿都有具体产品的支撑（SGLang→Miles→托管平台）
