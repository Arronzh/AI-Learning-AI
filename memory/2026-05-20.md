## 今日国际 AI 动态（5/19-5/20）

### 1. 🔥 OpenAI Content Provenance 多层级方案（5/19）← 今日最新
OpenAI 发布内容溯源（content provenance）多层级方案：

**三层架构：**
- **C2PA 协议合规**：OpenAI 成为 C2PA Conforming Generator Product，提供带加密签名的 Content Credentials 元数据，跨平台可识别
- **Google SynthID 隐形水印**：与 Google DeepMind 合作，对 ChatGPT 图像 2.0、Codex、API 生成的图片嵌入抗截图/格式变换的隐形水印
- **公开验证工具**：上线 verify.openai.com 预览版，用户可上传图片验证是否来自 OpenAI

**覆盖产品线**：DALL·E 3 → ImageGen → Sora → ChatGPT Images 2.0 → Codex → API

**两层互补关系**：C2PA 元数据提供详细上下文（谁/何时/如何生成）但易被剥离；SynthID 水印抗变换（截图/格式转换）但信息量有限。两层叠加使溯源更鲁棒。

**选题预判：**
