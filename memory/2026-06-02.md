## 风格学习记录

### OpenAI AWS 文章分析（6月1日发布）

**文章信息**：OpenAI frontier models and Codex are now available on AWS
**类型**：企业合作/产品发布公告
**风格特征**：

| 维度 | 特征 |
|------|------|
| 语气 | 正式、企业级、合作伙伴导向 |
| 结构 | "发布信息 → 两种集成方式 → 客户价值 → What's next" |
| 核心叙事 | **"摩擦消除"框架**——"removes one of the biggest barriers"为叙事主干 |
| 关键短语 | "less friction", "familiar operating model", "faster path to production", "move from evaluation to real deployment" |
| 面向受众 | 企业决策者（CTO/CIO/安全负责人） |
| 数据点 | Codex "used by more than 5 million people every week" |
| 结尾策略 | "teasing"——预告 Daybreak 能力，制造期待 |

**可借鉴的写作技巧**：
- ✅ **"摩擦消除"叙事框架**：企业技术文章中，"移除障碍"比"新增能力"更能打动决策者
- ✅ **"从评估到部署"故事线**：evaluation → production 的路径描述，给读者一个清晰的成熟度模型
- ✅ **"What's next"+前瞻预告**：用"包括未来（Daybreak）在内的能力将持续扩展"，制造续集感
- ✅ **三个关键词重复**：security, procurement, governance 多次出现，建立信任锚点
- ⚠️ **注意**：此类公告型文章篇幅短小（本文约600字英文），信息密度低于技术深度文

**与机器之心风格的关联**：
- 机器之心翻译此类合作新闻时，通常采用"刚刚"快讯体（参见 style_guide 机器之心第 6 条的"刚刚快讯体"模板）
- 中文角度可从"AWS+OpenAI 联合对企业AI部署意味着什么"切入，而非简单翻译公告
