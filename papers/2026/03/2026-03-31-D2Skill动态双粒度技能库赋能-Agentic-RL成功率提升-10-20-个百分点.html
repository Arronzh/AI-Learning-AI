D2Skill：动态双粒度技能库赋能 Agentic RL，成功率提升 10-20 个百分点

📌 核心摘要

中国科学院自动化研究所、鹏城实验室与中山大学联合提出 D2Skill（Dynamic Dual-Granularity Skill Bank），一种面向 Agentic 强化学习的动态双粒度技能库框架。针对现有技能方法仅提取轨迹级指导、缺乏技能记忆演化机制的局限，D2Skill 将可复用经验组织为任务技能（task skills）和步骤技能（step skills）两个粒度：前者提供高层任务指导，后者支持细粒度决策与错误纠正。通过在相同策略下对比技能注入与非注入轨迹的性能差距，D2Skill 推导后见效用信号用于技能更新与策略优化。在 ALFWorld 和 WebShop 基准上，基于 Qwen2.5-7B-Instruct 和 Qwen3-4B-Instruct-2507 的实验表明，D2Skill 相比无技能基线 consistently 提升成功率10-20 个百分点，且技能库在训练过程中保持高效用、可迁移、低开销的动态演化。

---

一、研究背景与动机

Agentic RL 的核心挑战

Agentic 强化学习（Agentic RL）是训练语言智能体解决长程决策任务的新兴范式，涵盖交互式环境（如 ALFWorld）、网页搜索（如 WebShop）及科研场景。在这类任务中，策略通过文本接口与环境交互，基于任务描述和有限的历史观测 - 动作对选择动作。

然而，这种基于历史的上下文通常不是底层状态的充分统计量，导致严重的部分可观测性，且随着决策视界增长，信用分配（credit assignment）愈发困难。在稀疏奖励和大动作空间下，孤立地学习每个任务效率极低。

现有技能方法的局限

近期研究通过引入额外监督信号缓解上述挑战：

  • 部分方法采用基于结果的信用分配提供过程奖励
  • 部分方法从完成轨迹中推导后见监督
  • 最新工作聚焦于使智能体跨任务积累经验并在训练中迭代优化

在这一方向上，可复用技能已成为过去经验的有效形式。例如 SkillRL 从过去轨迹构建技能库并检索相关技能指导策略交互，提升长程任务的探索效率。

但现有技能与反思驱动框架仍存在两大局限：

1. 粒度单一：大多数方法从完整轨迹推导技能，强调任务级反思，虽能捕获高层指导，但对单个交互步骤的细粒度错误纠正效果有限

2. 技能库膨胀：随着训练推进，技能库持续扩张，检索与管理愈发困难。若无原则性的技能评估与剪枝机制，冗余或无效技能会退化检索指导质量，阻碍策略优化

二、核心方法

D2Skill 框架概览

D2Skill（Dynamic Dual-Granularity Skill Bank）通过维护双粒度技能和动态技能管理机制解决上述问题。

2.1 双粒度技能建模

D2Skill 区分两类技能：

技能类型功能定位作用粒度典型内容
任务技能（Task Skills）高层任务指导任务级任务分解策略、子目标序列、全局规划原则
步骤技能（Step Skills）细粒度决策支持单步级局部错误纠正、动作选择启发式、状态 - 动作映射规则

这种设计使智能体既能获得宏观任务指引，又能在具体交互步骤中快速纠正偏差。

2.2 配对轨迹训练与效用估计

D2Skill 的核心创新在于联合训练策略与技能库：

1. 配对 rollout：在相同策略π_θ下，并行执行两类轨迹：

  • 基线轨迹（无技能注入）
  • 技能注入轨迹（检索技能并增强上下文）

2. 效用信号推导：通过对比两类轨迹的性能差距，推导后见技能效用（hindsight skill utility）：

  • 若技能注入轨迹表现更优 → 技能效用为正，保留并强化
  • 若技能注入轨迹表现相当或更差 → 技能效用为负，标记为待剪枝

3. 双向优化：效用信号同时用于：

  • 技能库更新（技能生成、检索权重调整、剪枝）
  • 策略优化（策略梯度更新）

2.3 动态技能管理

技能库的演化通过以下机制实现：

  • 反思驱动扩展：从训练经验中通过反思生成新技能
  • 效用感知检索：优先检索高效用技能，降低噪声干扰
  • 动态剪枝：定期移除低效用或冗余技能，保持技能库紧凑

这一机制确保技能库在整个训练过程中保持信息密集、高效用、低冗余的状态。

三、实验结果

3.1 实验设置

基准任务：

  • ALFWorld：文本交互的家庭环境任务（如"把某个物体放到某处"）
  • WebShop：网页购物导航任务（如"找到符合某条件的商品并购买"）

基线模型：

  • Qwen2.5-7B-Instruct
  • Qwen3-4B-Instruct-2507

对比基线：

  • 无技能基线（Skill-Free）
  • GRPO（Group Relative Policy Optimization）
  • 现有技能增强方法（如 SkillRL）

3.2 主要性能指标

方法ALFWorld 成功率WebShop 成功率提升幅度
无技能基线~55%~35%-
GRPO~62%~42%+7%
SkillRL~68%~48%+13%
D2Skill（Ours）~75%~55%+10~20%

关键发现：

1. D2Skill 在两个基准上均一致优于无技能基线和现有技能增强方法

2. 双粒度建模与动态维护对性能提升均至关重要（消融实验验证）

3. 学习到的技能展现出高效用、跨评估设置可迁移的特性

4. 训练开销适中，未引入显著计算负担

3.3 训练动态分析

成功率训练曲线（图 1c）显示：

  • D2Skill 技能组的成功率增长最快且最终收敛值最高
  • 配对基线组（相同策略但无技能注入）表现次之
  • GRPO 基线增长较慢且收敛值较低

技能库动态（图 1d）显示：

  • 有管理条件下，平均技能效用保持稳定高位
  • 无管理条件下，技能效用随技能库膨胀而下降
  • 动态剪枝有效维持技能库质量

四、技术启示与发展方向

对 AI Agent 开发的启发

1. 经验抽象的必要性：原始轨迹冗长且含噪声，将其抽象为技能（规则/启发式）再注入 prompt，比直接塞入原始日志更高效、更省 token

2. 双粒度设计的价值：单一粒度（仅任务级或仅步骤级）难以兼顾宏观规划与微观纠错，双粒度技能库是更稳健的设计

3. 动态管理优于静态存储：技能库需具备"生长 - 修剪"机制，否则随规模扩张会退化为噪声库

4. 效用评估是关键：通过配对轨迹对比推导技能效用，是 principled 的技能评估方法，避免主观筛选

可直接应用的技术点

  • 技能检索增强：在现有 Agent 框架中引入技能检索模块，从历史成功轨迹中提取可复用模式
  • 反思驱动更新：在任务失败时触发反思，生成"失败教训"技能供未来参考
  • 效用感知剪枝：定期评估技能使用频率与成功率，移除低效技能

---

五、总结

D2Skill 提出了一种动态双粒度技能库框架，通过任务技能与步骤技能的协同、配对轨迹的效用估计、以及反思驱动的动态管理，有效解决了 Agentic RL 中经验复用与技能演化的核心挑战。

核心贡献：

1. 首次提出双粒度技能建模（任务级 + 步骤级）

2. 设计配对轨迹训练机制，实现策略与技能库的联合优化

3. 引入效用感知的动态技能管理，保持技能库紧凑高效

4. 在 ALFWorld 和 WebShop 上验证了 10-20 个百分点的显著提升

实际效果：

指标数值
成功率提升+10~20%
技能效用稳定性高（动态管理下）
跨任务迁移性支持
训练开销适中
