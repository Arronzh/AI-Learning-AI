SearchSwarm：当 LLM 学会"分配任务"，轻量模型如何击败十亿参数巨无霸？

清华 · 北大 · 蚂蚁集团 · 中国人民大学 | arXiv 2606.09730 | 2026年6月9日
📌 核心摘要

上下文窗口不够用怎么办？清华、北大、蚂蚁集团和中国人民大学组成的研究团队提出了一个全新的思路：让大模型学会"分配任务"——主 Agent 将复杂任务拆解成子任务，分派给子 Agent 执行，子 Agent 只返回压缩后的结果。这种被称为"委派智能"（Delegation Intelligence）的能力，使得仅 30B-A3B 参数的 SearchSwarm 模型在 BrowseComp 上达到 68.1 分，超越了 GPT-5.2-Thinking（65.8）和 DeepSeek V3.2（67.6），甚至能与 10 倍以上参数的模型同台竞技。

一、研究背景与动机

1.1 大模型的长程任务困境

随着 LLM 被广泛应用于复杂的真实世界任务，一个根本性矛盾日益凸显：任务复杂度可以无限增长，但模型的上下文窗口始终是有限的。

现有的解决方案大多是"被动式"的：超过长度阈值后截断或丢弃历史信息、只保留最近几轮工具调用结果、对轨迹进行自动摘要压缩。这些方法缺乏预先规划，总是在上下文预算耗尽后才采取行动，或者按照固定规则随意丢弃信息。

1.2 "委派范式"：一种更智能的上下文管理

研究团队提出了一种新范式：主 Agent 将任务分解后分派给子 Agent 执行，子 Agent 在独立的上下文中运行，只将压缩后的结果返回给主 Agent。

这种方法的优点在于：子 Agent 的探索成本被隔离在自己的上下文中，主 Agent 的注意力始终集中在高层协调上，返回的摘要天然是一种"内容感知的压缩"。

"表面上这是一个多 Agent 系统，但实际上它是单 Agent 的上下文管理——只是模型用自己生成的摘要替换了固定规则的截断。"

二、核心方法

2.1 SearchSwarm 架构

SearchSwarm 采用 "主分配-子执行" 范式，整体流程如下：

  • 主 Agent 接收用户查询，规划整体研究方案
  • 主 Agent 将复杂问题拆解为多个子任务
  • 通过 call_sub_agent 工具将子任务分派给子 Agent
  • 子 Agent 在独立上下文中执行搜索和验证
  • 子 Agent 返回带引用的压缩报告
  • 主 Agent 汇总各子报告，形成最终答案

2.2 四大设计原则

① 鼓励委派：多步信息收集是 token 密集但认知浅的工作。主 Agent 应将这类工作交给子 Agent，只有当子任务足够浅时，才自行执行。

② 全面简报：子 Agent 从零开始，没有预先的研究背景。简报不仅是任务描述，还应包括为什么这个子任务重要、已经确定了什么、还有什么不确定、哪些方向已经尝试过或排除了。

③ 主 Agent 保留核心判断：只有主 Agent 拥有全局视图。子 Agent 负责收集证据和验证假设，所有方向性决策由主 Agent 独立做出。

④ 引用溯源报告：子 Agent 的每个重要结论必须附带内联引用指向具体来源 URL，主 Agent 可以验证结论的可靠性，实现端到端的可追溯性。

2.3 数据合成与训练

研究团队面临的核心挑战是：委派智能的训练数据在自然文本中极为稀缺——自然语料很少包含多 Agent 协作行为。

解决方案：先用 Harness 引导模型在深度研究任务上执行委派行为并记录轨迹，然后筛选答案正确的样本，去除不良行为模式，最后通过监督微调（SFT）将委派行为内化到模型权重。

2.4 委派即上下文管理

论文的一个重要洞察：委派机制本质上是上下文管理的一种形式。与传统方法由固定规则决定不同，这里简报和报告都由模型自己生成——这是一种更智能的、内容感知的压缩策略。

相比基础模型（43.4），训练带来了 24.7 个百分点的绝对提升。在 GAIA 上甚至超过了 GPT-5（76.4）和 Seed-2.0-Pro（78.6）。

3.2 Harness 有效性验证

在 BrowseComp 的 200 题子集上：基础框架 47.7 → +call_sub_agent 工具 50.0（+2.3）→ 完整 Harness 57.7（+10.0）。仅仅提供委派工具只有小幅提升，完整的 Harness 设计带来了大幅飞跃。

3.3 跨基座与跨场景泛化

使用完全相同的数据训练 Qwen3-30B-A3B-Thinking，同样取得显著提升（BrowseComp 子集 66.5），证明数据本身的质量。禁用委派工具回归单 Agent，SearchSwarm 仍比基础模型高 8.5 分。在开放式长文本任务上平均提升 14.2 分，零样本泛化到未训练过的场景。

四、技术启示与发展方向

委派智能正在成为 AI Agent 的下一个重要能力。与其不断扩展模型规模和上下文窗口，不如教会模型更智能地管理有限资源。委派机制本质上是一种"元认知"能力——模型不仅要会做事，还要知道什么事该自己做，什么事该交给别人做。

开源生态的重大贡献。研究团队承诺开源 Harness 代码、模型权重和训练数据，这将极大推动委派智能和 Multi-Agent 协调方向的研究。

现有局限：多轮提升不显著、仅支持单层委派、更大规模下的效果有待验证。

对 AI Agent 开发者而言，这一思路具有重要的实践意义：与其一味追求更大的模型和更长的上下文，不如让模型学会"分配任务"——正如一位优秀的项目经理，不一定自己什么都会，但知道该怎么把工作分配出去。

五、总结

SearchSwarm 是委派智能领域的开创性工作，证明了通过精心设计的 Harness 引导和 SFT 训练，轻量级模型可以在长程研究任务上达到甚至超越超大规模模型。

核心贡献：

  • 首次系统探索了委派智能在超长程 Agent 任务中的应用
  • 设计了包含四大原则的 Harness，有效引导模型产生高质量委派行为
  • 利用 Harness 轨迹合成了高质量 SFT 数据，将委派行为内化到模型权重
  • SearchSwarm 在多个基准测试上达到同规模最佳，展现跨场景泛化能力
