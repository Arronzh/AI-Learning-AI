量化的"幻觉"：LLM 低比特量化下的行为漂移，你看到了吗？

📌 核心摘要
后训练量化（PTQ）被广泛用于在资源受限环境中部署大语言模型，但传统评估几乎只依赖准确率和困惑度——而这可能是一个危险的"等效幻觉"。来自曼尼托巴大学和中佛罗里达大学的研究团队通过引入正确一致性（Correctness Agreement）这一决策级度量，揭示了量化模型在精度看似保持不变的情况下，内部行为已发生显著漂移。在 8-bit 到 2-bit 的全精度范围扫描中，他们发现：（1）中等量化下即出现行为分歧；（2）Query 和 Key 投影比值和输出投影对量化敏感得多；（3）低比特宽度存在非线性断裂点，越过该点即使困惑度不变，决策行为也已天差地别。

一、研究背景与动机

部署 LLM 时，"小了还想小"是永恒主题。量化通过降低参数和激活值的数值精度，直接减少内存占用、加速推理并降低能耗。后训练量化（PTQ）凭借"无需重新训练"成为业界主流。

用 llama.cpp 把 Llama-3.1-8B 压到 Q4_K，跑个 HellaSwag，准确率掉了 1%，"还行"——这是今天绝大多数团队的共识。

但这个共识可能错了。

问题在于：准确率和困惑度是聚合指标。 两个模型可能在同一基准上跑出几乎一样的分数，却在同一批样本上做出完全不同的正确判断。更危险的是，这种"行为漂移"并不随精度的恢复而消失——它隐藏在统计量的变化中，直到某些关键场景才暴露出来。

本文的核心贡献就在于揭穿这个"等效幻觉"，并为量化评估引入一种新的方法论框架。

二、核心方法

2.1 将量化建模为算子族

团队将 PTQ 严格形式化为对参数空间的算子：Tc(θ) = Dc(Qc(θ))，其中 c 表示量化配置（含位宽和量化方案标识），Qc 和 Dc 分别表示量化和反量化操作。量化前后的变化可以在统一的数学框架下被精确度量。

评估覆盖了两类主流量化方案：

  • Legacy 量化：Q8_0、Q5_0、Q4_0，采用逐块均匀线性量化
  • K-量化：Q6_K、Q5_K、Q4_K、Q3_K、Q2_K，使用基于局部均值和标准差的统计分块方案

2.2 关键创新：正确一致性（Correctness Agreement）

这是本文最核心的贡献。设 zm 为基模型对样本 m 的预测正确性（1 正确，0 错误），zm(c) 为量化后模型的对应值：

CA(c;θ,D) = (1/M) Σ 𝟙[zm = 1 ∧ zm(c) = 1]

这个指标衡量的是：基模型做对的那些样本，量化模型也做对的比例。 它与准确率有一个关键的约束关系：

0 ≤ CA ≤ min{Acc(θ), Acc(Tc(θ))} ≤ 1

也就是说，CA 天然是"准确率的下界度量"。如果 Acc(θ) = 0.75，Acc(Tc) = 0.74，看起来几乎没差，但 CA 可能只有 0.60——这意味着虽然总分接近，但两模型实际上在大量样本上做了不同的正确预测。

2.3 双层结构分析框架

团队构建了一个"权重空间 → 行为空间"的双层分析框架：

  • 权重空间分析：均值、标准差、偏度、峰度 + KS 统计量、欧氏距离、余弦相似度、KL 散度
  • 行为空间分析：困惑度 + 准确率 + 正确一致性（CA）

三、实验结果

3.1 实验设置

  • 模型：Llama-3.2-3B、Vicuna-7B-v1.5、Mistral-7B-v0.1、Llama-3.1-8B
  • 量化范围：8-bit → 2-bit（8 个精度级别）
  • 评估基准：WikiText-2、C4（困惑度）；HellaSwag、Winogrande、ARC（零样本任务）

3.2 四大关键发现

发现一：统计量在低比特下发生非线性断裂

随着位宽降低，注意力权重的统计量不是线性退化，而是存在明显的相变点。在 Q4_K（4-bit）以下，峰度急剧下降——权重分布的重尾被抹平，那些罕见但高度重要的权重几乎被量化噪声吞没。

发现二：Query 和 Key 是量化"软肋"

在所有注意力投影中，Query 和 Key 投影权重对量化的敏感度显著高于 Value 和 Output。这一发现具有重要的实用价值：混合精度量化策略应该优先保护 Q、K 投影，允许 V、O 承受更多压缩。

发现三：行为漂移在中等量化下已经出现

即使在 Q5_K（5-bit）下，模型的正确一致性已经出现可检测的下滑。基模型和量化模型虽然在各自的总分上持平，但两者正确预测的样本重叠率却在持续降低。

发现四：困惑度不是行为的"替代指标"

两个量化模型的困惑度可以几乎相同，但 CA 指标却存在显著差异。仅凭困惑度来验证量化质量的工程实践存在根本性缺陷。

四、技术启示与发展方向

4.1 对评估体系的冲击

这项工作直击当前量化评估的"阿喀琉斯之踵"。未来的量化评估标准应当强制包含某种形式的"行为一致性"度量。

4.2 工程实践的建议

  • 混合精度量化：对 Q、K 投影使用更高位宽（如 6-bit），对 V、O 投影压缩到 4-bit
  • 量化后的行为验证：部署前跑 CA 检查，确保关键样本行为被保留
  • 避免"一刀切"：不同模型架构的敏感层分布不同，需针对性分析

4.3 本期 arXiv 关联推荐

本周还有几篇值得关注的工作：

  • "Remember When It Matters: Proactive Memory Agent"（arXiv:2607.08716）—— Meta AI 提出的主动记忆机制，用独立记忆 Agent 判断"什么时候该提醒主 Agent"，在 Terminal-Bench 2.0 上带来 +8.3pp 提升
  • "Training-free Relaxed Speculative Decoding"（arXiv:2607.08690）—— 对推测解码"宽松策略"的系统实证，关键发现：放松严格保真度可加速，但需谨慎评估能力影响

五、总结

量化从来不是"无损"的，只是我们以前不够仔细去看到它的代价。"The Illusion of Equivalency" 用严谨的统计方法撕掉了量化精度评估的遮羞布。它不仅提醒我们准确率不是万能的，更重要的是提供了一套可落地的分析框架。

对于每一位在实际项目中做模型量化的工程师和研究者，这篇文章都值得一读——它可能改变你对"这个量化模型和原模型等价"这一假设的看法。

写代码时，一个 bug 会在测试中暴露；量化时，一个"等效"的幻觉却可能悄无声息地带偏模型的行为。
