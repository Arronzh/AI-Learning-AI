预训练喂得越多，RL 学得越好？三篇论文揭示 AI 推理能力的底层密码

AI 论文精读 2026年7月20日 · 周一
📌 核心摘要
本周 arXiv 为我们带来了三篇与 LLM 推理和训练方法密切相关的重量级研究。NYU 团队用国际象棋搭建了一个从预训练到 RL 后训练的完整透镜，首次量化了"预训练喂得越多，RL 学得越好"的标度律；Texas A&M 团队则从信息瓶颈理论出发，解释了多智能体系统何时真正优于单智能体——答案藏在"中继消息的压缩"中；而第三篇工作挑战了一个被普遍接受的假设：模型合并真的能替代联合多任务训练吗？答案是——在 RL 场景下，合并的效果与联合训练统计上无差异。

一、研究背景与动机

1.1 预训练与 RL 之间的"黑箱"

过去两年，以 DeepSeek-R1、OpenAI o1 为代表的推理模型展示了 RL 后训练对复杂推理能力的巨大提升。然而一个根本问题始终悬而未决：预训练的质量到底在多大程度上决定了 RL 的效果？

当前的主流视角出现了分歧。一派认为"预训练为王"——更大的模型、更多的数据、更充分的预训练才是根本；另一派则主张"经验至上"——RL 能从环境交互中涌现出超越模仿的能力。但现实中，这两阶段的交互从未被系统量化过：预训练语料庞大且不可控，难以将行为归因于预训练还是 RL，同时跨两阶段的系统计算扫描成本高得令人望而却步。

1.2 多智能体系统的"玄学"

与此同时，多智能体系统（MAS）正在成为 LLM 应用的热门范式。从 AutoGen 到 MetaGPT，研究者们将复杂任务分解给多个专业智能体协作完成。但一个尴尬的现象是：MAS 的优势极不稳定——某些任务上效果显著，另一些任务上甚至不如单智能体系统（SAS）。更强的基座模型往往让 MAS 的优势消失。这种"玄学"状态呼唤一个理论框架来解释其本质。

1.3 模型合并的"未验证承诺"

模型合并（Model Merging）被广泛宣传为联合多任务训练的"平替"——通过 TIES、RAM+ 等方法合并独立训练的专家模型，理论上可以获得与联合训练相当的泛化能力。但吊诡的是：这个方法几乎从未真正与它声称要替代的基线进行过对比，因为联合训练模型本身通常不可得。一次严谨的"同场竞技"已经迟到了。

二、核心方法

2.1 预训练→RL 标度律：国际象棋作为"AI 科学的果蝇"

NYU 团队的策略堪称巧妙：用国际象棋作为 LLM 推理研究的受控测试平台。为什么是国际象棋？因为它拥有：紧凑且明确的动作空间（每步仅 81 个 token 的词汇表）、可验证的奖励信号（最优走法可由引擎精确判定）、充足的、可控制的人类对弈数据（可按棋力 Elo 分筛选），以及小模型也能体现有意义的差异（5M 到 1B 参数规模的模型都能产生可测量变化）。

研究团队严格模仿标准 LLM 训练流水线：预训练阶段在 540 亿 token 的 Lichess 人类棋局上训练自回归策略；SFT 阶段用合成推理轨迹（思维链的"棋盘版本"）监督微调；RL 阶段在国际象棋谜题环境中使用 GRPO 算法进行强化学习。

关键创新在于：他们合成推理轨迹的方式不是外挂搜索算法，而是从预训练模型自身采样可能走法的延续，按深度优先序列化为"思维链"——这与 LLM 的 CoT 推理完全对应。

2.2 信息瓶颈视角：把 MAS 建模为"压缩-保真"优化问题

Texas A&M 团队的核心洞察非常简洁：单智能体系统把所有推理痕迹累积在一个共享上下文中，而多智能体系统通过隔离的局部上下文和一串有带宽限制的"中继消息"连接各智能体。

他们数学上证明了一个重要结论：在无限中继带宽下，任何 SAS 都可以被 MAS 精确模拟。也就是说，MAS 的优势——如果有的话——一定来源于带宽受限带来的中继压缩。

这引出信息瓶颈（IB）视角下的权衡：压缩减少了冗余上下文（提高效率），但可能丢弃下游任务所需的信息。他们形式化了一个"阶段性 MAS 增益"公式：

MAS 增益 = 上游噪声减少的收益 − β × 中继信息丢失的代价

其中 β 是随模型能力增长的参数——越强的模型越不需要压缩带来的"简化"，也越敏感于信息丢失。

2.3 模型合并 VS 联合训练：一次迟到的"同场竞技"

研究者使用 LOOP 算法在 AppWorld 智能体基准上训练了 Qwen3-8B 的难度-1 和难度-2 专家模型，然后用 TIES 和 RAM+ 合并它们，再与在相同数据上联合训练的模型进行正面比较。

他们进一步分析了任务向量的几何结构：两个专家的任务向量几乎是正交的（余弦相似度 0.06-0.10），尽管参数支持集有约 65% 的重叠。由于方向和参数支持集是解耦的，基于支持集和符号的合并方法实际上退化为近均匀平均。

三、实验结果

3.1 预训练与 RL 的"黄金配对"

研究团队在 10 个模型规模（5M 到 1B 参数）上扫描了 36 种预训练-RL 组合，发现了清晰的联合标度律：

  • 给定 RL 计算量下的最终性能，可以用预训练损失精确预测
  • RL 奖励曲线的斜率与预训练 token 数量近似呈线性增长
  • 预训练更充分的 checkpoint 在相同 RL 计算量下达到更高性能，且 RL 学习速度更快

在数学领域（1B 参数模型在 10B-200B token 数学文本上预训练）的实验中，同样的规律成立。

更深入的机制分析揭示：RL 不只是"锐化"已有能力。在简单谜题上，RL 确实只是放大了 SFT 策略已经偏好的正确走法；但在困难谜题上，RL 能"浮出"那些在 SFT 策略下几乎不存在的正确走法——但又会同时强化错误走法。这解释了为什么 RL 提升了 pass@1 却不持续提升 pass@k。

3.2 MAS 何时真正有效？

在 5 个智能体基准（ALFWorld、WebShop、WorkBench、WideSearch、TravelPlanner）和 3 种模型规模上的 18 组对照实验表明：

  • 当中继近乎充分时，MAS 对弱模型一致有帮助
  • 当中继发生信息丢失时，MAS 的优势缩小甚至逆转——尤其是对强模型而言
  • 一个典型案例：在 TravelPlanner 任务中，同一个中继设计让 GPT-4o-mini 提升 18% 准确率，却让 Qwen3.5-27B 下降 8%

这完美验证了他们的理论预测：更强模型从冗余上下文中提取有用信息的能力更强，因此从压缩中获益更少，而对信息丢失却更敏感。

3.3 模型合并：意外的好消息

在 AppWorld 智能体基准上，合并模型与联合训练模型在任务目标完成率上统计上无差异。无论使用 TIES 还是 RAM+，所有合并变体的表现几乎相同。任务向量近乎正交（余弦相似度仅 0.06-0.10），暗示每个专家在不同的"方向"上学习，使得合并本质上变成了均匀平均。

四、技术启示与发展方向

这三篇论文各自从不同角度触及了同一主题——我们正在从"盲人摸象"走向对 AI 训练和推理更底层、更量化的理解。

对预训练-后训练分配策略的启示：NYU 的研究表明，对于固定计算预算，最优的预训练/RL 分配并非固定比例，而是随着总计算量的增长，RL 的占比应该逐渐提高。这意味着在预算有限时，优先保证充分的预训练数据量；当预算充裕时，加大 RL 后训练的投入会更划算。

对多智能体系统设计的启示：信息瓶颈视角提供了一个实用的"MAS 适用性诊断工具"——在设计多智能体系统之前，先评估你的中继消息是否足以承载下游任务所需的信息。如果中继带宽严重不足（例如被严格的 token 限制或过于激进的摘要策略约束），强模型反而可能比单智能体表现更差。

对模型合并的启示：任务向量近乎正交的发现暗示，在 RL 场景下，不同难度的任务确实在模型参数空间中占据不同的子空间。这为"专家混合"（MoE）和持续学习提供了新的视角——模型可能比我们想象的更容易同时容纳多个任务而不产生严重干扰。

尚未解决的问题：
· MAS 的 IB 框架如何扩展到非链式（如星型、全连接）的通信拓扑？
· 如何设计自适应中继策略，使中继压缩程度随任务和模型自动调整？
· 预训练-RL 标度律在自然语言推理任务上是否完全成立？团队已用数学文本验证了趋势，但更广泛的验证仍需进行。

五、总结

本周的三个亮点研究虽然来自不同团队、聚焦不同问题，但都指向同一个方向：AI 社区正在用更严谨的科学方法代替经验试错。

将国际象棋作为推理研究的受控测试平台，让我们得以首次"可视化"预训练如何塑造 RL 的回报率——一个可以量化计算的答案，胜过一千次直觉猜测。将信息瓶颈理论引入多智能体系统分析，把"MAS 何时有效"从经验观察升级为可推导的数学框架。而模型合并与联合训练的正面对决，则用统计学否定了一个被广泛接受但从未验证的假设——科学精神的胜利。
