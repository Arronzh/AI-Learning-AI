# 反思不如重试？三篇 arXiv 论文同时拷问"推理时计算"：算力花在哪才值

📌 **核心摘要**

大模型进入"推理时计算"时代后，一个朴素的问题反而没人认真回答：多出来的算力，到底花在哪最值？

今天 arXiv 上的三篇论文从三个角度同时逼近这个问题。**论文一**（Sample More, Reflect Less）用严格的设计实验给出了一记重锤：在 token 预算完全相等的前提下，Self-Refine、Reflexion 等"自我反思"类方法，从 1.5B 到 7B 规模、36 组配对比较中无一显著胜过"重复采样+多数投票"这个朴素基线，其中 10 组还显著更差——全是让模型检查自己输出的方法。**论文二**（Rethinking Inference-Time Scaling in Local Computer-Use Agents）发现，本地部署的计算机使用智能体（CUA）上，推理时扩展的收益普遍递减：拉长时间视野往往只是延长了错误轨迹，而不是修正它。**论文三**（OSReward）则拷问了裁判本身——用来给智能体轨迹打分的大模型评委普遍存在"宽松偏差"，会把失败的轨迹误判成成功。

一句话总结：**当算力成为稀缺品，"想得更久"未必比"试得更多"划算，而"谁来裁判"本身也成了问题。**

## 一、研究背景与动机

先做个小思想实验。假设你手里有一笔固定的 token 预算，面对一道数学题，你有两种花法：让模型写一遍答案然后自己检查、批评、重写；或者干脆让它独立写 8 遍，挑出现次数最多的那个答案。哪种更划算？

直觉上，前者听起来更"聪明"——反思、纠错，这正是人类解题的方式。过去两年，Self-Refine、Reflexion、Best-of-N、自我辩论（debate）等方法也确实在论文里不断报出好消息。但这里藏着一个方法论陷阱：这些方法几乎都会生成比单条思维链多得多的文本，而"生成更多文本"这件事本身就会提升准确率。换句话说，你很难分清提升来自方法的"想法"，还是仅仅来自它烧掉了更多 token。

早在 2024 年，Wang 等人的研究就提示过：把预算拉平后，朴素的"重复采样取多数"常常能赢。但那份工作只给了点估计，没有置信区间，也没有显著性检验——严谨性上留了把柄。

论文二来自另一个战场。前沿模型做计算机操作（CUA）时，推理时扩展能显著提升表现，但那是建立在云端巨量算力之上的结论。本地部署的模型（Qwen3-VL、UI-TARS、OpenCUA 这一档）受硬件约束，扩展到底有没有用、什么时候边际归零，此前几乎没人系统测过。

论文三则盯上了评估链条本身。CUA 的轨迹验证是评估、数据筛选和强化学习的核心环节，人工标注撑不起规模，业界越来越多地让视觉语言模型（VLM）当"评委"。可这个评委自己可不可靠？这个问题居然长期没人系统检验。

三篇论文，三个层面：方法层、系统层、评估层。它们互不隶属，却指向同一个疑问——**推理时计算的每一分钱，真的花对地方了吗？**

## 二、核心方法

### 论文一：把"反思"放进成本核算的显微镜下

这项研究的设计思路相当直白，但执行得很较真。它选了 7 种方法（含 Self-Refine、Reflexion、Best-of-N、多数投票、自我辩论等），在 1.5B、3B、7B 三个规模的开源模型上、两个数学基准各 150 道题上跑。关键动作有两个：

一是**成本核算**。所有生成的 token 都被计数——包括花在批评、反思、辩论回合和检查上的 token。每个方法都和"重复采样"基线在**各自实测成本**下对比，而不是给一个固定的采样数。

二是**统计严谨性**。36 组比较全部按题目配对，用 bootstrap 置信区间加多重检验校正，把"看起来赢了"和"统计上赢了"严格区分开。

### 论文二：四个维度的扩展实验

研究者把推理时扩展拆成四个维度系统测试：**上下文扩展**（给更多历史信息）、**时间扩展**（放宽最大步数）、**结构分解**（把任务拆成两阶段 Agent）、**并行扩展**（多路同时尝试）。模型覆盖 Qwen3-VL-8B/30B-A3B、UI-TARS-1.5-7B、OpenCUA-7B，基准是 OSWorld——一个模拟真实桌面操作环境的测试场。

### 论文三：先造一把尺子，再量所有评委

OSReward 的构建分三步：从多个 Agent 主干（backbone）在跨平台执行人类核验过的指令，收集真实轨迹；用多阶段人工标注给每条轨迹打上 ground-truth 判定；在此基础上再切出两个子集——OSReward-Hard 专挑真正棘手的困难样本，OSReward-Multi 则做细粒度的效率与对齐评分。有了这把尺子，研究者对当前主流 VLM 评委做了一次迄今最全面的体检，并据此训练了开源的 OS-Shepherd（9B/35B）奖励模型。

## 三、实验结果

### 论文一：没有奇迹，只有账单

结果相当干脆：**36 组比较中，没有任何方法在等成本下显著优于重复采样；10 组显著更差，全部是"模型检查自己输出"的方法；18 组自我检查类比较，无一例外是负结果。**

两个细节很有意思。

第一，"让模型自己挑答案"这件事，随着模型变大正在从"伤害"变成"不痛不痒"。把 Best-of-N 采的 8 个样本拿来数票（多数投票），比让模型自己选，在 1.5B 模型上能高出 8.0 和 11.3 个点；但到了 7B，差距缩到 2.0 和 1.3 个点，统计上已和零无异。小模型不会挑，大模型勉强会挑，但挑了半天也没比数票强。

第二，"重写"救不回来。Self-Refine 和强制版的 Reflexion 在 7B 模型上依然落后基线 3.6 到 10.1 个点。

最戏剧性的发现藏在角落里：**Reflexion 按原论文的配置跑，在最小的 1.5B 模型上从来没有触发过一次自我重试**——它每次都判断自己"答对了"，然后安安静静地退化成一条普通思维链。你以为是反思在起作用，其实它压根没反思。

### 论文二：扩展的收益曲线，比想象中更早见顶

本地 CUA 的实验结果可以用"收益递减"四个字概括。上下文扩展确实提升了轨迹稳定性和任务准确率，但收益随 token 成本上升迅速饱和——而且失败模式发生了转移：从"重复循环、卡死不动"变成了"过早的假成功"（模型以为做完了，其实没有）。

时间扩展更微妙：放宽最大步数确实减少了"撞到步数上限"的停滞，但任务成功率几乎没有提升。**更长的视野，往往只是让错误轨迹跑得更远而已。** 结构分解在本地两阶段 Agent 上引入了额外的规划和格式开销；并行扩展能部分缓解这些失败，代价却是高昂的计算成本。

### 论文三：裁判们的体检报告

OSReward 的评测结论带着一点残酷：即便是当前最强的 VLM 评委，也达不到"理想裁判"的标准，而且共享同一个系统性缺陷——**宽松偏差**，把失败的轨迹批量误标为成功。更麻烦的是，少数勉强可靠的评委贵得无法规模化使用，而便宜的开源模型又差得太远。

研究者给出的解法是开源生态：OS-Shepherd-100K 语料库（带推理标注的轨迹判定）+ OS-Shepherd 9B/35B 模型。后者的亮点在于，用比商业前沿评委低 30-60% 的成本，提供了稳定可靠的奖励信号——"够用且便宜"，恰好是规模化最需要的两个属性。

## 四、技术启示与发展方向

把三篇论文放在一起看，几条线索开始清晰起来。

**第一，"自我反思"的价值主张需要重新陈述。** 这类方法的论文几乎都用"超过单条 CoT"来证明自己，但那个比较本身就失真——因为反思方法天然烧掉更多 token。等成本对比一拉平，优势就消失了。这不是说反思毫无用处，而是说它的适用面比宣传的窄得多：至少在数学推理和 7B 以下的开源模型上，"多试几次数票"是更稳的性价比选择。这也给社区提了个醒：**以后报告任何推理时方法，不控制 token 成本的对比都该打问号。**

**第二，Agent 的失败模式应该成为设计输入。** 论文二最有价值的观察不是"扩展没用"，而是"扩展改变了失败的方式"——从停滞变成假成功。这意味着本地 Agent 的优化方向不是无脑加算力，而是做**选择性计算分配**（把算力投给真正需要的地方）和**失败感知控制**（识别"假成功"并干预）。算力堆不出可靠，机制才能。

**第三，评估者本身需要被评估。** 论文三揭示的宽松偏差，影响的远不止 CUA 领域——任何用 LLM-as-a-judge 的评估管线都可能带着同样的盲区。好消息是，开源奖励模型（OS-Shepherd）证明了"便宜+可靠"可以兼得，这类基础设施大概率会成为 Agent 训练与评估的公共品。

合起来看，三篇论文其实在讲同一件事的三个方面：**推理时计算的预算分配正在从"凭感觉"走向"讲证据"。** 方法层要算清 token 账，系统层要认清收益曲线，评估层要校准裁判本身。下一步值得关注的方向也很明确：成本感知的评估协议会成为新标准；失败模式驱动的 Agent 架构会越来越多；而开源评估基础设施，可能会像当年的开源数据集一样，成为整个生态的地基。

## 五、总结

这三篇论文没有带来新的 SOTA，也没有炫目的架构创新。它们做的是更朴素、也更稀缺的事情：**把流行的叙事放进成本核算里，看看哪些是真的，哪些只是账单。**

"反思比重复更聪明"被证伪了（至少在小模型和数学任务上）；"更多算力=更好 Agent"被画出了收益曲线；"大模型评委可信"被贴上了宽松偏差的标签。每一个结论都在提醒我们：当推理时计算成为新的军备竞赛，最先要搞清楚的，不是怎么花更多，而是花在哪。

这也留下一个开放的问题：随着模型规模继续变大，"自我选择"的劣势正在收窄（论文一里 7B 已接近持平），那到了 70B、700B 的尺度上，反思类方法会不会迎来翻身？到那时，今天的结论会不会也需要一次"等成本重测"？——或许这正是这个领域最健康的循环：**每一代结论，都值得被下一代用更严格的尺子重新量一遍。**
