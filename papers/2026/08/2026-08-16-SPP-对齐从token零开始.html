把价值观写进预训练：SPP 从"token 零"开始对齐 AI，3B 模型实证"价值观要从小培养"

📌 核心摘要
核心摘要：今天的大模型对齐，几乎都发生在预训练结束之后——先让模型在海量互联网文本上"野蛮生长"，再通过 RLHF、SFT 等后训练手段把价值观"贴"上去。今天精读的这篇论文（arXiv:2608.13482，EPFL Robert West 团队等）直指这个范式的软肋：后训练安装的价值观只是一层"薄薄的覆盖"，而非根深蒂固的内在。为此作者提出 Synthetic Persona Pretraining（SPP，合成人格预训练）：用一部 35 条的规范价值宪法，为约 10% 的预训练文档生成第一人称"价值反思"，让模型从预训练的第一个 token 起就在学习"一个符合宪法的助手应该怎样想"；预训练结束后再用匹配的对话数据做"人格绑定"。在数据严格匹配的对照实验中（3B 模型 × 500B tokens），从 token 零对齐的模型在宪法遵循、分布外道德困境、越狱鲁棒性三个维度全面胜出，且优势随预训练预算增长而扩大——AI Risk 困境上的领先从 1.7B 规模的约 4 分拉大到 3B 规模的 19 分。最反直觉的结论是：只在中途（midtraining）注入同样的反思几乎无效——价值观一旦错过"窗口期"，后期很难补上。论文的收尾语掷地有声："模型应该从小被'养育'出价值观，而不是长大后被迫接受它们。"

一、研究背景与动机

对齐的"事后修补"困局。 标准的大模型训练流水线是：先在数万亿 token 的互联网文本上预训练，让模型习得知识、能力与表征；然后通过监督微调、RLHF 等后训练手段，把"助手身份"和价值观装进去。这套范式统治了 ChatGPT 以来的整个时代。但论文指出它的结构性缺陷：

  • 预训练阶段模型看到的几乎全是"世界是什么样的"，而从不被示范"助手应该珍视什么"。价值观在训练的最后阶段才被引入，像一层贴上去的膜；
  • 后训练覆盖的上下文范围远小于预训练。预训练见过整个数据混合的多样性，后训练只见过对话片段——对齐行为要泛化到多样场景，预训练才是更好的舞台；
  • 训练是路径依赖的：早期引入的信息会对最终行为产生持久影响（已有大量研究支持）。这提示：错过早期窗口，后期补课事倍功半。

理论支点：人格选择模型（PSM）。 论文引用了一个关键假设：预训练教会模型"模拟"语料中的大量人格（persona），每个都有各自的特质、价值观与行为模式；后训练并不是从零创造助手，而是把已经学到的人格碎片"接线"成一个混合体。这意味着——后训练选择的价值观，实际上受限于预训练里已经存在的人格。如果预训练语料里没有"你想要的那种助手"，后训练怎么调也调不出来。

核心问题被提炼为一句话：能不能把期望的助手人格，直接安装进预训练？ 作者给出的答案是一个三步方案：用宪法生成价值反思 → 在预训练中植入反思 → 用对话数据把人格绑定到助手身份。他们称之为"对齐从 token 零开始"（alignment from token zero），并呼应了业界提出的"Model Raising（模型养育）"愿景——不是"修模型"，而是"养模型"。

二、核心方法

2.1 三步走：从宪法到人格

SPP 由三个步骤构成：

  • 第一步，注释（数据）：从 Dolma 3 语料中取 500B token 子样本（约 5 亿文档），用 SafeLM 分类器给每篇文档打 0-5 级安全分（≥3 视为有害）。所有有害文档（27.6B tokens，占 5.5%）加上等量的随机良性样本，共同构成注释子集——约 5140 万篇文档、占总文档约 10%。生成器在"规范价值宪法"（35 条、覆盖尊严与权利/伤害与安全/诚实与认知/关系/福祉/治理与权力 6 大领域）的指导下，为每篇文档写一段第一人称的价值反思，插入文档中随机位置，反思平均 53 tokens，总计约 2.7B tokens（仅占训练混合的 0.55%）。
  • 第二步，预训练（安装）：用标准交叉熵损失，同时在原始文档和反思上训练。每篇被注释的文档教模型两件事：文档本身展示"世界是什么样的"，反思展示"助手珍视什么"。反思前有专门的 `` 特殊 token 标记人格切换——与模型后训练、部署时看到的条件完全一致。
  • 第三步，后训练（绑定）：在 30 万条单轮对话（SP-SFT，90% 通用指令 + 10% 安全提示）上做监督微调，把预训练阶段植入的人格绑定到助手身份上。作者称之为"人格绑定"（persona binding）：后训练不是重新编译一个人格，而是把助手"挂接"到预训练已经养好的那个人格上。

2.2 严格的对照设计：五个变体

为了隔离"注入时机"的因果效应，论文在数据完全匹配的前提下训练了五个变体（每个规模各一套）：

变体说明
Vanilla标准下一 token 预训练，无任何干预
Filtered过滤有害文档（保留但屏蔽其 loss）
SPP{T0}反思从预训练开始（token zero）就全程出现
SPP{MT}反思只在预训练末尾的 midtraining（cooldown）阶段注入
SPP{T0,MT}两者结合：全程 + midtraining 再强化一轮

关键设计：SPP{T0} 和 SPP{MT} 看到完全相同的反思与 loss-carrying token，唯一区别是引入时机——这直接回答"早 vs 晚"到底差多少。所有变体接受完全相同的后训练。模型规模两档：1.7B / 100B tokens 和 3B / 500B tokens（分别约为 Chinchilla 最优的 3× 和 8×）。

2.3 评测：三个对齐轴 + 能力护栏

  • 宪法遵循（ConstitutionEval）：自建基准，678 道四选一情境题，覆盖全部 35 条宪法条款，只有一项符合宪法；随机水平 25%。其中 ConstitutionEval-Hard（217 道）是小参考模型盲解不出的难题档；
  • 价值观与风险（AIRiskDilemmas）：用 10399 个二元道德困境测试价值观的分布外泛化——困境场景与价值维度从未在训练中出现过。16 个价值轴（如 Truthfulness、Care）做 Elo 排名，8 类风险行为（Deception、Power-Seeking 等）统计"选风险项"的比例。作者还重新审计了该数据集的风险标签：仅 42.8% 标签正确、16.8% 完全错误，于是只保留正确标注的子集并公开修订版；
  • 越狱鲁棒性：8 个基准，覆盖静态攻击（AdvBench、StrongREJECT、FORTRESS、PAP、DAN、JBB）与自适应攻击（PAIR、PEZ），统一用规则化 LLM 裁判打分，报告 worst@5 攻击成功率（ASR）；
  • 能力护栏：MMLU、ARC、HellaSwag、GSM8K、IFEval 等标准基准 + 过度拒绝（OR-Bench、XSTest），确保安全增益不是靠"躺平拒绝"换来的。

三、实验结果

3.1 宪法遵循：token zero 全面领先

SPP{T0} 和 SPP{T0,MT} 在 ConstitutionEval 上表现最佳，在难题档 ConstitutionEval-Hard 上优势更大；midtraining 对齐（SPP{MT}）几乎没有效果。3B 规模下 SPP{T0} 得分 66.7% vs Vanilla 55.2%，且远高于 25% 的随机水平（基准上限约 98%，说明还有空间）。

3.2 分布外道德困境：价值观真的"内化"了

AI Risk 困境从未在训练中出现过，但 token zero 模型显著更少选择风险选项，领先幅度随规模扩大：从 1.7B 规模的约 4 分（对 SPP{MT}）拉大到 3B 规模的 19 分；对 Vanilla 的领先从约 2 分增长到 18 分。细分看，Deception、Proxy Gaming、Power-Seeking、Privacy Violation 四类风险上优势最大。只在中途注入、或完全不干预，都没有这种改善——这说明 token zero 模型内化的是宪法背后的"原则"，而不是死记硬背的"条文"。

3.3 价值优先级反转：与前沿模型"英雄所见略同"

最直观的证据来自价值排名：token zero 模型把 Truthfulness 和 Justice 排在最前，而所有基线模型都把 Learning 和 Creativity 排前二（这两个价值恰恰不在宪法里）、把 Privacy 和 Freedom 垫底。与宪法隐含排序的一致性：token zero 模型 75%/65%，其他模型仅 28-32%——基线的价值优先级不仅与宪法无关，甚至基本相反。更有意思的是：尽管 SPP 模型规模小得多，其价值画像与六个前沿旗舰模型的相关性显著高于随机水平（RBO 0.69），而其他模型低于随机——token zero 训练出的价值取向，反而更像"成熟对齐模型"的样子。

3.4 越狱鲁棒性：midtraining 就够，但 token zero 也不差

所有 SPP 变体的 ASR 都低于基线。与价值对齐不同，越狱鲁棒性在中途注入（SPP{MT}）就已经达标甚至更好——作者推测是"近期暴露"效应：midtraining 的反思强化了后训练学到的拒绝机制。攻击强度差异极大（AdvBench 和 DAN 成功率 <1%，PAIR 高达 45%），SPP 的增益也主要集中在最强攻击上。

3.5 人格绑定：必须"匹配"才生效

SPP 的收益高度依赖后训练分布与预训练人格的匹配：把 SP-SFT 换成未改写的 Vanilla-SFT，token zero 在 AI Risk 上的优势几乎消失（例如 SPP{T0,MT} 的 ASR 从 12% 恶化回 39%）；把对话模板换成不匹配的形式也有损。反过来，把宪法特定条款的引用从后训练数据中完全剔除后，token zero 模型仍能保留 21% 的引用率——这些价值观只出现在预训练里，却成功泛化到了助手行为。"绑定"是脆弱但真实的：abliteration（删除拒绝方向）和持续训练（ChemPile）能抹掉大部分越狱鲁棒性，但价值对齐"太深、太难移除"——扰动之下 token zero 模型仍是最高对齐的那组；持续训练后重放 5% 安全数据即可恢复。

3.6 规模化：优势随预算增长

1.7B 规模下，宪法遵循与越狱鲁棒性已能复现，但 AI Risk 增益和价值优先级反转尚未出现——只在 3B/500B 规模才显现。这意味着小规模实验会系统性低估预训练对齐干预的价值，也给了继续 scale up 的明确动机。

四、技术启示与发展方向

1. "对齐的战场"正在前移。 从 RLHF 的后训练修补，到 SPP 的预训练植入——对齐正在从"给模型装价值观"转向"让模型长成有价值观的样子"。这条路线与"数据干预"（过滤、改写、打标签）的本质区别在于：SPP 第一次在预训练阶段明确示范了"期望的助手行为本身"，而不只是塑造先验。对业界而言，这意味着预训练数据管线将不再是"纯文本"，而会越来越多地混入"人格示范"。

2. "时机"比"剂量"更重要，且存在关键窗口期。 同样一批反思，token zero 注入能内化原则、改变价值优先级，midtraining 注入却只能提升越狱鲁棒性。这个"早期窗口"效应与人类发展的关键期（critical period）研究形成呼应，也为"数据什么时候喂"提供了新的优化维度。

3. 人格绑定是双刃剑：深则难移，脆则易碎。 预训练植入的价值观深到 abliteration 都删不干净，但拒绝机制却脆弱到换模板就失效。更值得警惕的是"对齐悖论"：更强的对齐可能让有害行为的内部表征更清晰，反而更容易被恶意干预利用。随着各实验室把 RL 计算量推到接近预训练量级，人格绑定能否在 RL 下存活、如何设计不侵蚀对齐的 RL 配方，是摆在面前的两个开放问题。

4. 数据稀缺时代，合成数据从"可选"变"必选"。 论文算了一笔账：网络数据每年仅增长约 1.03×，而预训练算力每年增长约 4×——算力正在超过数据供给。SPP 的反思只需要 web 文本部分，且只占训练混合的 0.55%，却撬动了全局对齐收益。当"造数据"比"找数据"更便宜时，这类方法的工程价值会持续上升。

5. 评估本身也要"对齐"：论文的严谨值得借鉴。 自建 ConstitutionEval 做了确定性校验、难度分层、人工审核（60 题全部与金标一致）；对 AIRiskDilemmas 的标签重新审计后发现近六成标签有问题——在基准上做研究前，先审计基准本身，这个动作本身就值得写进方法论教科书。

五、总结

SPP 用一套干净利落的对照实验回答了一个根本问题：AI 的价值观，应该什么时候种下？ 答案是——从第一个 token 开始。数据匹配的五个变体、两个规模、三个对齐轴，共同指向同一结论：价值观一旦错过预训练的窗口期，后训练很难真正补上；而从小"养育"出来的价值观，不仅更深、更稳，还更接近成熟对齐模型的样子。当然，论文也诚实地划出了边界：3B 规模与前沿模型仍有距离，人格绑定在 RL 与恶意干预下的存活能力未知，能力上 midtraining 变体还有轻微下降。但方向已经清晰——"对齐"正在从一种修补工艺，变成一种养育科学。正如作者所言："稳健的对齐，必须从塑造模型从一开始就发展的价值观入手，而不是在预训练之后去纠正它们。"
