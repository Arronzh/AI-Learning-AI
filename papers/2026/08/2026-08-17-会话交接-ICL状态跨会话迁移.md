# 上下文窗口见底之后："会话交接"该带什么过界？信息论给 Agent 交接记录写下了答案

📌 **核心摘要**：任何一个用 LLM 做过正经应用的人，都撞过同一堵墙：上下文窗口满了、应用重启了、或者任务要交给另一个 Agent——新会话只拿到你"递过去"的东西。该递什么？现在的通行做法是让模型写一段总结，但**散文式摘要既可能丢掉约束（constraint），也可能丢掉证据（evidence），而这两样都可能改变后续的预测**。今天精读的这篇论文（arXiv:2608.14528，东京大学/RIKEN AIP 的 Masahiro Kato 等）把"会话交接"（session handover）正式化为一个信息论问题：交接记录是**任务相对 ICL 状态**的转移，判断标准不是"像不像原文"，而是"交接后的预测分布保没保住"。核心结果包括：预测充分性给出**最粗确定性充分交接**（等价类映射），只需要 ⌈log₂N⌉ 比特而不是完整复述；损失可以严格归因到**记忆预算、writer、续跑程序**三方；在"写记录时还不知道下游 query"的前提下，存在可量化的信息代价（1−B/m 比特 vs 查询后编码的 1 比特）。方法上论文给出一个可以直接落地的**三段式交接记录**：决策与约束原样保存、重复证据仅在"有显式误差保证"时才压缩、其余原始观测保留。高斯线性回归下交接可以做到**与样本量无关的有限维充分状态**，非参数回归则给出记忆–误差权衡与一个硬性的"记忆地板"（(B+1)^(−2β/d)）。

## 一、研究背景与动机

**"会话"是怎么断的？** 论文给的定义很朴素：一个 session 是共享同一批历史消息和工具结果的一系列模型调用；当上下文撞到输入上限、应用重启、或另一个 agent 被叫来接活时，任务就要跨过一条"会话边界"（session boundary）。新会话能看到的，只有应用主动传递的东西——**这就是交接记录（handover record）**，而负责写这份记录的程序被称为 **writer**。

**为什么不能直接"总结一下"？** 问题出在信息的类型上。前一个会话里有两类东西会影响后续行为：一类是**约束**——一个已做的决策排除了某些动作，一个被否掉的方案不能再提；另一类是**证据**——上下文里的示例会改变模型后续的预测。一段流畅的 prose summary 可能两头都漏。所以论文立下根本判据：**交接记录的好坏，不看它跟原对话像不像，而看交接之后的预测或动作对不对**。

**一个常被忽略的信息序差异。** 提示词压缩（prompt compression）通常是"看到 query 再压缩"，可以精准丢掉 query 用不到的信息；而交接 writer 在写下记录时，**通常还不知道下一个 query 或工具结果是什么**。论文把这种"先写记录、后见查询"的问题称为 **pre-query state-coding problem**，并指出它与 Wyner–Ziv 带边信息信源编码是同一个信息模式：writer 看到 (C,T)，解码端额外看到 X。这也是为什么交接记录必须为"一组可能的后续输入"保留信息，而不能像 query-aware 压缩那样只为一个输入服务。

**相关系统盘点。** 论文把现有手段逐一归位：compaction（提示词压缩）、persistent memory（持久记忆）、retrieval（检索/RAG）都能帮应用续跑，但都没有回答"下一个决策到底需要什么"。特别地，**KV cache 被明确排除在任务记录之外**——它只是注意力计算的运行时缓存，不显式承载任务目标、承诺或证据。而前一个会话里生成的**文件、数据库（external records）**虽然不在首个提示词里，只要新会话还能读，就必须计入"保留内存"的账——**短 prompt 不等于小内存**。

## 二、核心方法

### 2.1 形式化：把交接写成"任务相对 ICL 状态"的转移

论文用一个 episode ω=(C,T,X,Y) 框定问题：C 是交接前的会话内容（对话、指令、示例、工具结果），T 是 writer 写记录时已知的任务信息（目标形式、评分规则），X 是边界之后才到来的查询或任务状态观测，Y 是用于评分的答案。writer 在观测 (C,T) 后产出 H=(V,M)：**V 是放进新会话首个提示词的记录，M 是外部文件/索引/归档**。两个预算必须分开报：b_act(V)（首个提示词大小）和 b_tot(V,M)（总保留内存）——一个方法完全可以用"短提示词 + 越长越大的外部文件"来作弊。

接着论文把三个常被混为一谈的问题拆开：

- **精确恢复（exact recovery）**：能否从 (H,T) 还原出某个原始条目——这是最强条件，大多数任务并不需要；
- **预测充分性（predictive sufficiency）**：P(Y|C,X,T) = P(Y|H,X,T)——**交接后目标的分布没变**，这是论文定义的"任务保住"；
- **下游行为**：固定的续跑程序拿到记录后实际表现如何，只能从任务结果上评估。

精确恢复 ⇒ 预测充分 ⇒ 决策风险相等，但反过来都不成立——**能复述原文不等于任务成功，任务成功也不需要复述原文**。

### 2.2 理论核心：最粗充分状态、比特下界与损失归因

**等价类定义状态。** 在外生性条件下（给定任务，后续输入 X 的分布不依赖具体上下文 C），两个上下文 c 和 c′ 只要对 μt-几乎所有的后续输入给出相同的 Y 分布，就属于同一个"任务相对 ICL 状态"等价类 [c]∼t。**Proposition 3.1** 给出核心刻画：预测充分 ⇔ writer 不把不同等价类合并；而等价类映射 q_t(c)=[c]∼t 就是**最粗的确定性充分交接**——它能从任何其他充分交接中恢复出来。**Corollary 3.2** 顺势给出定长编码下界：N_t 个状态至少需要 ⌈log₂N_t⌉ 比特。这就是"任务特定记忆可以远短于完整重建"的理论依据：**交接只需区分会导致不同 Y 分布的上下文，为复述原文而存在的区分可以全部丢弃**。

**损失归因三分（论文 Eq. 21）。** 设 R*_full 是拿着完整上下文能达到的最优风险，则任意交接方案的超额风险可以写成三项之和：

> R(E,Dθ) − R*_full = (R*_B − R*_full) + (R*_E − R*_B) + (R(E,Dθ) − R*_E)

依次是：**① 记忆预算 B 造成的不可避免损失；② 所选 writer 的额外损失；③ 续跑程序相对理想解码器的差距**。"信息没给够"和"信息给了但没用对"，第一次被严格分开。在 log-loss 下还有精确恒等式：R*_log(H) − R*_log(C) = I(Y; C|H,X,T)，即**被交接丢弃的任务信息恰好等于一个条件互信息**；有限动作空间的决策损失则被它控制（≤ L_max·√(MI/2)）。

**"写在前面的代价"（Proposition 3.6）。** 论文用一个极简例子量化信息序的代价：C 是 m 个独立 Bernoulli(1/2) 位，X 在 {1,…,m} 上均匀取值，Y=C_X。若编码器先看到 C、后看到 X，B 比特预算下贝叶斯 log-loss 至少是 max{0, 1−B/m} 比特；而看到 (C,X) 再编码的压缩器只需 1 比特、零损失。**这就是"交接记录"与"查询后压缩"之间的信息论差价**——前者必须为整个查询分布保留信息，后者只需要为那一个查询花钱。

### 2.3 方法：三段式交接记录

基于上述理论，论文提出一个可直接落地的记录结构 **H = (H_exact, H_stat, H_residual)**：

- **H_exact（精确区）**：当前目标、已生效的决策、被否决的选项、未决问题，连同每一条的来源。必须**原样保存**——把一个"已采纳的决策"改写成"建议"，或把一个"未决问题"写成"已定结论"，都会改变后续允许的动作集合；
- **H_stat（统计区）**：重复出现的示例或工具结果，**只有在任务提供了显式保证或误差界时**（充分统计量、或带误差界的近似）才允许用更短的量替换；
- **H_residual（残差区）**：统计量无法覆盖的原始观测——一个罕见示例或一次具体失败，可能比任何聚合量都更决定下一步。

配套的工程约束：writer 在边界处做确定性检查（字段、数值维度、引用、总大小）；序列化过程（四舍五入、丢字段、加计算值）也被视为 writer 的一部分并计入预算；残差观测可以以"标识符 + 外部存储"的形式留在 V 之外，但两边大小都要入账。

## 三、实验结果：两个可解模型的精确刻画

作为理论论文，它没有跑基准，而是在两个回归模型上把上面的抽象结果算到了"闭式解"的精度——这本身就是它的实验。

### 3.1 参数化回归：有限维充分状态（与样本量无关）

高斯线性回归 y = xᵀβ + ε（方差已知，高斯先验）下，后验预测分布只通过 **(G_n, b_n) = (XᵀX, Xᵀy)** 依赖数据。**Theorem 5.1**：这个记录对任意后续输入 x 预测充分，条件互信息严格为 0——**无论前面积累了多少条示例，交接只需 d(d+1)/2 + d 个实数**，维度与 n 无关。

两个漂亮推论：

- **合成充分示范**：对 G_n 做特征分解，可以构造出 (X̃, ỹ) 使 X̃ᵀX̃ = G_n、X̃ᵀỹ = b_n——即**用"示例格式"而非"矩阵格式"表达同一个充分状态**。两种表示信息等价，固定续跑程序下任何表现差异都只能归因于数值精度或解析问题，而不是信息缺失；
- **有限精度量化**（Theorem 5.3 / Corollary 5.6）：统计量量化后的协方差/均值扰动有显式上界（‖V̄−V‖ ≤ δ_G/(σ²α²) 等），预测 KL 散度按 **K·2^(−2(B−B₀)/p)** 随比特数指数衰减——**每个参数每多 1 比特，误差按指数律收缩**。

### 3.2 非参数回归：记忆–误差权衡与"记忆地板"

Hölder β 光滑、d 维输入的函数类里，固定维度的统计量不可能表示所有函数。writer 的做法是**格子统计**：把 [0,1]^d 切成 M=m^d 个格子，每格只存 (N_j, S_j)——计数与响应和。**Theorem 5.7** 把风险拆成四项：C₁M^(−2β/d)（格内近似误差）+ C₂M/n（抽样波动）+ C₃exp(−np_min/M)（空格代价）+ C₄q²（量化误差）。最优取 M ≍ n^(d/(2β+d)) 时，**达到全数据 minimax 率 n^(−2β/(2β+d))**——也就是说，对这类任务，恰当的交接记录在统计效率上"零损耗"，且比特预算只需 B_n = O(n^(d/(2β+d))·log n)。

更关键的是**下界**（Theorem 5.10）：

> R_n,B ≥ c · max{ n^(−2β/(2β+d)), (B+1)^(−2β/d) }

第二项就是"**记忆地板**"：交接记录总共只有 2^B 种可能，误差就不可能低于 (B+1)^(−2β/d)。合起来看：**交接所需的内存由目标精度与函数类决定，而不只是样本量**——参数化任务可以有限维，非参数任务必须随精度增长。当预算低于无约束最优选择时，内存是紧约束；一旦预算够用，多出来的比特不该乱花（继续细分格子只会增加方差）。

### 3.3 评估方法学：理想解码器校准

**Proposition 6.1 / Corollary 6.2** 给出记录比较的纪律：若 H₂ = s(H₁,T)，则 R*(H₂) ≤ R*(H₁)；若两个表示互相确定，则理想风险相等——此时固定续跑程序下的任何差异都归因于"程序与理想解码器的差距"，**不许甩锅给"信息缺失"**。反过来，比较任意两个摘要而不说明 writer 知道什么、后续输入分布是什么、序列化怎么做的，就无法识别任何理论量。这对当下"记忆评测"满天飞的局面是一个方法论提醒。

## 四、技术启示与发展方向

**1. "交接"应该成为 Agent 架构的一等公民。** 上下文压缩、持久记忆、RAG、compaction 长期各自为战，论文用"任务相对 ICL 状态"这个锚点把它们统一进同一个框架：边界事件、信息载体、任务状态三分离。对工程实践最直接的落点是：**决策与约束必须原样保留，禁止让摘要模型"润色"它们**——把已定决策、被否选项、未决问题单独成区、逐条带来源，这条规则今天就能写进任何 Agent 的 prompt 模板。

**2. 短 prompt 是假象，记忆账本要算全。** 把信息挪进文件/数据库只是改变了记账科目，没有减少总内存；评估任何交接/记忆方案都必须同时报告 b_act 和 b_tot。KV cache 不算任务记录——这个澄清能省掉大量无谓的争论。

**3. "先总结后查询"有可量化的信息税。** max{0, 1−B/m} 的代价说明：只要 writer 必须在看到 query 前落笔，就必然要为"可能的查询分布"多付信息成本。这给 Agent 设计一个反直觉的提示：**能延迟的总结尽量延迟**，把压缩放到 query 到达之后（query-aware），信息效率完全不同。

**4. 拉长上下文没有消除交接，只是推迟了它。** 窗口内的 compaction 与跨会话的 handover 是同一枚硬币的两面；这篇论文的等价类与比特下界，同样适用于"窗口内该驱逐什么"。随着上下文长度军备竞赛放缓，**"如何在有限记忆里保住任务状态"会取代"窗口有多长"成为新的竞争维度**。

**5. 开放问题。** 自由行动的 agent 会改变后续观测，预测充分性需要升级为轨迹级损失；边界之后若仓库、规则或运行时发生变化，"先前证据是否仍然有效"必须作为独立状态变量跟踪；未知噪声方差、更高光滑度与内在低维结构，论文都给出了扩展方向但尚未闭合。

## 五、总结

这篇论文做了一件稀缺的事：**给"会话交接"这个所有 LLM 应用开发者都撞过的墙，立起了第一块理论基石**。它用统计充分性与信息论回答了三个问题：交接必须保什么（预测充分性，而非文本复述）、最少要多少内存（⌈log₂N⌉ 比特，或非参数下的 (B+1)^(−2β/d) 地板）、损失该算在谁头上（预算 / writer / 续跑程序三分归因）。方法上，三段式记录（精确决策 + 有保证的统计量 + 残差观测）朴素到可以直接落地，却每一项都有定理背书。当然，边界也很清楚：理论建立在"干净恢复"假设上，真实世界的环境漂移、轨迹反馈、多模态证据都还没有闭合；高斯与非参数回归只是两个可解的特例。但方向已经明确——**当"记什么、丢什么"从经验手艺变成可证明的工程，Agent 的长任务能力才真正有了地基**。
