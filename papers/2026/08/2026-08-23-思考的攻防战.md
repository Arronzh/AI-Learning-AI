# 思考的攻防战：隐藏思维链能被逐字偷走，模型也学会了"想多久自己定"

📌 **核心摘要**：推理模型的"内心独白"——隐藏思维链（hidden CoT）——正在同时成为攻防焦点与成本焦点。一边，CISPA 团队提出的 **EchoCoT** 攻击发现，工具调用之间藏着一道此前被忽视的"推理回放面"：利用它，攻击者只需通过 API 交互，就能从黑盒模型中**近逐字**提取隐藏思维链——开源模型上提取成功率最高 66.4%，同一注入轨迹跨数据集泛化后最高 80%，甚至能从 Gemini-2.5 中挖出 33,463 token 的完整思考轨迹，还顺带泄露了 o4-mini 的系统提示词。另一边，阿姆斯特丹自由大学提出 **Learning When to Think**：让模型在回答的第一个 token 就自主选择 NoThink / Short / Long 三种思考模式，用 GRPO 端到端学会"该想多久想多久"，在 MATH500 上准确率几乎不掉（0.782 vs 0.796）的同时，把平均思考长度砍掉 **41%**，在 GSM8K 上更是省下 **76%** 的 token。思考既是该守的资产，也是该省的成本——这是推理模型时代的一体两面。

## 一、研究背景与动机

先看一个有点反直觉的现状。推理模型（LRM）面对一个问题时，会先生成一段长长的思维链（CoT），再给出最终答案。这段"内心独白"里藏着逐步计算、探索过的替代方案、失败的尝试和自我修正——信息量远大于最终答案。

正因为如此，隐藏 CoT 被各家视为核心资产：它是训练监督和模型蒸馏的富矿，也是诊断模型、监控不安全或欺骗行为的窗口。OpenAI、Anthropic 等前沿厂商对内部 CoT 严防死守，绝不让它暴露给用户。

但一个此前被严重忽视的问题是：**这些隐藏思维链本身，能不能被偷走？** 过去的隐私研究大多在问"从 CoT 里能推断出用户的什么敏感信息"，几乎没有人认真问过"CoT 本身能否被原样恢复"。已有的两次尝试都不完美：REP 用 few-shot 提示让模型复述推理，但不验证是否逐字一致；更近的 Stolen Thoughts 靠重放厂商返回的加密推理块，依赖特定架构特性——而且据论文所述，2026 年 8 月厂商修复后该攻击已不可复现。

与此同时，还有另一场关于思考的战争在成本侧打响。用强化学习训练的推理模型，通常在一个**固定 token 预算**下运行：简单题被逼着长篇大论，难题却常常想得不够。时间折扣（对长序列施加统一惩罚）能压缩推理，但它不区分题目难度——简单题和难题被同等对待，而它们需要的思考预算明明天差地别。

两个问题，同一深层结构：**思考是一种需要被管理的资源**。一边要防它泄露，一边要防它浪费。

## 二、核心方法

### EchoCoT：工具调用之间的"推理回放面"

EchoCoT 最锋利的洞察，来自一个被所有人忽略的工程细节。在普通多轮对话中，隐藏 CoT 在每轮结束就会被丢弃；**但工具调用是个例外——它会在单轮内保留隐藏 CoT**。这一保留，就形成了一道"回放面"：攻击者可以利用它，让模型回忆并复述自己的思考过程。

具体攻击分三步走。第一步，攻击者把目标问题连同工具调用请求一起发给模型，模型在调用工具前会产生一段包含核心推理的 CoT。第二步，通过一个 scratchpad 工具反复注入指令，逐步诱使模型吐出越来越完整的思维链。第三步，因为攻击者看不到真正的目标 CoT，就用 API 返回的**代理信号**来估计保真度——报告中的推理 token 数、可选的压缩 CoT 摘要——据此设计长度级和文本级保真度分数，指导下一轮注入该往哪个方向使劲。

为了不靠手工设计提示词，作者还搭了一个 LLM 优化框架，用 Inject-Reflect-Distill 的工作流自动搜索对每个目标模型有效的"通用注入轨迹"，并区分了只用长度信号的 LGO 和长度+文本双信号的 LTGO 两种优化目标。

### Learning When to Think：把"思考预算"变成模型自己的决定

这篇论文的思路更直接：既然外部统一预算不合理，那就**让模型自己决定想多久**。模型的响应以三个路由 token 之一开头——NoThink（尽快作答）、Short（简短推理）、Long（深度推理）——然后整个生成都在该模式的约束下进行。路由 token 是主策略的一部分，端到端由 GRPO 训练，没有独立的路由器。

要让三个模式真正"各司其职"，作者用了三个关键设计。一是**按模式塑形的奖励**：每个模式有自己的基础奖励和折扣，把统一的长度惩罚拆成按模式的激励——简短作答在短长度上划算，深度推理在长长度上划算。二是**硬性 token 上限**：模式之间由构造保证互不相同，路由标签不会和行为脱钩。三是**平衡项**：类似 MoE 中防止专家坍缩的负载均衡惩罚，直接加进 advantage，避免策略收敛到单一模式。训练时还安排了预热阶段，先强制各模式各跑一部分 rollout，再放开自由选择。

## 三、实验结果

### EchoCoT：近逐字的"思考窃听"

在 DeepSeek、Qwen、GLM 三个开源推理模型上，EchoCoT 交出了相当惊人的数字：ASR@99（提取轨迹长度误差 ≤1% 且 99% token 完全匹配）达到 22.8%–46.1%，ASR@90 达到 30.8%–66.4%。同一注入轨迹还能迁移到未见过的数据集——在 MATH500、JEEBench、LiveCodeBench 上 ASR@90 最高冲到 80%。长度上，超过 20K token 的轨迹也能完整提取。

闭源前沿模型同样失守。Gemini-3.5 上提取出 17,645 token（目标 18,119），Gemini-2.5 上更是提取出 33,463 token（目标 32,948）——和厂商自己报告的推理长度几乎一致。大量提取结果与厂商提供的 CoT 摘要在语义上高度对齐。还有一个意外收获：在 o4-mini 的一次案例中，攻击泄露了系统提示词内容——泄露面可能比思维链本身更大。

有一个细节值得注意：带工具调用请求的最终答案与原始答案一致性高达 84.2%–93.0%，说明提取出来的确实保留了解决该问题的核心推理链，不是模型现编的。

### Learning When to Think：41% 的思考瘦身

在 1.5B 蒸馏模型、MATH 数据集上的训练中，三个模式**没有坍缩**，稳定涌现。更有意思的是，简短模式最终比 Long 模式更准——这说明路由 token 确实在按题目难度分流，而不是随机乱选。

量化结果干净利落：MATH500 上准确率 0.782，基线的固定预算模型是 0.796，几乎无损；但平均响应长度从 4,796 token 降到 2,811 token，**缩减 41%**。迁移性同样亮眼——不用重新训练，直接换到 GSM8K 上就省了 76% 的 token，而且在相同响应长度下准确率还高于基线。作者还做了一个精巧的验证：训练后期把平衡项退火到 0，路由分配依然稳定，证明模式分流是校准到难度上的，而不是被正则项硬撑着的。

## 四、技术启示与发展方向

1. **"看不见"不等于"安全"**。隐藏 CoT 之所以能被偷，不是因为加密被破，而是因为工具调用这个正常功能本身成了回放面。推理模型的攻击面，正在从提示词注入扩展到"功能即漏洞"。
2. **防御没有银弹**。EchoCoT 的防御实验很有说服力：系统提示词防御能把 ASR@90 从 46% 压到 5%，但攻击者自适应重新优化后又能回到 29%；只删掉推理 token 计数，自适应攻击下照样反弹到 30.3%。唯一根治的办法是把推理状态本身移除（ASR 直接归零）——但这对模型厂商意味着架构级改动。多层防御不是选项，是必须。
3. **思考预算的"元认知"时代**。让模型自己决定想多久，比外部路由器更优雅：端到端、零额外推理开销、还能跨基准迁移。这可能是测试时计算优化的下一个主流方向——从"花多少算力"进化到"让模型知道该花多少"。
4. **Agent 化放大了两面风险**。工具调用是 EchoCoT 的攻击面，而 Agent 恰恰是工具调用最密集的场景。未来推理模型接入的工具越多，"回放面"就越大；同时 Agent 的推理成本也在随工具链膨胀，自适应思考的收益也会更大。攻防与省钱，在同一趋势下同步升级。
5. **一个值得追问的张力**：如果模型学会了"少想"，隐藏思维链会变得更稀缺还是更珍贵？当 NoThink 模式被广泛采用，那些仍然保留的长思维链，恐怕会成为更诱人的攻击目标。

## 五、总结

两篇论文，一篇在偷思考，一篇在省思考。EchoCoT 提醒我们，推理模型最值钱的部分——那些被厂商锁在内部的"内心独白"——可能正通过一扇没人注意的窗户被原样搬走；Learning When to Think 则展示，思考本身也可以被精算，让模型在准确率和 token 之间找到自己的平衡点。当"思考"既能被窃取、又能被定价，它就已经从模型的一个内部属性，变成了一个需要攻防、需要核算的公共议题。这场关于思考的战争，才刚刚开始。
