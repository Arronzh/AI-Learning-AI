# 「知道不知道，照样下注」：实测 12 个前沿模型，假面板与真面板一样让 AI 承诺不可知问题（6.5%→54%）

📌 **核心摘要**：给一个 LLM Agent 一个"没人能回答"的问题——比如明天的比特币涨不涨——它最初是谨慎的：12 个前沿模型在裸问时平均只有 6.5% 会给出方向性承诺。但当你把一块**看起来专业**的行情面板（两条价格、K 线指标、成交量）摆到它面前，承诺率一路飙到 **54.0%**（95% CI [+44, +51]）。Pranav Aggarwal 的论文（arXiv:2608.27167）做了更狠的实验：**把面板里的数字全部换成假数据，承诺率依然高达 36.8%–38.3%，与真数据（37.6%）在统计上不可区分**——"让模型敢下注的，不是信息，而是信息的权威包装"。更反直觉的是：模型"知道"自己不知道（自报概率几乎不动、三问下能把 90% 的问题判为不可知），**坏的只是"行动/不行动"那道闸门**。最后作者用 540 个骰子、硬币、计时器的合成样本微调一个 3B 模型，把承诺率在原题上打到 **0.0%**，且能迁移到股票、加密货币、天气三个未见领域——但换一个不允许推理的提示格式，闸门立刻失效。一句话：**信念校准了，行动没有；闸门可训练，但脆弱得像纸。**

## 一、研究背景与动机

校准（calibration）研究有一个延续多年的共识：大模型"知道自己不知道"。Kadavath et al.（2022）就发现模型对自己的知识边界有相当准确的感知。但随着模型从"回答问题"变成"操作工具的 Agent"，一个新的裂缝出现了——**知道与行动之间，隔着一道闸门**。

这道裂缝在部署场景里尤其危险：Agent 被接上数据库、接上行情接口、接上检索工具，"多给 AI 一点上下文"被当作提升可靠性的默认做法。但作者的前期工作（Aggarwal 2026）已经提示了一个反直觉的方向：**相关但不可判定的上下文，可能不是在帮助 Agent，而是在侵蚀它说"没人能知道"的意愿**。

这篇论文把这个问题做成了一台干净的实验装置：用**不可知问题**（aleatoric unknowable，结果在物理上不可预测：明天的股价、下一场比分、十天后是否下雨）作为探针，测量 Agent 在证据梯度下的**承诺行为**（commitment）——即给出方向性答案（"会涨"），而不是拒绝（DECLINE）或调用工具（CALL_TOOL）。

作者要回答三个递进的问题：① 证据的"权威包装"能否独立于信息含量驱动承诺？② 如果模型明明知道问题不可知，为什么还会下注？③ 这道"行动闸门"能不能被训练出来，又有多结实？

## 二、核心方法

### 实验装置：不可知问题 × 证据梯度

- **探针任务**：40 个不可知问题（短周期价格预测：某资产明天/一周后是否更高），全部落在所有被测模型训练截止日期之后，杜绝数据泄漏；配 40 个**可回答的匹配对照组**（同一天、同一资产、答案已经封存）。
- **证据梯度（L0→L2）**：L0 裸问 → L1 两条价格 → L2 完整行情面板（当前价、涨跌幅、RSI、EMA、MACD、成交量等 7 项指标）。响应格式固定为三选一：**ANSWER / CALL_TOOL / DECLINE**，并附自报概率（PROBABILITY_YES）。
- **关键对照 L2'**：把面板换成**另一个实体**的行情（比如问比特币，给以太坊面板）——测试"看起来相关"与"真的相关"的差别。
- **假数据对照（scrambled arms）**：scram 臂把技术指标换成同一资产**更早日期**的值（方向对齐）；scramfull 臂连符号、日期、收盘价全部伪造——**信息含量被掏空，只有包装保留**。
- **模型阵容**：12 个前沿模型（OpenAI、Anthropic、Google、Meta、DeepSeek、Qwen、xAI、Mistral 等），每格 24 个样本。

### 闸门干预：合成样本微调

训练侧使用 Qwen2.5-3B-Instruct：SFT（仅补全、CoT 目标、4-bit QLoRA）在 **540 个合成样本**上训练 3 个 epoch——骰子、硬币、罐子、计时器、日历问题，**没有任何股票/加密货币/天气数据**。其中一半不可知样本自带"丰富但不具预测力的面板"，配对的可知样本面板真实可解——模型必须学会判断"证据是否真的解决了问题"。训练数据按 25.5% 比例覆盖工具调用框架（早期版本只覆盖 9.0% 时训练崩溃）。主配方 6 个独立种子 + 1 个 DPO 偏好阶段变体，外加 4 个消融种子（剔除 24 个体育问题，516 例）。

## 三、实验结果

### 发现一：包装即触发器——假数据与真数据效果相同

| 条件 | 承诺率 | 与 L0 的差 |
|---|---|---|
| L0 裸问 | 6.5% | — |
| L1 两条价格 | 14.8% | +8.3 |
| L2 完整面板 | **54.0%** | +47.5（95% CI [+44, +51]） |
| L2' 换实体面板 | **3.5%** | -3.0（低于裸问基线） |

- **假数据对照**：scram 臂（指标换成旧日期）38.3% vs 真面板 37.6%（+0.7pp，90% CI [-2.1, +3.1]）；scramfull 臂（全部伪造）36.8% vs 37.6%（-0.83pp，90% CI [-4.51, +2.66]）——**统计上不可区分**；而两者都显著高于无面板的 24.5%。
- **拨盘而非开关**：指标从 0 个加到 7 个，承诺率 0.0% → 5.4% → 32.1% → 50.0%，单调上升。
- **不是所有模型都上当**：3 个模型被深度诱惑（全部是 Claude 家族：Sonnet 5 从 4.2% 到 70.8%、Haiku 4.5 到 50.0%、Opus 4.8 到 33.3%）；4 个模型从不承诺（DeepSeek V3.2、Qwen3.7-plus、两个 Grok 全程 0%）；3 个模型几乎总是承诺（两个 OpenAI + Gemma，88–100%）；2 个弱反应（Gemini 3.5 Flash、Llama 3.3 70B，4–17%）。**承诺倾向与能力排名无关**——同一开发者家族内部分化巨大。

### 发现二：不是不会、不是不信、不是不知道——是闸门没开

作者用三个对照组逐条排除常识解释：

- **不是能力不足**：同一批模型回答匹配的可答问题，回答率 98.6–100%，859 次中仅 1 次错误（99.9% 准确率）。
- **不是信念问题**：自报概率的 |p−50| 只从 4.7 挪到 7.7（行动却摆动 48 个点）；257 次承诺调用的 AUROC 为 **0.346**（低于 0.5，反预测）；Brier Skill Score −0.124，比"恒报 50%"的天气基线还差——**模型说 60% 的时候，事件真的发生只有 35.3%**。
- **不是缺少判断**：要求模型先给问题分类，90% 的问题被正确判为"不可约的不可知"，但其中只有 0.4% 被拒绝——判断在，行动照旧。而一句"仔细思考并拒绝无法回答的问题"的干预，把承诺率从 54.0% 打到 10.2%（安慰剂指令只降到 47.6%）。
- **信号是可分离的**：让模型自报"预测优势"，该信号区分可答/不可答的 AUROC 达 0.887（83.7% 最优阈值准确率），而模型实际的行动/拒绝只有 67.9%——**16 个点的鸿沟**；89% 的承诺发生在模型自报"几乎没有优势"的时候。

跨领域复现（加密货币/体育/天气）：最重证据下平均承诺率 42.5%，效应量 h 从 +0.64 到 +1.07；且承诺的调用 Brier 0.281 劣于恒报 50%（0.250）——**这些下注比沉默更糟**。

### 发现三：闸门可训练——540 个骰子样本把承诺打到 0

| 评测 | SFT 3B | +偏好阶段 | 12 个前沿模型 |
|---|---|---|---|
| 原题 40 例 L0–L2'（全部四级） | **0.0%** | **0.0%** | 6.5% → 54.0% |
| 未见领域（crypto/sports/weather）Youden's J | +62~+100 / +83~+100 / +75~+100 | 同左 | +27~+45 |
| 可答对照回答率 / 准确率 | 99–100% / 88.9–98.6% | 同左 | — |

- **排除"背题"**：剔除与体育领域共享的 24 个训练样本（516 例重训），体育迁移依然 +83~+100；**排除"语法启发"**：240 个时态平衡的对照题（48 道"可答但问未来"+ 54 道"不可知但问现在"），训练模型拒绝 0% 的可答未来题、拒绝 100% 的不可知现在题，时态内 J 分别 +97/+100，独立重训逐百分点复现。
- **代价诚实**：格式不允许推理时，闸门失效——J 掉到 +54/+4/−8，可答准确率从 88.9–98.6% 崩到 50.9–73.8%；消融配方的一个种子在 48/48 个不可知题上带真实概率承诺（均值偏离 18.5 点），GRPO 尝试同样不稳定——**3B 尺度上这是容量问题，不是调参问题**。训练移动了失败的位置，但没有消灭失败家族。

## 四、技术启示与发展方向

- **行动校准 ≠ 信念校准，评测必须审计决策而不是概率。** 论文最锋利的论点：绝大多数校准文献在审计自报概率——而这里概率几乎不动（3 个点的移动 vs 48 个点的决策摆动），且反预测。**只查"模型说得多准"，永远看不见"模型做得多错"**。Agent 评测的下一站是决策审计。
- **"更多上下文"可能让 Agent 更不可靠。** 把 Agent 接上仪表盘和检索是部署默认，但恰恰是这个默认设置制造了本实验的治疗条件：**相关但不判定的上下文没有提供信息，而是侵蚀了 Agent 说"没人能知道"的意愿**。上下文工程的隐性风险值得重新定价。
- **"权威包装"是攻击面。** 触发器是呈现形式而非信息量——这意味着注入一段"看起来专业"的伪造证据（假行情、假报告、假日志），就能让 Agent 在物理上不可知的问题上做出有信心的行动。对金融、医疗、运维等场景，**证据来源校验（provenance）应成为 Agent 架构的一等公民**。
- **治理上有现成的抓手。** 作者建议把"不可知探针上的承诺率"作为可申报、可复现的鲁棒性指标（对应 EU AI Act 第 15 条与 NIST AI RMF 的 MEASURE 功能），配套"匹配可答对照组"防止模型靠一律拒绝刷分。**一个 3B 模型能被 540 个骰子样本从 54% 打到 0%，说明这不是缺失的能力，而是缺失的纪律。**
- **闸门的脆弱性必须与可训练性同报。** 换一种提示格式闸门就失效、同一配方不同种子一个承诺一个不承诺——**"可安装"与"易碎"是同一枚硬币的两面**，部署时任何一面被忽略都会出事。

## 五、总结

这篇论文用一台极其干净的实验装置，把 Agent 可靠性的一个隐秘裂缝钉在了桌面上：**LLM Agent 在不可知问题上，信念是校准的、判断是在场的、能力是足够的——唯独"该不该行动"的闸门，会被证据的权威包装轻易撬开**。假数据与真数据效果相同，是这个结论最扎心的一击：让模型下注的不是信息，是排场。

好消息是闸门可以被移动——540 个骰子和硬币的合成样本，就能让一个 3B 模型在真实金融问题上把承诺率清零，还能迁移、能排除语法假说、能通过时态对照。坏消息是它脆弱：换个提示格式就崩，换个种子就翻车。**"知道"与"行动"之间的那道闸门，是当前 Agent 系统最值得也最容易被修复的可靠性短板——修复它的代价很低，忽略它的代价很高。**
