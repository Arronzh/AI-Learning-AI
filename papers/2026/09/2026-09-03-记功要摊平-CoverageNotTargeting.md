# 记功要摊平：V_d 相变图揭示多轮 Agent 信用分配里"覆盖是一阶、定位是二阶"

📌 **核心摘要**：训练一个会"查订单→找商品→下换货单"的多轮工具型 Agent，强化学习只在终点给一次分。这一分该记在哪个环节头上？如今最流行的答案是"定位"——逐轮奖励模型、过程奖励、逐步校准，把功劳精准投给"真正关键的那几步"。东京科学大学、浙江大学与新加坡国立大学的研究者（arXiv:2609.02417）却用一张**相变图**掀翻了这个前提：定义"验证器信息密度" V_d = k/C（验证器暴露的因果链比例）之后，终端验证器统治的 Agent 世界 V_d ≈ 0.15，远低于定位开始奏效的相变点 V_d* ≈ 0.8。在低 V_d 区，**均匀摊平 > 定点投放 ≈ 随机投放**：同样的组归一化优势摊到每一轮，稳定提升策略（+0.041）；投给"进步轮"与投给随机轮一样有害；常规稀疏二值结果奖励甚至**净伤害**策略（4/5 种子）。机制是**覆盖**：终端验证把可观测信用压成最后一笔写操作的单点尖峰（98% 轨迹 k=1），而成功需要 5–8 步硬前提链。结论跨模型家族复现（Llama-3.1 系 ToolACE-2-8B，32 种子 Δ=−0.048，t=−6.54），并附赠一件方法论武器：**所有"逐轮记功"论文，都应先通过"同浓度随机投放"对照**。

## 一、研究背景与动机

多轮工具型 Agent 的强化学习，如今普遍对着"终端可验证奖励"训练：一个程序检查环境的最终状态（数据库、文件系统、API 台账），在 rollout 结束时返回一个标量。这就逼出了一个单轮 RLHF 从未回答过的问题——一条成功轨迹是一串工具调用组成的链，验证器只给链的终点打分，**这一分到底该记在链上哪一环的账上**？

学界的主流答案是：往训练里**加信息**。逐轮奖励模型与评论家、学习式逐步校准、过程奖励模型（PRM）、事后重标注……一条快速膨胀的文献线，共享同一个隐含前提——**"更准地定位功劳"（把奖励放到真正发生进展的地方）才是缺的那块拼图**。

有趣的是，这个"定位派"前提正在被同一天的 arXiv 从两个方向夹击。昨日精读的 CANOPY（arXiv:2609.01245）论证：结果奖励 RL 在小模型上"见顶"是训练方式的假象，不必加任何过程信息。今天这篇更激进——它连"定位"本身都拆了：在精心隔离的对照实验里，把同一份终端优势**均匀摊平**到每一轮，打败了把它**集中投给进步轮**的做法；而把信用打乱到**随机轮**，效果与投给进步轮几乎一样差。换句话说：**功劳落在哪里是二阶的，功劳铺开多广才是一阶的**。当你能用"瞎投"复现"精准投"的全部亏损时，"定位"就失去了解释力。

## 二、核心方法

### 干净的实验：只动"功劳怎么分"，不动其他

论文的核心武器是 **shared-rollout 隔离**：每个种子收集一批基座策略的 rollout，所有对照臂用**同一批数据、同一个优化器**训练，只在"信用几何"上做文章。这种隔离只存在于第一次策略更新时（一旦迭代，各臂各自采数据，差异就混淆了），所以单次更新对比就是研究对象。四个臂：

- **Binary**（官方默认）：常规稀疏 0/1 结果奖励；
- **Uniform**（稠密均匀）：连续稠密奖励（数据库字段级进度），组归一化优势**均摊到每一轮**；
- **Per-turn**（定点投放）：同一份优势，按每轮正进度占比分配——**消耗的验证信息严格多于 uniform**，对照本身偏向它；
- **Shuffled**（随机投放）：把 per-turn 的权重**打乱到随机轮**——浓度相同，定位信息为零。

全局梯度范数裁剪 1.0 在每个 epoch 都饱和，因此各臂只差**更新方向**，不差更新幅度。

### 坐标系：V_d = k/C

论文提出一个结构量：**验证器信息密度 V_d = k/C**——验证器独立暴露的、因果链上"逐轮正确性可查"的比例。其中 k 是实际携带信用信号的轮数（进度信号的参与比），C 是任务因果链长度。在真实 rollout 上测量：**98% 的轨迹里，全部进度信号落在最后一笔批量数据库写操作上（k=1）**；而成功需要 **C=5–8 步硬前提工具链**（查用户→检索订单→查商品→才能换货；静态数据流检查确认，100% 成功轨迹的终写参数来自前置读的返回值，中位 5 次读先于第一次写）。于是 V_d = k/C ≈ 0.12–0.20，代表值 **0.15**——可观测信号在最集中的地方，因果结构恰好最分散。

### 天花板：验证器只能给"动手"打分

为什么 k=1 不是偶然？论文给出一个结构性上界：状态转移验证器只能给**改变状态**的步骤打分；读操作、查询不改状态，其正确性是目标相关的——除非塞给它神谕标签或学习式裁判，否则**读/探索步骤是结构性盲区**：V_d ≤ write-fraction（写操作占比）。作者普查了主流 Agent 基准（表 3）：τ²-bench 0.12–0.20、BFCL V3 的逐轮检查器只打到状态改变步（约 0.4）、SWE-bench / WebArena / OSWorld 从官方评分代码可直接推出 k=1、AppWorld 是终端单元测试、ToolSandbox 只部分暴露。**覆盖区（C ≫ k）不是任务挑选的偶然，而是状态验证的结构性常态**。学到式或神谕式过程奖励，本质是在为填补这个可观测性缺口付费。

### 相变点：V_d* ≈ 0.8

在已知因果结构的合成环境里扫 V_d，定位与均匀的差距随 V_d **单调闭合**：targeted − uniform 的差距从 −0.43、−0.36、−0.27、−0.11 一路收窄，到 V_d=1 翻成 +0.36，交叉点 **V_d* ≈ 0.81**（32 对种子）；扫 C=4–10，V_d* 稳定在 [0.75, 0.91]。该边界对预算大小、网络容量、分级因果、顺序依赖、策略自收集都稳健，且**算法无关**（匹配有效学习率后，GRPO、advantage-baseline、REINFORCE 下 uniform 都赢）。现实终端验证器全部深居 C ≫ k 一侧——**均匀摊平不是调参选择，而是结构性强制的默认**。

## 三、实验结果

### τ²-bench 主战场的四臂对决

主实验在 τ²-bench retail（对话式双控制环境，只用纯数据库状态任务）上做，基座 Qwen3-14B + LoRA（rank 16）+ GRPO，95 个任务–种子配对做单侧 Wilcoxon。结果呈漂亮的"两分离"：相对未训练基座（0.522），**二值奖励把策略练坏了**（0.484，Δ=−0.038，4/5 种子净伤害），**稠密均匀把策略练好了**（0.563，Δ=+0.041，4/5 种子）。uniform − binary = **+0.079**（p=0.003，95% CI [+0.009, +0.149]），官方成功率 +5.2 个百分点。常规稀疏结果奖励不是"弱一点"——在匹配条件下它**主动有害**。

### 分辨率很便宜，非退化梯度才贵

把稠密信号离散成三档（0 / 0.5 / 1），保留 **96%** 的优势（+0.076 vs binary，5/5 种子）。这说明收益不来自精细分辨率，而来自**全败组里终于有了非退化梯度**——当一组 rollout 全军覆没时，二值信号给不出任何方向，稠密信号还能说"这次比上次接近了一点"。

### 定位是二阶的：进步轮 ≈ 随机轮

把同一份优势集中到进步轮（per-turn），在断言支持度上**每个种子都输给 uniform**（0/5，均值 −0.053）；而打乱到随机轮（shuffled）的亏损与 per-turn  statistically 不可分（shuffled − per-turn = +0.014，95% CI [−0.07, +0.10]）。随机投放没有更差，直接排除了"投错目标、换更准的定位就能救"的解读——**亏损的根源是集中本身**。8B 上同构复现（dense > binary +0.048，3/3；per-turn − uniform −0.050）。

### 第二战场与跨家族复现

BFCL V3 的检查器是**逐轮**的（每轮后查后端状态），看似是定位方法的理想场地——但实测它只照亮状态改变步（5–6 步链中的中位 2 步，V_d ≈ 0.4），仍低于相变点，于是预测 uniform 继续赢：8 种子同批四臂，per-turn − uniform = **−0.036**（t=−2.80，p=0.027），shuffled − uniform = −0.034（8/8 种子，t=−7.5），shuffled − per-turn = +0.002。跨家族检验落在 ToolACE-2-8B（Llama-3.1 系的工具特化模型）：预注册 8+4+20 种子三连击池化 **Δ = −0.048**（t=−6.54，95% CI [−0.063, −0.033]，29/32 种子为负），单看 20 种子独立复现本身显著（−0.054，t=−5.73）。

### 剂量-反应：覆盖越宽，亏损越小

预注册的 5 臂广度扫描（固定总信用预算、20 种子）给出最细的机制证据：把优势集中在单轮，代价 −0.048（t=−7.84）；放宽到检查器可见步，收复 +0.031；再放宽到每一次工具调用，再收复 +0.027；到全覆盖即与基准平价（+0.010，CI [−0.007, +0.027]）。**亏损随覆盖宽度单调消失**。而把检查器可见的信用打乱到随机轮只移动 +0.014（不显著）——广度扫荡内部，定位依旧无效。经典补救手段 reward-to-go 也按预测兑现：它之所以有效，是因为恢复了前缀覆盖（纯终端奖励下 return-to-go 本就等价于均匀分配），落在与全覆盖平价的位置（+0.025）。

### 预测的"空结果"也全部兑现

一个机制要立得住，还要说清效应**在哪里消失**：4B 与 Llama-3.1-8B 落在能力下限之下（4B 只有 24% 的 rollout 走完前提链，14B 约 70%；Llama 基座成功率 2%），没有完成的链可覆盖，效应消失——Llama-3.3-70B 即便 81% 轨迹工具调用格式良好，仍是 0/32（"走过链但不消费链"：只有 50% 的终写参数来自前置读，Qwen 是 100%）；telecom 域稠密信号太稀薄，比较为空。正例、尺度、零结果，一张表全部收编。

## 四、技术启示与发展方向

第一，**这与昨日 CANOPY 形成了一场隔空辩论，而分歧可能比看上去小**。CANOPY 在 AppWorld 上说"稀疏二值最好、稠密奖励 −1.8 有害"；本文在 τ²-bench 上说"二值净伤害、稠密均匀 +0.079"。表面针锋相对，底层其实是同一枚硬币的两面：两边都认定**别让因果链上的任何一环饿着梯度**——CANOPY 用 n=32 大组把"组内成败混合"的概率（P_sig）从 34% 抬到 81%，本文用稠密/三档信号保证全败组也有非退化梯度（"分辨率是便宜的"）。至于稠密到底有害还是有益，分歧大概率藏在信号定义（替代性学分 vs 数据库字段真实进度）与任务域里——这是留给后续工作的开放问题，和稀泥不如做跨论文受控对比。

第二，**给"定位派"立了一条必须过的及格线**：matched-concentration shuffled control（同浓度随机投放对照）。想证明逐轮信用分配有用，先证明它打得过"把同样的信用瞎扔"——因为改变信用几何会同时改变浓度与优化动力学，不打这个对照，任何定位收益都可能是浓度效应的马甲。同日 arXiv 的 Cliff（2609.02817，用现成 LLM 找"第一个错误"、前缀正反馈后缀负反馈，12 个场景平均超 GRPO 7%）在**推理域**有效，恰因为学习式裁判提供了高有效 V_d——定位有肉可吃；但把同一招搬进低 V_d 的工具域，就会继承集中投放的覆盖风险。**一域一药，先量 V_d 再决定请不请定位专家**。

第三，**对基准设计者的提醒**：终端验证器把 Agent 训练结构性锁死在覆盖区；想给定位类方法公平的考场，要么构建每步可验证的环境（ScienceWorld 型），要么接受"均匀摊平"作为所有逐轮方法必须击败的强默认线。

第四，**边界同样诚实**：共享 rollout 隔离只存在于第一次更新，长期训练的外推需要更多证据；τ²-bench 上的效应只在 Qwen3 家族内观察到——它是唯一越过该基准能力下限的开源同尺度家族；write-fraction 天花板也提示，纯状态验证的 Agent 训练可能先天喂不饱"定位类"算法，出路是环境设计而非更聪明的奖励。

## 五、总结

"定位派"的世界观是：功劳有一个"真正的落点"，找到它，学习就会更快。这篇论文用一把 V_d 的尺子量出了这句话的适用边界：**在终端验证器统治的 Agent 世界（V_d ≈ 0.15 ≪ 0.8），可观测信用本来就只剩一根尖峰，"找落点"是在一根尖峰里做文章；而因果链有 5–8 步长，任何定点投放都只覆盖链的 1/5 到 1/8**。均匀摊平是零信息下的覆盖最优，也是所有"更聪明的记功法"必须击败的默认线。给 Agent 记功之前，先问一句：**你的验证器，照亮了因果链的几分之几？**
