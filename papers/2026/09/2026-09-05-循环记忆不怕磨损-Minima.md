# 循环记忆，不怕磨损：把 Gated DeltaNet 也压到 4-bit——27B 混合模型全量化实录，精度纹丝不动、显存 17.5 GiB、prefill 快 19%

📌 **核心摘要**：混合大模型把 softmax 注意力与线性注意力（如 Gated DeltaNet）拼在一起，用固定大小的循环状态压缩上下文。社区做 4-bit 量化时几乎都默认一条铁律：**循环部分的误差会随长上下文累积，所以 GDN 块的 gate 投影必须留在 8-bit 甚至 16-bit**。两位研究者（arXiv:2609.04098）偏要试试这条铁律——他们构建的 **Minima** 把 Qwen3.8-27B 全部 **496 个线性层**（GDN 一层不落）压到 **NVFP4 W4A4**。结果：PPL（4K/32K）、MMLU-Pro、GSM8K、AIME'25、GPQA-Diamond、LiveCodeBench、RULER（64K 检索）全线与 BF16 **落在种子噪声之内**（5 任务平均 −0.52），同时是四套方案里**最小**（权重仅 17.53 GiB，比 BF16 小 2.9 倍）**、prefill 最快**（TTFT 6.90s→4.03s @32K，8K prompt 吞吐 +14~19%）的那个。论文更用四层机制拆解回答了"为什么"：块缩放锁死离群值、gate 参数化压缩噪声、delta 规则主动擦除状态误差、逐 token 误差随上下文被冲淡——**社区拼命保护的投影，恰恰是架构自己早就保护好的那批**。循环的一半，是混合模型里"最好量化的一半"。

## 一、研究背景与动机

**两个趋势正在合流。** 一边，服务成本把 W4A4（4-bit 权重 + 4-bit 激活）推理推成实用目标：NVIDIA 的 **NVFP4** 格式用 E2M1 的 4-bit 数值 + 每 16 个元素一个 E4M3 缩放因子，能原生跑在当代加速器上。另一边，前沿开源模型越来越"混合"：大部分层不再是 softmax 注意力，而是线性注意力算子——状态是一个固定大小的矩阵，随 token 循环更新。以 Qwen3.8-27B 为例：**64 层里 48 层是 Gated DeltaNet（GDN），只有 16 层是全注意力**。

**社区的"保护清单"。** 作者调研了当时所有公开的 Qwen3.8-27B 4-bit 构建——包括模型作者自己的 FP8 版本——发现它们高度默契：MLP 可以激进量化，**GDN 块必须保护**。它的 query/key/value、输出投影，尤其是两个 gate 投影（控制衰减 α_t 的 a、控制写入强度 β_t 的 b），一律留在 8-bit 或 16-bit。背后的直觉非常自然：递归状态

```
S_t = α_t·S_{t−1} + β_t·k_t·(v_t − S_{t−1}ᵀ·k_t)ᵀ
```

要跨成千上万个 token 传递信息，**每一步的量化误差理应复利式累积**；而 gate 直接控制状态的生命周期，gate 出错应该累积得最快。

**这篇论文的主张是：对这个架构，直觉反了。** 贡献有三：① 一个真正的 W4A4-GDN 模型 Minima，并在固定服务 regime 下认真评测；② 一套四层机制研究，把"碰巧能用"升级成"架构性解释"；③ 四个 serving 层的测量发现——不修好它们，上述结论一个都测不出来。

## 二、核心方法

### 2.1 Minima：全量化，没有例外

Minima 是纯后训练量化（PTQ）：**Qwen3.8-27B 的全部 496 个骨干线性层**统一压到 NVFP4 W4A4，GDN 的 gate 投影也不例外。这使它成为唯一一个 GDN 块（约 5.5B 参数、占 decode 权重字节 ~23%）也处于 4-bit 的 checkpoint。评测 regime 刻意锁死：FP8 KV cache、vLLM 0.27.1、单卡（RTX PRO 6000）、完全相同的 harness、逐样本有效性校验——对比对象是 BF16 原版与两个社区 NVFP4 构建（Unsloth、RadixArk，二者 GDN/attention GEMM 仍是 FP8）。

### 2.2 机制研究的三件工具

- **激活统计**：捕获 4 条 32K-token 真实输入，在 NVFP4 粒度下统计各层角色的 max/RMS、峰度、以及"1-hot 块"占比（16 元素块内单个值能量占比 >56% 的情形）；
- **逐投影敏感性重放**：96 次 (层, 序列) 重放 × 8K token，**每次只量化一个投影**，观察层输出 y 的扰动；
- **FP32 lockstep 误差传播**：1 条干净轨迹 + 11 条扰动轨迹跑相同输入 32K token（5 个不同深度的层），隔离量化噪声在递归里的演化——另加一个 1% 状态脉冲注入实验，测量递归的"自愈"速度。

## 三、实验结果

| 指标 | BF16 | Minima | Unsloth | RadixArk |
|---|---|---|---|---|
| PPL @4K / @32K ↓ | 6.95 / 10.35 | 7.67 / 10.84 | 7.16 / 9.91 | 7.35 / 9.95 |
| MMLU-Pro | 80.4 | 79.7 | 78.9 | 79.1 |
| GSM8K | 95.5 | 95.5 | 95.4 | 95.7 |

| TTFT @32K | 6.90 s | **4.03 s** | 4.49 s | 4.39 s |

三个观察：

**① 所有量化方案都在种子噪声内追平 BF16。** 三个量化模型在 5 任务均值上只差 0.54 分——小于一道 AIME 题（3.3 分）；最大单任务差距（RadixArk 的 AIME −2.5）也落在 BF16 自身种子波动（83.3–93.3）之内。Minima 的 AIME'25 与 BF16 **四个种子完全同分（26/30）**，而它的 GDN 全在 4-bit。生成行为也没变：Minima 不会"想得更久"（AIME 平均生成 14,531 vs 14,532 token），触及 32K 上限的频率略低。任意两模型在任一任务上都没有被置信区间分开。

**② 量化 GDN 块换来实打实的效率。** Minima 权重仅 17.53 GiB：比 BF16 小 **2.9×**（VRAM 与磁盘皆然），比两个社区 NVFP4 构建还小 7–13%；单卡可缓存 token 预算最大（1.81M）；prefill 最快——32K TTFT 从 6.90s 砍到 4.03s，8K prompt 吞吐比 GDN 仍跑 FP8 的 Unsloth/RadixArk 高 **14–19%**。decode 受权重带宽限制，三者差距收窄到 4% 以内（RadixArk 领先 2–4%）。

**③ 一个被忽略的细节**：PPL 表里社区方案的 32K 数字看起来"更好"，但论文第 6 节指出这类比较充满测量陷阱——raw-completion harness 对思考型（thinking）模型无效、per-module 校准与 fused-GEMM 之间存在全局尺度错配。修好测量后，结论才成立。

## 四、它为什么扛得住？四层机制拆解

### 4.1 输入不是原因：GDN 读到的残差流一样"脏"

最简单假说：GDN 的输入分布比注意力"好量化"。**不是。** GDN 投影读的是与注意力同一条残差流：极端离群值照旧（中位层 max/RMS = 63.5、峰度约 1,560、热通道是中位通道的 100 倍），10–32% 的 16 元素块被单一数值主导。但**实际逐 token A4 误差在所有层角色上出奇均匀——7.5~9.2%**，因为 NVFP4 的块缩放把每个离群值"囚禁"在它的 15 个邻居里，不向外泄漏。权重误差（10.5–11.9%，近高斯权重）处处高于激活误差；两者在 32K 窗口内随位置完全平坦。**鲁棒性必然来自层"怎么处理误差"，而不是数据干净。**

### 4.2 被保护的投影，恰恰是最安全的投影

逐投影重放给出了全场最反直觉的表：把社区死死护在 BF16 的 gate 投影 a、b 全量化，层输出 y 只动 **2.1% 和 2.6%——全场最小**——尽管它们自己的 GEMM 误差高达 11.0% 和 8.5%。护盾在参数化本身：softplus/指数与 sigmoid 这类**有界压缩非线性**，把约 11% 的 pre-activation 误差压成 1−α 上 7.5%、β 上 5.2% 的误差，递归再容忍二者。Minima 真正扛的误差来自三个普通 GEMM：out（12.7%）、qkv（10.4%）、z（9.9%）。两个附带的规律性发现：五个投影的误差统计独立（单投影误差按正交合成 19.4%，与全量化的实测 19.2% 几乎相等）；且**每个**投影都是权重误差 > 激活误差；误差沿序列不增长（首尾四分之一：19.5% vs 19.7%）。

### 4.3 递归"有界"并"擦除"噪声：delta 规则是自清洁的

误差会不会随时间累积？FP32 lockstep 跑满 32K token 的答案是：**不会**。全 Minima 状态误差从 token 256 的 12.96% 到 token 32768 的 12.31%，平台期 12.6%（峰值 14.9%）——遗忘与注入在某个平衡点相遇，然后整个窗口纹丝不动。更妙的是脉冲实验：在 t=1024 注入一个 1% 状态扰动，它在 **80–1,382 步内衰减到 1/e、约 2,200–2,900 步衰减到 1/10**——而同一批层由衰减 gate 暗示的遗忘地平线长达 44K–62K token。**额外擦除来自 delta 规则本身**：如更新式所示，每次写入都沿着当前 key 的方向覆盖旧状态，旧误差是被"逐 key 删除"的，而不只是被指数衰减。反过来，实验也定位了真正的脆弱点：直接对 α 施加 0.1% 的相对噪声会引出 22% 的状态误差——因为 α≈1 时，微小的 δα 就是遗忘地平线上巨大的相对变化。**这正是参数化存在的意义**：gate 非线性把误差挡在递归的控制信号之外。

### 4.4 端到端：上下文把误差冲淡，而不是放大

若机制成立，served 模型的量化 gap 不该随位置增长。把 32K PPL 逐 token 按位置拆开（Minima − BF16，同 KV regime）：**权重量化代价前半窗口 +0.081 nats、后半 +0.011 nats，最后 2K token 反而为负（−0.053）——Minima 比 BF16 更好**。4-bit 的代价是一个"短上下文、逐 token"的效应，被逐渐填满的状态吸收殆尽。FP8-KV 的代价行为完全相反：小、随位置上升、对 Minima 约 3× 更大——这是注意力路径的效应而非权重效应，第 7 节用校准 scale 把它消除。

### 4.5 测量陷阱：四个差点毁掉结论的 serving 发现

- **per-module 校准 vs fused-GEMM 缩放**：逐模块校准的 NVFP4 checkpoint 被"把多个模块融合进单个 GEMM"的 kernel 服务时，会出现**全局尺度错配**——这影响当下任何混合模型 NVFP4 部署；
- **composite vs text-only 服务路径**：两种路径给出不同结果；
- **raw-completion harness 对思考型模型无效**；
- **基座模型的 context inversion**（上下文反转现象）。

### 4.6 KV cache：48 层 GDN 没有 cache，16 层注意力的 FP8 几乎免费

GDN 层不携带 KV cache，只有 16 层注意力层有。存 FP8（scale=1.0）在任务上几乎免费：6 套件 × 4 种子无一分数移出种子波动，容量还涨 **1.8–1.9×**。唯一系统性代价在 32K PPL：BF16 +0.13、Minima +0.41（3× 更大——Minima 的 K/V 投影已是 W4A4，cache 再舍入一次时余量更小）。校准 scale 一举关闭它：Minima + scales（llm-compressor 的静态 per-tensor FP8 scales，16 层 32 个 tensor）把 32K PPL 从 10.84 拉回 **10.50**，回收 83% 的惩罚；残余 +0.07 甚至低于 BF16 自己未校准的 +0.13；4K PPL 不变、RULER 32K/64K 仍满分、吞吐差 <0.4%——**scales 是性能免费的**。

## 五、技术启示与发展方向

1. **给混合模型做量化的处方只有一句话**：quantize everything（全量化）、serve FP8 KV（FP8 KV 服务）、ship calibrated scales（带上校准 scale）。社区此前"保护 GDN"的精度地图，保护的恰恰是架构自己已经保护好的投影——白花了带宽与显存。
2. **"循环误差会累积"的直觉需要按架构重审**。对 delta 规则这类"写入即覆盖"的递归，量化噪声不是复利，而是被主动擦除的坏账；判断一种递归怕不怕量化，要看它的**写入是否沿 key 方向覆盖旧状态**、以及**控制信号是否有界压缩非线性把关**——这两条比"它是不是循环的"重要得多。
3. **测量 pipeline 是量化研究的隐形战场**：fused-GEMM 的全局尺度、thinking 模型的 harness 合法性、per-module 校准与 kernel 的交互，任何一个都会静默地翻转结论。论文把这四条写成 serving 层的"已知陷阱"，值得每个做低比特部署的团队对照自查。
4. **可迁移的追问**：GDN 不怕 4-bit，其他线性注意力（Mamba 系、RWKV 系）呢？其他 gate 参数化呢？若"覆盖式写入 + 有界 gate"是充分条件，混合模型的内存墙还能再往低比特推一档；若只是 NVFP4 块缩放的功劳，则 FP8/E4M3 时代的结论要重测。

## 六、总结

Minima 用纯后训练量化造出了一个**全 W4A4 的 27B 混合大模型**：496 个线性层、Gated DeltaNet 一个不落，推理、知识、数学、代码、检索、长上下文六路评测全部落在 BF16 的种子噪声里，同时拿下同批方案的最小体积与最快 prefill。机制研究把"碰巧能用"讲成了架构故事：NVFP4 块缩放中和残差流的离群值 → gate 参数化在噪声抵达递归控制信号前就把它压缩 → delta 规则的覆盖式写入把状态误差擦除得比衰减 gate 更快 → 端到端误差随上下文被冲淡。再把测量 pipeline 修正确，结论干净利落：**混合模型的循环一半是"容易的一半"，放心量化。**
