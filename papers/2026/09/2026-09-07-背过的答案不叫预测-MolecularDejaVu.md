# 「背过的答案，不叫预测」：22 个前沿模型在分子基准上的"数字级复读"审计——推理档位开得越高，背得越欢

📌 **核心摘要**：LLM 越来越多地被请去"预测"分子性质——输入一个 SMILES 结构式，输出溶解度、毒性、结合自由能。但基准分数有一个从未被正面回答的盲区：**准确率分不清"算出来的"与"背出来的"**。汉堡工业大学与亥姆霍兹-盖斯特哈赫特研究中心团队（arXiv:2609.05381）对 22 个前沿模型 × 12 个分子性质回归基准做全面板审计（264 个模型-基准格、每格同一批 500 个分子、零样本、受控推理档位），用一套"数字级"统计（三位有效数字命中率 + 逐位保留率 vs 分子盲地板）抓逐字背诵。结果：**高推理档下 89/264 格存在显著背诵**，且高度集中于 5 个被广泛转载的基准——FreeSolv 14/22 格、ESOL 15/22、LD50 16/22、AqSolDB 15/22、教科书沸点正对照 22/22 全中；而未被转载的新近对照（2024–2025 抗病毒盲测数据）**全面板零背诵**。两个最扎眼的发现：其一，**推理开得越大、背得越欢**——同一模型、同一分子、同一提示词，推理从最低档升到约 1,024 token 档，显著背诵格从 47 涨到 89（+89%）；其二，某模型把 FreeSolv 复现到中位绝对误差 0.025 kcal/mol，而该基准默认实验不确定度高达 0.6 kcal/mol——**误差比它"预测"的物理量本身的测量噪声还低一个数量级，那不是预测，是复读**。用字符替换打盲后，排行榜被洗牌：Claude Opus 5 从三个基准全领先变成一项不领先，模型间误差跨幅从 21 倍收敛到 5.5 倍。一句话：**不控制背诵的分子基准评测，分不清预测与回忆。**

## 一、研究背景与动机

**LLM 正在走进"预测化学"的考场。** 从 SMILES 结构式直接报数值性质的路线（predictive chemistry），在部分任务上已逼近专用模型与训练基线。但这类报告全部建立在同一面承重墙上：**一个基准分数**。分数只告诉你"离真值多近"，从不告诉你"这个数是你算出来的，还是你见过的"。

**数字的诡计藏在第三位有效数字里。** 如果某个数值能从模型权重里被恢复出来，低误差度量的就是"模型对基准背后文献的暴露程度"，而不是"对未见分子的泛化"。为什么分子性质基准特别适合做这件事？作者给出三层论证：① 数值回归没有"标准答案字符串"可补全——记忆检测的经典工具（canary 插入、前缀抽取、成员推断）全部假设"被记住的是一个字符串"，且多数需要梯度或 logprob，前沿 API 一概不给；② 换序检验（exchangeability test）需要可置换的"序"，分子表没有规范序；③ "答对"本身不构成暴露证据——合格的化学家或模型能大致估出溶解度量级，**但给不出第三位有效数字**。实验测量的第三位有效数字通常埋在测量噪声里：FreeSolv 大多数条目默认实验不确定度 0.6 kcal/mol（原始文献未报误差），而受控档位的主实验里，某模型报出中位绝对误差 0.025 kcal/mol。"误差低于实验不确定度，不可能反映对底层物理量的预测，只能反映与已发表数字的一致。"第三位有效数字，就是抓背诵的天然金丝雀。

**这篇论文还是对自己的一次翻案。** 作者团队 2026 年初做过一项"盲测研究"（打盲 SMILES 做 in-context 性质预测），在 3 个旧基准、最低推理档下没有抓到任何逐字背诵——当时读作"干净"。本文是对这项阴性结果的系统复查：更大面板、受控推理档、数字级统计。结论推翻了自己：**那不是干净，是审计档位太低**。这为全文埋下最锋利的方法论注脚——"每个污染审计，都是它运行档位下的一个下界"。

## 二、核心方法

### 2.1 面板与协议

22 个模型（Claude Opus 5 / Sonnet 5 / Haiku 4.5、Gemini 3.6 Flash 到 2.5 Pro 五个世代、GPT-5.6 terra/luna/sol 三兄弟、GPT-5.5、GPT-5、GPT-4.1、Grok 4.5/4.3、Kimi K3、Qwen3-235B、Llama 4 Maverick、Mistral Large 2512、MiniMax M3）× 12 个回归基准（FreeSolv、ESOL、LD50、AqSolDB、Lipophilicity、Caco-2、BACE、PPBR、QM7、QM8，外加两个对照：45 个教科书沸点正对照、2024–2025 ASAP 抗病毒效价盲测挑战新近对照）。全部经同一供应商零样本查询：系统提示点名"基准名 + 标签名"，用户提示只给一个 SMILES，要求报三位有效数字，前面可写任意长度的推理。主地图每格同一批 500 个分子——同一列两个格的差异只能是模型效应，不可能是样本效应；推理档位统一控制在约 1,024 token。

### 2.2 数字级统计：不问"差多少"，问"背没背出来"

每个（真值，预测）对按 1/2/3 位有效数字计命中，得到嵌套计数 m1 ≥ m2 ≥ m3。由此定义三个量：三位命中率 hit3 = m3/n，以及两个"保留率"R12 = m2/m1、R23 = m3/m2——"对上一位的里面，有多少续上了下一位"。保留率是条件统计，几乎与模型整体准确率无关；它只检验一件事：模型是否比"不看分子也能做到的最好程序"更常续出下一位数字。这个"分子盲地板"只吃该基准标签的数字分布（一半标签拟合、另一半评分；局部均匀分布下约 9.5%，再按各基准实际分布精算）。保留率显著高于地板 = 解析出了分子盲程序不可能解析的数字——而实验值的第二、三位有效数字原则上不可从结构预测（旁证：在被背的四个基准上，模型与发表值的相关性在 88 格里有 87 格达不到"只对第一位、低位全瞎"的参考预测器）。多重检验用 Benjamini–Hochberg 控制 FDR；每格截断率 ≤1.4%。

### 2.3 三个实验臂

① **污染地图**：全面板、受控档；② **推理阶梯**：Gemini 3 Flash / 3.1 Flash-Lite / 3.5 Flash / GPT-5.5 / Claude Opus 5，每模型至多 5 档推理（端点最小值到 high）× 12 基准，每格固定 ≤60 分子、3 次重复，同一模型各档背靠背跑——格内配对比较，排除端点漂移；③ **盲测打断**：4 个模型（Claude Opus 5、Grok 4.5、Kimi K3、GPT-5.6 sol）× 3 个背诵最凶的基准，100 个 in-context 样例，L1 条件给发布版 SMILES 并点名属性，L5 条件把 SMILES 逐字符替换、只称"该样本的性质"。

## 三、实验结果

### 3.1 污染地图：背诵普遍，但极度"挑基准"

高推理档下 264 格里 89 格显著（34%），其中五个基准承载了绝大部分：

| 基准（单位） | 规模 | 显著背诵格 | 说明 |
| --- | --- | --- | --- |
| FreeSolv（kcal/mol） | 642 | 14/22 | 水合自由能，随化学信息学包广泛分发 |
| ESOL（log mol/L） | 1,128 | 15/22 | 水溶性，教程常客 |
| LD50（−log mol/kg） | 7,385 | 16/22 | 大鼠急性毒性 |
| AqSolDB（log mol/L） | 9,982 | 15/22 | 水溶性聚合库 |
| 沸点正对照（°C） | 45 | 22/22 | 教科书值，维基百科全量可查，接近 100% 复现 |
| Caco-2 / BACE | 910 / 1,513 | 0/22 | 干净 |
| 抗病毒新近对照（pIC50） | 1,006 | 0/22 | 2024–2025 盲测数据，全面板干净 |

其余基准只有零星格子（QM7 三格、QM8 两格、Lipophilicity 与 PPBR 各一格）。年龄与规模都解释不了这个分布：被背的基准都比所有被测模型老；同族不同规模（GPT-5.6 luna/terra/sol）污染水平相近；反倒是老模型（GPT-4.1、Gemini 2.5 Pro）比最新前沿模型干净——"为什么最新模型背得更多，我们没有解释"，作者直言不讳。

**溯源给出了一个干净的相关性。** 污染不走"基准文件本体"路线（若文件整体进语料，背诵率会高得多）。三个开源预训练索引的扫描显示：基准分子在语料文档中的出现频率，与该基准的最强背诵率 ρ=0.88；而"基准文件自带表头"的出现频率只有 ρ=0.20。也就是说，模型是在**二手中介**里见过这些分子——ESOL/FreeSolv/AqSolDB/LD50 随工具包、教程与衍生仓库被广泛转载，沸点在维基百科全量可查。对补救的含义很残酷：基准文件可以从训练语料里删掉，毒理学手册和百科条目很难排除；**但两条路线对评测有效性的伤害完全相同——基准都不再测量"从化学原理出发的预测"。**

### 3.2 推理档位：开得越大，背得越欢

同一批格子的配对比较：最低推理档 47/264 格显著，升到约 1,024 token 档后变成 89/264（**+89%**）。增量几乎全落在已被污染的那组基准上（LD50 从 4 格涨到 16，ESOL 与 AqSolDB 各从 4 涨到 15）；干净基准纹丝不动（BACE、Caco-2、新近对照恒为 0）。五模型推理阶梯给出单调图像：在被背的基准上，hit3 随模型实际发出的推理 token 数上升（多数模型从接近 0 起步）；在干净基准上全程持平。QM7 是唯一例外——只在少数模型的高推理档露出背诵。

**Claude Opus 5 反潮流**：FreeSolv 与 ESOL 上 hit3≈65% 全场最高，每档却只花其他模型一到两个数量级更少的推理 token；而且所有模型在"自己最熟的基准"上花的推理 token 都更少——**记得越牢，推理越省**。机制只破了一半：LD50 的发表值 = 实测值 + 分子量换算 + 对数，捕获的推理轨迹证实模型在做换算——推理供的是算术，不是数值；其余基准没有换算，上升机制未明。

方法学后果是作者对自己开火：**污染审计是其所运行档位的下界**——最低档审计会漏掉约一半污染案例；他们 2026 年初那篇"零背诵"的盲测研究，同样因为跑在最低档而必须被降级读作"下界"，而非"阴性"。

### 3.3 打断实验：盲掉结构身份，排行榜重新洗牌

L1 → L5：显著背诵格从 10/12 降到 3/12；9/12 格的 hit3 跌破 2%。两个"清不掉"的格子信息量最大：GPT-5.6 sol 在 ESOL 上几乎不动（14%→13%）；Claude Opus 5 被削弱却未被清除（ESOL 48%→6.7%、FreeSolv 31%→4.8%）——**从没见过的结构串照样背出数值，说明它认的是 in-context 样例里的标签与数值，而不是结构**。记忆挂在"标签—数值"对子上，不挂在化学上。

误差代价严格按背诵率排序：盲后中位误差上升 Claude Opus 5 ×34.9、Grok 4.5 ×16.9、Kimi K3 ×3.2、GPT-5.6 sol ×1.8——**背得越多，盲了越痛**。排行榜随之洗牌：未盲时四模型误差跨幅 ESOL ×21.1、FreeSolv ×13.4（严格按背诵率散开）；盲后收敛到 ×5.5、×3.1；Claude Opus 5 从三个基准全部领先变成一项都不领先；12 格里只有 3 格保住中位误差名次、2 格保住 Pearson 名次。**"领先幅度"里有多少是记忆的功劳，这篇论文给出了第一个量化答案。** 旁证：同一结构换一种合法 SMILES 写法（分子不变、字符串变），背诵保留中位 102%，12 格一格未清——记忆挂在分子上，不挂在字符串上。

## 四、技术启示与发展方向

**给分子性质评测的实操清单。** 报告结果必须附带推理档位——同一模型在不同档位是两个不同的被测对象；低档位审计只能当下界读；需要"干净分数"时用结构替换拿第二读数；选基准优先选未被广泛转载的新集合（新近对照的全面板干净是全文最强的正面证据）；在 FreeSolv/ESOL/AqSolDB/LD50 上报告前沿模型结论前，至少加一种对照。作者还提醒："干净"是弱结论——这套统计为"大规模背诵"供能，不为"零背诵"背书。

**方法可迁移，且不挑领域。** 数字级保留率统计只需要"基准值自带足够的有效数字"：凡是输出多位数连续值的基准——物性、药效、价格、物理常数、比分预测——都能用"第三位有效数字保留率"做黑盒污染体检：不需要 logprob、不需要梯度、不需要训练集。

**对"推理"叙事的重新审视。** 推理 token 在污染知识上的作用，可能不是"思考"，而是"回忆的脚手架"——检索路径、单位换算、把权重里存储的数值重新组织成合规输出。这与本周的"测量诚实性"主线咬合成闭环：9/5 讲 serving 测量陷阱、9/6 证明评委仪器不稳定（同一请求、同一模型名，读数不可复现）；今天这篇再补一刀——**即便读数稳定，分数本身也可能来自记忆**。三道工序指向同一句拷问：看见分数之前，先问分数是怎么来的。

**开放问题。** 为什么最新前沿模型比老模型背得多——与推理训练/RLVR 是否相关，作者没有答案，但这几乎是全场最有价值的未解问题；为什么规模不是主因；以及最难的：能不能在保留化学信息的同时修复基准？字符替换毁掉化学、重排标签毁掉命中率统计，两个显而易见的修复都走不通——持续更新的新近基准与动态分子集，可能是唯一现实的方向。

## 五、总结

这篇论文不提供新模型、不发布新基准，它交出的是一张**污染地图**、一把**数字级尺子**和一次**成功的打断演示**。三层发现层层递进：背诵广泛存在但极度挑基准——污染程度由"分子被转载的广度"决定（ρ=0.88），而不是由基准文件本身决定（ρ=0.20）；推理档位是背诵的放大器——47 → 89 格，审计不报档位就不可解读，作者连自己去年的阴性结论都一并推翻；背诵可被盲测打断，而打断之后排行榜洗牌——Claude Opus 5 从三冠王到颗粒无收，模型间 21 倍的误差距离缩到 5.5 倍。对读者最实用的一句话：**下次看到"LLM 分子预测"的榜单，先问两个问题——这组数字在训练语料里被转载过多少遍？报告跑在哪个推理档位？** 对整个领域，这篇论文把那个一直不好意思问的问题摆上了台面：前沿模型的"分子直觉"里，有多少是化学，有多少是文献综述？这是第一张地图，坐标还粗，但方向已经标出来了。
