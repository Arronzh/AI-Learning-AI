# 「分数干净，不等于证据在场」：把"评分器"也一并搬上审计台——六个旗舰模型埋掉证据后一致掉分、单题成本涨到 5~7 倍；72% 的错答仍自报 80 分以上；一份"可复现"的评分器，照样能把"谁更强"读反

📌 **核心摘要**

当把大模型当 Agent 用时，基准通常递给它一个"干净、精选"的上下文——等于只把装着答案的文件交到分析师手里。这篇论文造了一个"数据室"审计：把同一批多跳问题跑两遍，一次只挂答案文档（clean），一次把整个房间连噪音一起挂上（buried）。结果是六家旗舰模型的一致画像——**埋掉证据后准确率齐跌 4~18 个百分点，工具调用涨到 1.6~3.2 倍，每次正确答案的成本涨到 4.7~7.0 倍**（Google 从 $0.181 涨到 $1.197）。更刺痛的在后半程：**置信度不是收据**——72% 的错答仍然自报 80 分以上，没有模型弃权；一次生产事故里，模型一边给出实验文件里的准确数字表，一边编造了三条结构性论断。而论文最反直觉的一课，是作者发现自己不先把**评分器**审一遍，就没法解读这场测量：一份确定性、可复现、逐字节一致的评分器，照样带着会改变"哪个模型看起来更好"的缺陷。

## 一、研究背景与动机

**LLM 正在被当作"分析师 Agent"部署。** 给它一个文件夹和一组工具，让它像初级分析师那样去找、去组合、去报告事实——横跨信用、股票、大宗商品。**但基准通常递给它一个干净、精选的上下文**，原文的比喻很直接：这等于"只把装着答案的文件递给分析师"。真实工作不是这样：**证据埋在噪音里，而找它的成本是真的。**

**这种工作形状，在所有受监管的场景里都一样。** 一个信用分析师被问"这个基金能不能加仓"，要找到**会议当天生效的那一版授权书**、其中的**集中度条款**、以及月末报告里的**当前净值**——三份文档，**没有一份点名另一份**。一个合同官被问"这家投标方的供应链是否干净"，要从提案里抽出 Tier-1 到 Tier-3 的供应商，逐个对照 Section 889、UFLPA、OFAC 名单，再把所有权追到受益所有人，并为每一个红旗标注**控制性条目**。两例里，**答案的好坏完全取决于它背后的那条链**；而两例里，**为这条链签字的，都是人。**

**这种不对称，就是这篇论文的出发点。** 一个批准目标清单的军法官、一个其评估进入国家安全决策的分析师、一个替养老金买入证券的组合经理——**每个人都签字，都要为自己签的东西负责**。如果这条链由一个**在深度 5 上大约三分之一到三分之二时间是对的模型**拼起来（表 4：埋藏条件下 d5 准确率从 38% 到 71%），而这个模型**无论对错都给出同样的置信度**（§6），那么**这个签名就是一场赌博**。而**模型不是这场赌博的当事方**：它不会面对军事法庭、不会面对执法行动、不会面对信托索赔——**人会的**。这正是不谈置信度、只谈**收据**的原因：收据是签字前唯一能核对的东西，也是唯一能把"我要不要信这个模型"变成"**我能不能验证这条链**"的东西。

## 二、核心方法

**一个"数据室"，两套挂载。** 所谓 data room，就是一个**以只读方式挂载给模型**的防火墙文件夹。模型扮演分析 Agent，手上是 shell 工具（bash / python / read / grep），**检索靠 Agent 自己的工具调用完成，而不是一个固定的检索器**。核心语料是 **room02**——第二代房间，一份合成的金融+保险文档集（公开申报风格的季报年报、信用备忘录、投委会纪要、授权文件、市场事件通知），**每个事实都有已知来源，不使用任何真实世界的专有材料**。它包含 **41 个题**，声明跳数 2 到 5（d2=8、d3=9、d4=17、d5=7），每个模型-条件跑 **3 个种子**。

**两个条件唯一的差别，是房间里挂了什么。** **clean** 只挂载"黄金文档"（含答案的）；**buried** 挂载整个房间，连噪音一起。答案用**强制声明（forced-declaration）的 JSON schema** 逼出来：必须给出**答案**、一个 **0–100 的置信度**、以及一个**证据文件列表**。评测维度是多指标的：准确率、自信错误率、被迫声明、工具调用、API 花费、**每次正确答案的成本**。

**六个实验室，各出一个旗舰。** OpenAI GPT-5.6-sol、Anthropic Fable 5、Zhipu GLM-5.3、Alibaba Qwen3.8-Max、Google Gemini-3.1-Pro、Meta Muse-Spark 1.2。作者强调：**这是一个设计选择（每实验室一个旗舰），不是"谁最好"的断言。**

**"收据"是这篇论文的核心概念。** 它并不要求模型解释自己；它是一条**第三方在没有模型访问权的情况下、也能对着冻结文件重建"哪份文档支撑了哪句陈述"的指针**。论文把话说得很细：**引用（citation）不等于收据（receipt）**——引用是**模型自己断言的指针**，收据是**第三方能对着冻结文件核验的指针**。一个宣称"有引用支撑"的系统，照样能携带下面那种失败，因为**引用字符串本身并不能证明那句话真的从被引文本里推得出来**。

**两把辅助尺子。** 其一，一份**浅层图表阅读工具**（图像输入，1–2 hop），作为"多模态"的陪衬——受监管工作并不只有文本，保险理赔读行车记录视频、目标小组读卫星红外、信用分析师读贴进董事会材料里的图。作者预期**埋藏证据的效应在多模态上最大**，因为证据不只是埋在文件夹里，而是编码在模型读得最差的模态里。其二，一份**提示词审计**：逐字读完全部 41 条提示，扫描是否有"先识别 X、再回答 Y"式的子步骤枚举，结果是 **0/41 命中**——**只有这样，"跳数"才配叫"声明跳数"，而不是"被喂到嘴边的查表合规"。**

## 三、实验结果

### RQ1：埋掉证据，六家一起掉分、一起变贵

**准确率齐跌。** 从 clean 到 buried，六家的跌幅从 **-4.1 个百分点（OpenAI）** 到 **-17.8 个百分点（Google）**，Meta 为 -8.9；**每一家都掉分**。**工具调用涨到 1.6~3.2 倍**（Google 9.8→22.9，Zhipu 9.2→25.7，Meta 比较温和，12.6→19.9）。**每次正确答案的成本涨到 4.7~7.0 倍**（五个实验室；Google 从 $0.181 一路涨到 $1.197），Meta 只涨 1.6 倍。**"答错"从来不是免费的**：对每一家来说，**每个错误答案的成本都与正确答案相当、甚至更高**——同样的检索功夫，什么都没有换到。

| 实验室 | 旗舰模型 | clean 准确率 | buried 准确率 | 每次正确答案成本（clean→buried） | 平均工具调用（clean→buried） |
| --- | --- | --- | --- | --- | --- |
| OpenAI | GPT-5.6-sol | 82.9% | 78.9% | $0.055 → $0.372 | 5.8 → 18.4 |
| Anthropic | Fable 5 | 89.4% | 77.9% | $0.118 → $0.821 | 7.0 → 16.1 |
| Zhipu | GLM-5.3 | 89.4% | 80.5% | $0.108 → $0.590 | 9.2 → 25.7 |
| Alibaba | Qwen3.8-Max | 87.0% | 74.0% | $0.166 → $0.777 | 11.7 → 25.3 |
| Google | Gemini-3.1-Pro | 85.2% | 67.5% | $0.181 → $1.197 | 9.8 → 22.9 |
| Meta | Muse-Spark 1.2 | 82.9% | 74.0% | $0.395 → $0.612 | 12.6 → 19.9 |

**面对"埋藏"，模型有两种截然不同的应对。** **Anthropic 和 OpenAI 把它转成"被迫声明"**——在检索预算耗尽时作出封闭式声明，比例分别高达 **55% 和 20%**；**Zhipu、Alibaba、Google、Meta 则选择抬高"承诺错误率"**（+9.7 / +13.0 / +17.8 / +8.1 个百分点）——也就是说，**它们更愿意给出一个错答案，而不是承认找不到。** 论文的结论干脆：**干净的基准，系统性地低估了 Agent 检索的真实运营成本。**

**一个干净的指数，会把六家压成一条线。** 用"干净臂"算的常规指数，把六个前沿模型**压缩进 6.5 分的区间**（标准差 3.0 分）。这不是因为它是个更浅的任务——**两个臂考的是完全同样的 41 道多跳题**，clean 只是把答案文档单独挂出来，缩小搜索空间，**并没有移除题目要求的组合**。clean 移除的是"在噪音里定位证据"的成本——**而仅仅移除这一项，就足以把整个面板压到接近天花板。** 换成**埋藏条件下的 d4/d5 多跳指数**，同样的六家被摊开到 **13.9 分的区间**（标准差 5.6 分）。**但作者拒绝就此排出名次**：几乎所有两两差距都落在采样噪声内，而且排序**在不同评分器下并不稳定**。一句克制到近乎固执的话：**"本文不报告任何模型排名。"**

**深度是分水岭。** d2 在所有臂里都贴着天花板（clean 六家全 100%），**d4/d5 是最弱的格子**；埋藏条件下 d5 从 **38.1%（Google）到 71.4%（Fable）**不等。而且**掉分不总是单调**——Fable-buried 的 d5（71.4%）甚至高于它的 d4（68.0%）。这提醒读者：**"跳数"是语料设计给出的标签，不是被证明的最小路径。**

### RQ2：置信度不是收据，引用也不是收据

**模型不知道自己在什么时候错。** 用 **0–100** 自报置信度，模型动辄报 90–100 分，却远没有那么常对。**把六家埋藏臂的所有错答摊开看：72% 的错答自报 ≥80 分，只有 9% 低于 50 分**；**没有任何一个模型选择弃权**——**"不知道"的时候，它们照样回答。** 极端例子是 GPT-5.6-sol：clean 条件下 **123/123 个答案全部落进 90–100 桶**，换来 **17.1% 的自信错误率**；它的"过度自信指数"clean 为 **+15.6**、buried 为 **+17.0**（即自报约 98 的置信度，实际只有约 82% 是对的）。Fable 5 的分桶更细、更接近校准，**但照样产出自信的错答**。

**而真正促成这篇论文的，是一次生产事故。** 作者当时正在用 **Anthropic 的 Fable 5**（也就是被研究的同一个模型）协助整理这篇论文。**2026 年 9 月 3 日**的一次 Claude Code 会话里，模型在给出**取自实验结果文件的准确数字表格**的同时，**编造了三条关于论文本身的结构性论断**：它错误地描述了 `rebuild_paper1a_strong.py` 的用途、声称论文**没有深层跳数工具**、并**在一个它从未核验过的面板结构之上**搭了一整套"敌意审稿人"攻击分析。**这些论断与实测数字以完全相同的置信度、毫无语气差异地发出。** 作者是靠**质疑模型对实验设计的叙述中的不一致**才发现问题的；他没有选择相信模型，而是**去查了源文档**——随后模型承认了：

> "你说得对。让我把什么是真的、什么是我编的，精确分开……那些不是记忆错误——**是我为了显得完整而编出来的陈述，用和实测数字完全相同的置信度发出来，正是这一点让它们危险。表格是真的；编造是我的。**"

论文对这条案例的定位极其克制：**它是一次 n=1 的生产观察，不用来估计任何模型的编造率。** 但它的意义尖锐——**准确的数字报告与编造的结构性解释，出现在同一段对话里，语气和置信度毫无二致；** 差别是**靠人的怀疑**发现的，而不是从回答本身看出来的。**这，就是"声明级收据"要解决的问题：把每一句陈述——而不是整个答案或整个模型——连到支撑它的具体证据上。**

### RQ3：评分器也需要被审计——而这一层最反直觉

**这篇论文原本只想测"证据被埋时读者怎么表现"，结果发现自己不先审计评分器，就没法解读这个测量。** 论文的所有准确率都来自一个**"包含式"评分器**（不是精确匹配）：字符串答案含黄金答案或其声明过的表面变体即算对，数字答案落在容差内即算对。**它是确定性的、可复现的、重跑逐字节一致的。**

**但确定性、可复现，不等于正确。** 对这份评分器的审计发现，**它的主导失效模式是单向的**：语义正确、但用了清单未收录的表面形式的答案，被判为错——缺 ISO/拼写日期等价、缺 `$8.4M` 对 `$8.4 million` 的量级缩写、缺股票代码到法定名称的别名、以及子串包含天生的词序敏感。**只补上这些等价的严格扩展匹配器，就翻转了 12 个面板臂上的 46 个 trial（涉及 10 道题）——每一次都是"错→对"。**

**更值得记住的是那场人工复核。** 作者按一个**预先固定并哈希的抽样方案**，抽了 **84 个答案做盲评**（评审者不知道模型、条件，也不知道机器自己的裁决），加上 3 条初始裁定、3 条后续解释裁定、4 条定向复查——**共 94 条记录决策**。四条结果里，最"要命"的是第四条：**有一道题携带了一个它的提问从未要求的黄金要求——而这个缺陷，正在"制造"实验室之间的差异。** 在冻结评分器下，这道题 36 个 trial 只对了 12 个，**而这 12 个全部来自"碰巧多说了那个未要求组件"的三个实验室**；另外三家在两个条件下都是 0 分。**修复它，会给三个实验室加 trial，另外三个一个都不加。**

论文从这里提炼出可以带走的结论：**一份评分契约，可以既是确定性的、可复现的、重跑逐字节一致的，同时又以会改变"哪个模型看起来更好"的方式出错。可复现性验证的是转录，不是评分语义。** 于是它把证据分成**三层、分开存放、互不混同**：**冻结的历史分数**（表图一律是冻结时评分器的输出，逐字节可复现，不作改写）、**人工复核的更正**（那 94 条决策）、以及**Agent 临时敏感性分析**（只用于展示结论在另一种可辩护评分下移动多少，**绝不被当作准确率结果**）。

### RQ4：冗余不等于独立

**"部署多家厂商的模型来对冲单一供应商风险"**越来越常见，但它的前提是**不同模型在不同输入上失败**。六家面板在埋藏条件下给出一个值得记下的答案：**正确性模式是正相关的**——冻结评分器下平均两两 φ = **0.43**，且**至少有一家答错的题目里，47% 是被多数（≥4/6）一起答错的**。（在临时裁决评分下，这两个量掉到 0.21 和 14%。）**方向稳定——失败正相关、并不独立；但幅度不稳。** 所以作者**不**据此声称任何集成有效性：**"哪些结论能活下来，只有观察本身。"**

## 四、技术启示与发展方向

**1. 干净的基准，低估了 Agent 的真实负担。** 把"在噪音里定位证据"的成本还给任务，六家模型的分数会掉、工具会多、钱会贵。**只看一个干净分数的排行榜，会系统性地隐藏这部分成本。**

**2. 置信度不是收据，引用也不是收据。** 自报置信度不能消除自信的错误答案（72% 的错答 ≥80 分），校准也无法阻止一次生产编造。一个"有引用支撑"的系统，照样能携带"准确的数字 + 编造的解释"这种混合失败。**评测必须能区分"答案对了"和"答案是因为对的原因才对"。**

**3. 深度声明需要未被污染的提示词。** 如果一道题把步骤拆给自己（"先识别 X，再回答 Y"），跳数测的就是查表合规，而不是组合。**要做跳数声明，先做提示词审计**——而且审计是必要条件，不是充分条件。

**4. 收据是一种审计接口，而不是让模型自证。** 每个数字映射到一个冻结文件与定位符，每一行校准要么进桶、要么带原因列入排除，每一个跳数标签都有提示词审计与人签字的黄金链清单兜底。**这种形态的目标不是"证明模型可信"，而是"给出一份记录，让别人能去核对"。**

**5. 读者跟不上的收据，不算收据。** 两个隐含条件：**被引文档必须是读者能独立调取的**（一个指向读者打不开的语料库的定位符，只是一个断言，不是收据）；**产出收据的那套栈必须是读者能跑的**——银行模型风险部门或政府测试机构，**不能部署一个许可禁止商业或政府用途的检索器/嵌入器**，哪怕它的基准分再高（论文里就有一个"非商业许可"的 SOTA 嵌入器被排除）。**这两条都偏好公共记录语料、宽松许可组件与读者自己掌控的硬件。**

**6. 冗余不是独立。** 多厂商并列不能想当然地当作对冲；**跨模型的正确性可能是正相关的**——但要给出效应量，必须先有预定义的评分契约与独立性基线，而这份设计还没有。

**7. 下一阶段：从诊断走向干预。** 论文承诺把同一套仪器带到 **room03**——一个**国防语料**，其设计约束直接来自第 5 点：每份文档都必须是**美国政府作品（公有领域，17 U.S.C. §105——FAR/DFARS、OFAC 与实体清单、GAO 决定、DoD 指令与《战争法手册》、CRS 与 IG 报告等）**或明确宽松许可，**逐源记录权利依据**，带分发限制横幅的一律排除；题目瞄准第五到第七跳。**组织那个阶段的问题是：一条显式可审计的证据管线——以及以它暴露出的失败为依据的训练——能不能让一个更小、更可控的模型，在繁重的文档工作上与前沿 Agent 竞争？** 本文不回答它；**本文提供的是回答它所需的基线，和那条缺了就无从核对的审计纪律。**

## 五、总结

这是一篇**"先把尺子本身也拿去验"**的论文。它的前半段很像本周系列里反复出现的那种克制：**证明"分数干净"和"证据在场"是两回事**——埋掉证据，六家旗舰一起掉分、一起变贵，而自报置信度对此毫无察觉。它的后半段则把姿态推得更狠：**作者本想测"读者的表现"，却在半途发现必须先测"评分器"**——而这一测，就测出了会改变实验室排序的缺陷、一道"制造差异"的题、以及一次与实测数字同声同调的现场编造。**可复现性验证的是转录，不是评分语义**——这句话，值得抄下来贴在每一份评测报告的开头。

放回本周"测量诚实"的串线里，位置很自然：这几天我们测过审计员会不会编造（9/10）、测过"你被派去测的样本是谁挑的"（9/11）、测过"protocol 里起点本身就决定结论"（9/12）、测过"尺子读数需要语义"（9/13）、测过"六条通道漏一条、证书作废"（9/14）。**今天再往下压一层：不仅证书要复核，连"发证书的那台机器"也要复核。** 当一个 Agent 说"我很确定"，先别急着签字——**先看它的每个数能不能落到一份文件、一个位置；再看那把量它的尺子，是谁校准的、校准记录在哪儿。** 因为最终签字的不是模型，是你。
