# 「看着全对齐，其实早没在看图」：把 13 个多模态大模型（0.5B–72B）的图换成高斯噪点，准确率掉 38–50 个百分点，CKA、SVCCA、MIR、主夹角余弦四把「标准尺子」却读出几乎一样的分数——那份「跨模态对齐」是 MLP 权重压出来的，不是模型真的读懂了图

📌 **核心摘要**：凡是想证明「多模态大模型真的把图像读进了语言模型」，几乎都会掏出同一把尺子——**逐层的「视觉-文本表征相似度」**：把图像 token 和文本 token 在每一层的隐状态拿来比一比，相似度分数随层数升高，大家就默认这说明「语言模型在逐层把视觉内容整合进一个共享的表征空间」。这篇论文（arXiv:2609.30210v1 [cs.CV; cs.LG]，2026-09-24 提交，**已被 NeurIPS 2026 接收**；作者 **Hong-Han Wang、Yuntao Wang、Hu Ding**，中国科学技术大学）直接把这把尺子放上了手术台：**在 13 个多模态大模型（来自 5 个家族、跨 0.5B 到 72B）上，把投影器输出的视觉 token 换成高斯噪点**——图片内容被彻底抹掉，**任务准确率在全部 13 个模型上掉 38 到 50 个百分点**，可**四个标准标量指标（CKA、SVCCA、MIR、主夹角余弦 σ₁）却几乎分不出「真图」和「噪点」**，个别模型的相似度分数甚至比真图时还高、在深层一起逼近 1.0。论文把这种失败叫作**「对齐幻觉（alignment illusion）」**，并追到了病灶：问题出在**视觉与文本 token 共用同一条语言模型通道**，其中**各向异性的 MLP 下投影（W_out）把两种模态一起拽向同几个「主输出方向」，制造出一种一维的「权重诱导对齐」**——这种相似度**不需要两种模态有任何内容层面的耦合**。于是论文换了一把尺子：**主夹角间隙（PA gap，即最高两个主夹角余弦之差 σ₁−σ₂）**，**在「图→噪点」的渐变腐蚀下，它对准确率的追踪最稳（平均 |r| 0.894、12/13 个模型 |r|>0.80、13/13 符号正确）**；而当图片**换成「有结构但和问题无关」的图**时，它又暴露出**「内部几何」与「任务准确率」彻底分道扬镳**的一刻（几何排序 Orig<Irr<Noise，准确率却是 85.4% / 36.1% / 39.0%）。结论一句话：**内部「对齐分数」只是视觉流在语言模型里的一张几何体检单，它不是「模型在用图答题」的直接证据。**

## 一、研究背景与动机

**我们先说清楚这把尺子是怎么被用起来的。** 多模态大模型（MLLM）把视觉编码器和语言模型接在一起，一个越来越主流的分析路子，就是**去翻它的内部表征**，看视觉内容到底是怎么被处理的。而其中最标准的工具，就是**逐层表征相似度**：把视觉隐状态和文本隐状态在语言模型每一层拿出来比一比，得到的相似度分数「通常会随深度上升」，于是这些曲线就被读成——**语言模型在逐层把视觉内容整合进一个共享的表征空间**。CKA、SVCCA、主夹角相似度，都是干这件事的老牌工具。

**可这里藏着一个从没被直接检验过的强假设。** 论文把这句话挑明：**这套读法默认「视觉和文本隐状态之间的几何相似度，反映了内容层面的跨模态交互」。** 而这个假设**不只是描述性的**——它已经反过来**指导模型设计、数据筛选、训练诊断**：分数高，就认定「融合得好」。问题是，**这些方法原本是为了比较「两个独立训练的网络」的表征**：在那种场景下，高相似度意味着两套网络「收敛到了相似的特征」。**但在多模态大模型里，前提变了：视觉 token 和文本 token 进入的是同一串 Transformer 块，被同一套注意力和 MLP 权重处理**——**「独立」这个让标准解读成立的条件，已经不成立了。**

**一旦两条流共用权重，一个「对齐变高」就可能来自两个完全不同的源头。** 论文把它拆成两条：其一，**两种模态真的在内容层面交互了**，把表征拉近了；其二，**共享的 MLP 和注意力权重，给两条流强行施加了相似的几何**，**哪怕视觉 token 一点任务相关信息都没有**——论文把这一条命名为**「权重诱导对齐（weight-induced alignment）」**。**而标量相似度把这两个来源压成了一个数，根本没法告诉你：这份高相似度到底是「内容真的融合了」，还是「架构硬压出来的」。** 于是就有了一种失败模式：**一个模型在常规内部指标上看着「对齐得很好」，可它完成任务所需要的视觉内容其实并不在场。** 这就是**「对齐幻觉」**。

**为什么以前测不出来？因为标准基准把两种解释绑死了。** 论文指出：在常规多模态基准上，**每道题都配着一张语义相关的图**，于是「对齐分数」和「任务表现」天然正相关，两种解释**根本分不开**。**它们只有在「人为切断图像与问题的关联」时才会分离。** 受早期「泛化检验」「显著性图 sanity check」里那种**随机化对照**的启发，论文因此**对视觉流做两种受控干预**：**把投影器输出的视觉 token 换成高斯噪点**、**把输入图换成「有结构但无关」的另一张图**。**在 13 个模型、5 个家族、0.5B 到 72B 上，这两种设置里标量对齐分数依然很高，可任务准确率却塌了**——这就直接证实：**标准分数会高估视觉整合的程度。**

**于是论文抛出了那个核心问题：多模态大模型里的「内部对齐分数」，到底在量什么？什么时候才能把它的取值读成「内容层面跨模态交互」的证据？** 论文分三步回答：**第一步**，展示对齐幻觉（在受控干预下，视觉内容被拿掉、准确率崩了，标量分数却依然高）；**第二步**，把幻觉追到共享的语言模型通道——**各向异性的 MLP 下投影，在视觉和文本状态里诱导出一个共同的一维分量**，解释「没有任何内容耦合，高相似度也能冒出来」；**第三步**，提出**主夹角间隙（PA gap）**，**把「一维的权重诱导相似度」和「多维的视觉结构」分开**。

**论文也把边界摆得很清楚：它要问的是「效度（validity）」问题。** 它和三条既有路线相邻但不同：**表征相似度方法**（CKA / SVCCA / 主夹角）提供了通用工具，近来的多模态研究也拿内部视觉-文本对齐去分析视觉信息处理、共享跨模态任务表征、预训练质量——**但这些工作建立了「内部几何是有信息的诊断」，却没检验「视觉-文本相似度何时支撑得起「内容层面交互」这个更强的解读」**；另一条线证明**多模态模型的性能会高估它对视觉的依赖**（有些例子靠语言先验或选项就能答、模型会被无关视觉语境带偏）——**但它盯的是任务准确率，不是内部对齐分数的解读**；第三条线关于 **Transformer 各向异性、rogue dimension**（少数主导方向会扭曲相似度），以及**表征相似度本身可被与内容无关的设计选择操纵**——**而「两种模态共用同一套权重」这个多模态特例，此前没被直接检验，本文正好补上这个缺口。**

## 二、核心方法

**方法不复杂，它的价值在于「把干预做得足够干净、把数据流切得足够细」。**

**先立架构。** 论文研究的是当前多模态模型最典型的**「投影器 + 语言模型」设计**：视觉编码器先产出一批特征向量，一个学到的投影器把它们映射进语言模型的嵌入空间，得到**视觉 token V⁽⁰⁾**；这些视觉 token 和**文本 token H⁽⁰⁾** 拼接后，**一起被同一串 Transformer 块处理**。每一层里，**视觉流和文本流走的是同一个注意力子层和同一个 MLP 子层**（都带残差）。MLP 被拆成**上投影 W_in、非线性 φ、下投影 W_out**。**后面所有的对齐分数，都算在这条共享通道产生的隐状态上。**

**再立「尺子」。** 论文用**主夹角余弦谱**来概括每一层的视觉-文本对齐：把视觉矩阵和文本矩阵各自做 PCA、各留前 k 个主成分（全文默认 **k=30**），再算两组正交基之间的奇异值——**第 i 个奇异值 σᵢ 就是第 i 个主夹角余弦**，σ₁≥σ₂≥…≥0。**注意：σ₁（最高的那个主夹角余弦）本身就是四个「标准标量分」之一**；而**完整谱记录了剩下所有主夹角的余弦**。论文所说的**「标准对齐分数」**，就是现有的那几个标量概括：**σ₁、CKA、SVCCA、MIR**——每个都逐层计算。

**四种受控设置，逐层剥开。** 论文在固定的 **MMBench 上 1000 道多选题**（所有模型、所有设置**都用这同一批题**，确保差异来自干预、而非换题）上，比对这些「投影器输出」设置：

- **Orig（原图）**：问题所配那张图的投影器输出；
- **Noise（噪点）**：**把每个视觉 token 换成一个各向同性高斯向量，再缩放回去、对齐原来的逐 token 范数**——**保住了信号的「大小」，抹掉了信号的「内容」**；
- **Irr（无关图）**：从**同一数据集里另一道题**随机取一张图的投影器输出，**提供与当前任务无关的、自然的视觉内容**；**13 个模型用同一套固定配对**，让各模型准确率可直接比较；
- **Shuf（打乱）**：把 Orig 的视觉 token **沿 token 轴随机重排**——**内容保留、顺序打乱**；
- **Text（纯文本）**：视觉 token **整段去掉**，只留文字——**一个「不看图」的基线**。

**这几个设置是精心配对的：** 论文专门核对了**逐 token 范数在五种设置下几乎不变**（**Irr/Orig 的范数比中位数落在 [0.994, 1.002]**），**以此保证下游效应来自「token 的方向 / 内容 / 顺序」，而不是「信号有多大」**。

**关键分析手段有三样。** 其一，**旁路（bypass）**：**绕开 MLP 或绕开注意力子层**，看 σ₁ 怎么变——用来定位「放大发生在哪」。其二，**看 W_out 的谱**：**最上面两个奇异值之比 s₁(W_out)/s₂(W_out)**，和一个同形状高斯随机矩阵的参照比——用来判断**下投影是不是「有主导输出方向」**。其三，**把主夹角基投影到 W_out 前 10 个左奇异子空间上**，把「捕获到的能量」和「同维随机方向」比——用来验证**主夹角方向是不是「结构化地落在 W_out 的主导方向上」**。

**最后亮出新尺子——PA gap。** 逻辑是：**σ₁ 被 W_out 那唯一最强的输出方向主导，而 σ₂、σ₃… 对应更弱的共享方向、更能反映「输入特有的结构」**。于是**当视觉输入没有结构时，σ₁ 与 σ₂ 的间隙应当很大**（只剩那条架构方向了）；**当视觉输入有结构时，间隙应当很小**（对齐铺展到了多个共享方向上）。据此定义**主夹角间隙 Δ_PA = σ₁ − σ₂**（逐层），**Δ_PA 是它跨层的均值**。**一个小 Δ_PA 意味着对齐横跨多个共享方向、反映了有结构的视觉内容；一个大 Δ_PA 意味着对齐基本局限在 W_out 定下的那条方向上。**

**实验盘子**：**13 个多模态大模型、5 个家族（LLaVA-OV、LLaVA-OV-1.5、Qwen2-VL、Qwen2.5-VL、InternVL3）、参数从 0.5B 到 72B**。

## 三、实验结果

**RQ1——「把图换成噪点」，标准分数会掉吗？答案是不会。** 在 Noise 设置下，**任务准确率在全部 13 个模型上掉了 38 到 50 个百分点**（图 2A）。**而最高的主夹角余弦 σ₁ 反而变化很小**：**逐层看它和 Orig 曲线几乎重合、甚至更高，到深层两者一起逼近 1.0**（图 2B）。**这不只是 σ₁ 一家的毛病**：论文定义了一个「分离分数」——**衡量某个标量指标在逐层上「把 Orig 排到 Noise 之上」的能力**。**13 个模型的中位数：σ₁、CKA、SVCCA 都是负的，MIR 接近零。** 换句话说，**这四个标准标量概括，几乎给不出「原始视觉流」和「内容被抹掉的视觉流」之间可靠的区分。**

**RQ2——那这份高相似度到底从哪来？论文用四步把它揪到 MLP 下投影上。** **第一步（放大发生在共享通道里）**：**把「固定的投影器输出 V⁽⁰⁾」和「逐层的文本表征」直接比 σ₁，得到的只是中等水平、且几乎全程贴着随机上界**——说明**逐层看到的那种接近 1.0 的高相似度，是「两条流都过了共享语言模型通道之后」才出现的**。**第二步（放大主要在 MLP）**：**旁路 MLP 带来的 σ₁ 逐层平均变化，在全部 13 个模型里都大于旁路注意力的效果（中位效应是 3.5 倍）**；一个随机初始化对照进一步表明，**Noise 下被抬高的 σ₁ 不是架构的通用产物，而依赖训练出来的权重结构**。MLP 还留下第二道指纹：**Orig 与 Noise 下「MLP 输出分布」的前 k 个 PCA 子空间，最高的主夹角余弦中位数高达 0.996**——**MLP 把「有结构的视觉 token」和「高斯噪点」映射到了主导方向相近的分布上**。于是**任何「聚合子空间重叠度」的标量指标，都可能被 W_out 的几何，而不是被「每种模态编码了什么」所主导**。**第三步（W_out 有主导输出方向）**：**13 个模型里，逐层平均的 s₁(W_out)/s₂(W_out) 落在 1.2 到 1.6 之间，且每个模型都超过同形状随机矩阵的参照**（**高斯随机矩阵这个比接近 1**）——论文称之为 **W_out 的「方向各向异性」**，那些左奇异向量就是它的**「主导输出方向」**；**因为 W_out 是两个模态共用的，视觉和文本 token 都被压到同一批主导方向上，输出能量沿着共同的轴聚集**。**第四步（主夹角方向就落在这批主导方向上）**：**把视觉侧的主夹角基 Ψ⁽ˡ⁾ 投影到 W_out 前 10 个左奇异子空间，在全部 13 个模型上，它捕获到的能量是同维随机方向的 2.8 到 13.6 倍**——**主夹角方向是 W_out 主导方向的一个「结构化子集」，不是随机撞上的**。

**论文还给了个漂亮的上界（命题 1）。** 设 W 是共享下投影，若两条流的**主导输出方向各自都贴近某个公共方向 U₁**（夹角 θ_X、θ_Y），那么**输出子空间之间的最高主夹角余弦满足 σ₁(WX, WY) ≥ cos(θ_X + θ_Y)**。**这个式子里没有任何一项把 X 和 Y 耦合起来**——**一个共享的 W，只要把 WX 和 WY 都往 U₁ 拽，就能在「两条输入没有任何内容耦合」的情况下，把下游对齐分数抬高。**

**RQ3——那就换把尺子：PA gap。** 在模型层面，**逐层平均的 σ₁ 对 Orig vs Noise 的区分又小又不一致：差值贴着零、还会反向（Noise 追平甚至超过 Orig）**。**而 Δ_PA 相反：在整个模型集合上，Noise 下的 Δ_PA 更大，而且它是图 4C 里唯一一个「在全部 13 个模型里都把 Orig 排在 Noise 之上」的指标。**

**RQ4——渐变腐蚀下谁最跟得住准确率？PA gap。** 论文在原始 token 和高斯噪点之间做线性插值 **V_α = α·V_Orig + (1−α)·Z（α 从 0 到 1 每 0.1 一档）**，**α 越大、视觉内容越多，准确率先升后饱和**。除了 σ₁、CKA、SVCCA、MIR，论文还加了两个「谱离散度」基线（参与率 PR、谱熵）。在 13 个模型、每模型内层 80% 的层上算与准确率的 **Pearson |r|**：**Δ_PA 拿下最高的平均 |r|（0.894）、中位 |r|（0.917）、最低 |r|（0.655）**；**|r| 在 12/13 个模型上超过 0.80，且在全部 13 个模型上符号正确**。**它比其它标量概括更稳地追踪「视觉内容被渐变拿走」这件事。**

**RQ5——把图换成「有结构但无关」的图，会发生什么？这是全篇最有意思的一段。** 论文先说结论：**「无关图」不是被模型忽略的，而是被模型「主动加工」了。** 如果模型忽略无关视觉输入，Irr 应当和 Text（纯文本）持平；**可实际上 Irr 掉到 Text 之下**：**在全部 13 个模型上，Irr 比 Text 低的中位数是 5.0 个百分点，而 Noise 反而更接近 Text（中位差 2.1 个百分点）**——**也就是说，「加工一张无关的图」比「干脆不看图」还要更伤准确率**。作为对照，**打乱顺序（Shuf）对准确率几乎没有影响，中位差仅 0.8 个百分点**——**说明惩罚不是「对视觉 token 扰动」的笼统敏感**。惩罚还**和模型规模有关**：**在 <3B 那一组，Irr 与 Text 的差距缩到 2.9 个百分点**；**在 ≥3B 那一组，Noise 相对 Orig 掉得更多，Irr 与 Noise 的差距扩到 3.2 个百分点**。

**病灶在语言模型内部，不在投影器。** 论文用线性探针验证：**在投影器 token 上训练线性探针，能以 74.4% 到 78.5% 的准确率认出「那张无关图」的类别**（**随机水平是 5%**），**却几乎不携带「与问题相关类别」的信息**——**投影器忠实地编码了无关图；失败发生在语言模型：它没有把这份表征压下去**。接着做**「带内 / 带外」（In-Band / Out-of-Band）扰动**：在每一层，要么**在主夹角子空间内**、要么**在其正交补里**，用**相对于局部 token 范数大小为 ε 的高斯噪声**去扰动视觉 token 残差流。**在 ε=1.0 时，带内扰动在全部 13 个模型上都造成比带外更大的准确率下降**，**Δ_in−Δ_out 在 13 个模型上落在 1.1 到 5.5 个百分点之间**——**这说明主夹角方向不只是「权重诱导对齐」的几何签名，还是「视觉内容——相关也好、无关也好——能影响模型预测」的一条路径。**

**RQ6——几何排序 vs 准确率排序：它们会分家。** 标准标量指标**无法一致地对 Orig、Irr、Noise 三档排序**（**Noise 有时拿到和 Orig、Irr 相当甚至更高的分数**，而它们明明都带结构）。**而 PA gap 把三档排得很干净**：**中位数满足 Δ_PA(Orig) < Δ_PA(Irr) < Δ_PA(Noise)，分别为 0.130、0.213、0.324**，**且这一完整排序在几乎所有模型里都成立**——**Irr 处在一个「中间几何区」：它保留了有结构的视觉几何，但它的视觉-文本对齐「不如 Orig 那么多方向」**。**可对应的准确率却是另一套排序**：**Orig 中位 85.4%，而 Irr 和 Noise 双双掉进 Noise/Text 区间，且 Irr（36.1%）还略低于 Noise（39.0%）**。**换句话说：Irr 在几何上比 Noise 更有结构，可对「配对问题」而言一点也没更有用。** **有结构的视觉内容，能在塑造共享视觉-文本几何的同时，反而拉低任务准确率。** 论文由此给 PA gap 定了位：**它暴露了几何对齐诊断的一个极限——内部几何能追踪「有结构的视觉内容有没有流过共享语言模型通道」，却单凭它自己，无法确立「这份内容对配对问题到底有没有用」。**

## 四、技术启示与发展方向

**第一，这是本文最该被记住的一句：内部「对齐」是几何体检单，不是「模型在用图」的证据。** 论文的落点很克制也很硬：**因为视觉和文本 token 共用同一条语言模型通道，各向异性的 MLP 下投影可以在视觉内容已被抹掉之后，照样把标量对齐分数抬高。** **PA gap 把「一维的权重诱导相似度」和「多维的视觉结构」分开，比标量分更稳地追踪渐变腐蚀**；**而「无关图」实验进一步说明：有结构的视觉内容可以顺着共享子空间一路传播、却同时在拉低准确率**。**所以内部对齐揭示的是「模型内部视觉流的某些性质」，它本身并不确立「这条流支撑了配对问题」。**

**第二，把「对齐分数」从「结论」降格成「线索」，配上一套必须同行的证据。** 论文给的方法论建议是：**核心问题不只是「对齐分数高不高」，而是「是哪种几何造出了这个分数」**。**标准标量分会把「内容相关结构」和「权重诱导相似度」混在一起；PA gap 把两者分开，并把 Orig、Irr、Noise 排进三个不同的几何区**。**而任务准确率提供的是互补的另一半证据：视觉流到底支不支持配对问题。** **结论是：内部对齐分数，只有在「受控视觉干预 + 任务准确率」的陪跑下才最可靠。**

**第三，这条「各向异性 / rogue dimension」的老账，第一次在「双模态共用权重」的场景里被算清。** 论文在相关工作里承认：**Transformer 的各向异性、少数主导方向会扭曲表征相似度，这在单模态语言模型里早有讨论**；**而更广的表征相似度可靠性研究也表明，这类分数可被与内容无关的设计选择操纵**。**但「视觉与文本共用同一套这种权重」的多模态特例此前没被直接检验**——**论文把这个缺口补上了，并且给出了机理层面的一条可验证链条（放大→定位到 MLP→W_out 有主导方向→主夹角方向就落在这批方向上），外加一个「无耦合也能高相似」的形式上界。**

**第四，一个便宜可用的「补丁指标」就摆在那里。** **PA gap 只需要「最高两个主夹角余弦」这一对数字**——**在一个已经有谱分析流程的分析管线里，它几乎不增加成本**，却能在 13/13 个模型上把 Orig 排到 Noise 之上、并以平均 |r| 0.894 追踪渐变腐蚀。**对做多模态可解释性、做融合质量诊断、做「视觉到底有没有被用上」这类审计的人来说，这比再堆一个标量分更值得放进工具箱。**

**边界也要说清。** 论文明确：**分析聚焦「投影器-语言模型」架构、受控的多选题评测、以及「投影器输出」层面的干预**；**其它融合设计，以及开放式生成、视频、文档、Agent 任务，可能涉及不同形式的「以图条件化」推理与跨模态交互**——**把这些设置纳入同一套「干预式」分析，是重要的未来方向**。**换句话说：结论是「这类架构、这类评测下成立」，别不加限定地外推到所有多模态系统。**

## 五、总结

这一篇，又回到了本系列一路追问的那根柱子：**你手里这个数、这个信号、这份证据，到底能不能信？** 9/13 讲的是「真值探针读到 0 分，不代表模型把真相藏了起来——两种探针在优化上互补到小数点」；9/15 讲的是「分数干净，不等于证据在场——埋掉证据后掉分，是评分器在替你读答案」；9/24 讲的是「输出干净、格式合规、日志无痕，机密却从残差流溜走」；9/25 讲的是「监控所依赖的那份轨迹，正攥在被监控者自己手里」。**它们问的是同一件事——「证据的可信，必须先于证据的解读」。而今天这篇，把镜头对准了多模态里最常被当作「铁证」的那个内部信号：视觉-文本对齐分数。**

**得到的是一张「对齐幻觉」的解剖图。** 把图换成高斯噪点，**准确率在 13 个模型上齐齐掉 38–50 个百分点，可 CKA、SVCCA、MIR、主夹角余弦这四把「标准尺子」几乎读不出差别**——**甚至分数比真图时还高、在深层一起逼近 1.0**。**病根被追到了共享语言模型通道里那条各向异性的 MLP 下投影：它把两种模态一起拽向同几条主导方向，制造出一维的「权重诱导对齐」——一种不需要任何内容耦合就能出现的高相似度。** 论文换上的新尺子 **PA gap（σ₁−σ₂）**，**在渐变腐蚀下以平均 |r| 0.894 稳追准确率、在 13/13 个模型上把 Orig 排到 Noise 之上**；**而在「有结构但无关」的图上，它又把「几何排序」和「准确率排序」的分家暴露得很干净**（几何 Orig<Irr<Noise，准确率 85.4% / 36.1% / 39.0%）——**无关图甚至会掉到「纯文本基线」之下，说明它不是被忽略，而是被模型认真加工后带偏了。**

**也留下一条冷静的前提。** 论文的落点是：**内部对齐是「视觉流在语言模型里的几何诊断」，不是「任务相关跨模态交互」的直接证据**——**因为高对齐分数里，可能压根不含「模型在用图」这件事**。**当「融合得好不好」「视觉有没有被用上」越来越多地被写进模型设计、数据筛选、训练诊断里时，那把被默认为「铁证」的内部尺子，恰恰可能是最容易被架构悄悄灌水的一环。** **真正的「它看懂了图」，也许从来不在那条随深度上升的相似度曲线上，而在「当你把图换掉时，它的答案会不会跟着变」——这一层，9/13 是「读到 0 分不等于藏起来」，9/15 是「分数干净不等于证据在场」，今天则是：分数高，不等于在看图。**
