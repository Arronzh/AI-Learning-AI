# 「证据没有造假，只是过期了——照样能把对的答案改错」：同一个模型不检索时明明答对，喂进一份『当年真实、如今已失效』的旧文档后，30%（Llama）/37%（Qwen）的答案被翻成过时答案；再加一句『请遵循文档』，直接飙到 66% / 75%——而格式完全相同的『现行有效』文档，它 97%–100% 照单全收；论文把 50 组案例的证据逐字冻结、只改一个『评估日期』，证明大模型不是不会看日期，而是没人明确告诉它『这份证据什么时候作废』时，它就几乎不用

📌 **核心摘要**：检索增强生成（RAG）最常被用来对付「模型知识过期」，思路很简单——**知识可能在权重里过时了，那就去外面把最新的证据找回来**。但这篇论文（arXiv:2609.31342v1 [cs.CL]，2026-09-25 提交，作者 **Md Shamim Ahmed、Lukas Galke Poech、Richard Röttger**，University of Southern Denmark）指出了一个反直觉的失效：**检索回来的那份证据，自己可能也是过期的。** 它把这种现象命名为**「过期文档投毒（stale-document poisoning）」**——**一份文档并不需要造假、也不需要被恶意篡改；它当年说的都是真的，只是随着条件变化，如今已经不再适用**，而模型只要还继续照它答题，就会从一个「本来答对」的状态，被硬生生改成一个错的答案。**论文构建了 317 条经溯源核验的「知识反转（knowledge reversal）」基准，横跨医学（87）、法律（100）、软件 / API（60）和平台政策（70）四个领域**，覆盖 **12 个模型**。**最刺眼的数字是：在没有要求模型信任文档的「中性检索」下，一份过期文档就把 Llama 的 30%、Qwen 的 37% 答案翻了盘；一旦提示里加上一句『请遵循检索到的文档』，比例立刻升到 66% 和 75%。** 而在同一套对照里，**格式一模一样、只是「现行有效」的文档，模型 97%–100% 都乖乖照做**——**这说明问题不是「模型不会用检索」，而是它不会「选择性地信任」**。论文更进一步，**把 50 组案例的历史证据逐字冻结下来，只改一个「评估日期」**：**光靠日期，模型几乎不动（差距只有 0.04–0.12）；可一旦把「这份证据从哪一天起失效」明确说清楚，70B / 72B 的大模型立刻几乎 100% 切换到正确答案**——**它缺的不是时间信息，而是「有效性」这层信号。** 最后，**一个把「时效」与「取代关系」纳入的混合重排器，在日期可靠时能把投毒压低 4.6–10.0 个百分点**；**可一旦日期缺失，收益几乎归零，日期要是错了，甚至比不重排还糟。** 结论一句话：**可靠的 RAG 需要的不只是「找到相关证据」，而是先判断「这份证据还算不算数」。**

## 一、研究背景与动机

**先看清这件事发生在什么背景下。** 医学指南可能比模型重训得更快：**心梗后射血分数保留患者的常规 β 受体阻滞剂、维生素 D 联合钙剂预防骨折、固定疗程的抗生素方案**——**这些当年都是标准建议，后来陆续被撤回或收窄**。**法律教义也会反转**：**2024 年美国最高法院在 Loper Bright 案中推翻 Chevron 案，终结了长达四十年的「司法尊重行政机关解释」原则**。**软件知识同样在变**：**API 被弃用、被替换**。**于是，一个训练早于这些变化的模型，很可能牢牢记住了一批「曾经正确、如今不再适用」的答案。**

**RAG 是对这个问题最自然的回答**：**不再只依赖权重，而是在推理时把外部证据检索进来**。**但检索随之带来了第二重时间问题：被检索回来的证据，本身可能就已经过期了。** **既有工作早就显示，错误或反事实的上下文可以盖过本来正确的答案**；而**本文要说的是一类更隐蔽的情形——它甚至不需要有人恶意伪造**：**一份「当年有效」的文档，会在条件变化后，自然地变成一个「支持已被取代答案」的证据。** 论文把它称作**过期文档投毒**，并**特意与对抗式投毒、间接提示注入划清界限**：**这里的证据既非伪造、也非恶意构造，它「变得有害」，只因为它赖以成立的前提已经改变。**

**而真正深一层的难题，是「时间适用性（temporal applicability）」。** **知道一份文档「写于何时」，并不等于知道它「此刻还适不适用」。** **模型必须判断：这份文档所表达的推荐，在「提问的那个时刻」是否依然成立，并且让这个判断真的影响最终答案。** **同一份历史证据，可以在某个评估日期是恰当的、在另一个评估日期就变成过期的——哪怕它的文本一个字都没变。** **这一点把它和「参数知识 vs. 检索上下文的一般冲突」区分开来**：**关键问题不是「模型到底听谁」，而是「当证据越过一条经核验的有效性边界时，它的服从程度会不会随之改变」。**

**站在对齐的镜头下看，这其实是一场「选择性认知信任（selective epistemic trust）」的失灵。** **一个可靠的模型，应当在证据仍然适用时服从它，而不是「因为它出现在上下文里」、或「因为提示词叫它照做」就服从它。** **论文用一组严格配对的实验直接测这个区分**：**过期证据能翻掉本来正确的答案；显式「遵循文档」的指令会放大这个效应；而配对到位的「现行有效」证据，几乎被普遍服从。** **所以结论不是「模型不会用检索」，而是「模型无法可靠地把『是否服从』这件事，条件在『这份证据还该不该生效』上」。**

**那么这篇论文和本系列在追问的「证据是否可信」是同一条线吗？是，但今天换了一个更日常的角度。** **前几篇反复问的是「你手里的分数、探针、日志、排行榜，到底算不算数」**：**9/13「探针读到 0 分，不代表模型把真相藏了起来」，9/15「分数干净，不等于证据在场」，9/24「输出干净、格式合规，机密却从残差流溜走」，9/26「把图换成噪点，CKA / SVCCA / MIR 照样『高度对齐』」，9/27「那张排行榜，唯一站得稳的只有倒数第一」。** **今天这一篇把问题再往前推一格：就算证据真的被检索到了、真的在场、也真的没有造假——它还可能「已经不算数」了。** **换句话说，「证据在场」，并不等于「证据有效」。**

**论文把自己的贡献列得很清楚，也很有分寸。** **其一**，**一份带官方来源、带日期的 317 条知识反转基准，跨四个领域**；**其二**，**证明这是一场「选择性认知信任」的失败**——**模型乐于服从有效证据，却拦不住过期证据**；**其三**，**用 50 组「证据逐字冻结、只改评估日期」的对照，把「是否拿到时间信息」和「是否会正确使用它」分开**；**其四**，**因果实验证明「有效性信息」能直接改写答案，且这条通路借用的是一套更通用的比较机制**；**其五**，**证明检索侧的缓解措施高度依赖「时间元数据」的质量**。

## 二、核心方法

**方法本身不花哨，它的分量在于「把归因做得足够干净、足够可证伪」。**

**第一步，先把「投毒」定义得极其克制。** **对每一条基准项，模型先在不检索的情况下作答；只有当它在「无检索」时答对、却在拿到一份过期文档后答错，这一条才被计为「被投毒」。** **用论文的话说，这是「条件式」的计数**：**它专门隔离「检索引入的失败」，而不是把模型本来就答不对的题也算进来。** **于是两个核心指标就立起来了**：**P_m（投毒率）= 在「无检索答对」的条目里，喂入过期文档后答错的比例；G_m（适用性差距）= 「证据仍有效时的旧答案率」减去「证据失效后的旧答案率」**——**后者越大，说明模型越能分辨「同一份证据还该不该用」。**

**第二步，造一份「知识反转」基准。** **每条基准项都包含：一个问题、一个「在评估时点正确」的及时答案、一个「曾经正确、如今失效」的被取代答案；一份「现行有效」文档支持前者，一份「过期」文档支持后者，两份文档格式相同、只有推荐内容与是否仍然有效不同。** **全量 317 条：医学 87、法律 100、软件 / API 60、平台政策 70。** **所有实验都跑在同一份「固定、带版本号的基准快照」上**——**论文特意强调：以后再发现新的反转，只会记进「下一版语料」，而不会改动本篇所评的这一版**；**版本化快照 + 变更日志，让旧结果永远可复核。** **自动化检查核验来源出处、时间有效性、重复项与归档完整性**；**医学子集里，87 份官方来源页有 39 份被自动成功归档，其余保留来源链接与抓取状态。**

**第三步，做一套「只改日期」的时间适用性对照——这是全文最漂亮的一招。** **论文筛出 50 组「官方来源明确给出了旧建议何时停止适用」的反转项。** **对每一项，它把同一份历史证据呈现两次**：**一次在「证据仍然有效」的评估日期，一次在「证据已被取代」的评估日期**。**证据、问题、答案选项、指令全部逐字一致，唯一改变的是评估日期。** **它再把这个「只改日期」的设定，和两种「把失效时点写明白」的设定做比较**：**一种用散文写明边界，一种用一张小表格写明边界。** **Qwen2.5-7B/72B 与 Llama-3.1-8B/70B 只需要在「证据是否适用」上做判断、并在两个随机化顺序的答案选项中二选一**——**这样就能拿到一个「直接的行为测量」，而完全不需要自由文本评判。** **每个模型完成 600 个格子（两个评估日期 × 三种格式 × 中性 / 显式遵循两种指令），全实验共 2,400 个格子**；**所有答案、状态、标签字段无空缺。**

**第四步，用因果干预去问「模型内部到底有没有在用这条信息」。** **对每个大模型，论文挑最多 20 条「在答案 logit 度量下能复现出正确日期偏好」的条目**，**在评估日期那个位置上，把「有效日期」与「失效日期」两个配对提示的内部状态双向对调**。**「自我补丁」充当安慰剂对照；在「未改动的来源日期」位置做同样的补丁，则用来测这个效应是不是「专门绑定在评估日期上」**。 **之后，论文追踪这个干预从哪一层开始影响最终决策，并把注意力（attention）与 MLP 两部分的贡献分开**；**候选注意力头先用 10 条「发现集」找出来、冻结，再在另外 10 条「确认集」上检验**；**最后，它把这批头拿去测「普通日期比较」和「非时间的阈值判断」，看它们是「时间专用」，还是「支持更通用的比较」。**

**第五步，把「评判器」和「检索侧防御」都摊开、都验证。** **自动评判器用 GPT-4o，把自由文本判成「及时 / 被取代 / 不清楚」三类**；**它被独立验证了两次**：**① 换一个不同模型家族的第二个评判器，对 840 条医学回答重新判，两者近乎完全一致（Cohen's κ = 0.93）；② 再对 200 条盲标人工标签做对照**（**两名外部博士生独立标注，初始一致率 76.0、κ = 0.621，另有独立裁决者消解 48 处分歧**）——**自动评判器对最终人工标签的准确率 92.5%（95% CI 88.9–95.9%），macro-F1 = 0.894**。 **检索侧防御则是一个**固定**的混合重排器**：**每个条目配 1 份现行有效文档 + 2 份过期文档**；**打分规则是 s(d,q) = 0.5·cos(d,q) + 0.5·r(d) + 0.1·I_sup(d)**，**其中 r(d) 是文档年份在索引内做 min–max 归一化，I_sup 标记显式的「取代 / 作废」措辞**；**并对「语义近乎打平、但日期相互冲突」的匹配发出告警**。**论文在「日期正确 / 缺失 / 有噪声 / 错误」四种元数据条件下评测它**，**外加一个 GPT-5.5 的投毒压力测试**。 **按论文自己的说法：重排系数是一整张固定网格、全部公开报告，没有任何一个系数是「看到结果之后才挑出来的」**；**决定性 token 的层扫描遍历了每一层，交叉验证 AUROC 只用来挑「读出头在哪一层最好」，不用来调参。**

## 三、实验结果

**RQ1——「过期文档投毒」有多普遍？跨模型、跨领域，而且不随规模消失。** **先说「知识本身有多难」**：**12 个模型在「早已定案」的医学反转上几乎都是满分**（**Qwen-7B 0.97、Llama-8B 1.00……**），**可一旦换成「训练时点附近甚至之后才发生」的近期反转，准确率明显塌下来**：**Qwen-7B 0.61、Llama-8B 0.64、GPT-4o 0.76、Claude-Opus-4.5 0.87**——**12 个里有 10 个在 Benjamini–Hochberg 校正后依然显著**。 **再看「投毒」**：**在显式「遵循文档」条件下，医学领域最高（Llama-70B 0.91、Qwen-72B 0.85）**，**法律与政策依然可观**，**软件 / API 相对更「抗毒」（0.17–0.35）**。 **论文的关键一句是：「这个效应出现在每一个『模型 × 领域』组合里，而且不随规模消失」；全量的大小模型对比，也找不到系统性的规模效应。** **最扎心的是「高准确率也不免疫」**：**GPT-5.5 在无检索时对评测题目的正确率高达 0.92–1.00，可一份过期文档就把 74/83 条「此前答对」的医学答案翻掉了（投毒率 0.89）**。 **换句话说：这不是「弱模型」的毛病，而是「再准的模型，也可能在被喂进一份被取代的证据时，把已经答对的答案扔掉」。**

**RQ2——「过期」和「现行有效」只差一个有效性，结局却天差地别。** **论文做了一个漂亮的对照**：**把过期文档换成它「配对到位」的现行有效版，在全部 87 条医学项上，没有任何一条此前答对的答案被改错；四个模型对全部 87 条给出及时答案，Qwen-7B 与 Llama-8B 各 86/87**。 **而在「本来就答不对」的条目上，现行有效文档把错误**恢复**了 97%–100%**。 **所以投毒的根子，不是「模型不会用检索」，而是「模型对证据的信任，没有条件在『它是否仍然有效』上」。**

**RQ3——只改一个「评估日期」，大小模型几乎是两个世界。** **在 50 组「证据逐字冻结」的对照里，光靠日期，模型的适用性差距都很小**：**Qwen-7B 0.06、Llama-8B 0.04、Qwen-72B 0.12**——**也就是说，日期本身几乎不改变它们的服从。** **可一旦把「这份证据从哪一天起停止适用」明确写出来，格局立刻翻转**：**Qwen-72B 在两种显式格式下，50 组要求「从旧切到新」的转变全部完成（50/50）；Llama-70B 用散文边界做到 47/50、用表格边界做到 50/50。** **而同样两个大模型在「只改日期」设定下的对应数字，只有 6/50 和 7/50。** **小模型有进步，但幅度温和**——**这说明效应不是「换了响应格式」这么简单。** **论文的落点很克制也很关键：大模型**能**跟着一条清晰的有效性规则走；但**光有日期，几乎带不动它们**。** **「拿到时间信息」和「会用时间信息」，是两回事。**

**RQ4——因果实验：这条信息真的改写了答案，而且它走的是「通用比较」这条路。** **把「有效日期」的内部状态搬进「失效提示」里，答案偏好被大量迁移**：**Qwen-72B 迁移了 23.08 个 logit（95% CI [21.06,25.53]），Llama-70B 迁移了 7.82 个（[6.92,8.65]）；反向补丁则把答案推向相反方向。** **作为对照**：**在「未改动的来源日期」位置打补丁，答案边界只动了 0.04 和 0.03；自我补丁几乎没有任何效应。** **可见这个效应**专门**绑在「评估日期」这条信息上。** **它从哪一层开始影响决策？越靠后越明显**：**Llama-70B 在第 31 层达到 1.21 个 logit、第 39 层达到 5.86，恢复了约 75% 的迁移偏好；Qwen-72B 在第 55 层达到 3.66，到第 63 层恢复约 80%。** **而谁是早期的「主力」？是注意力，不是 MLP**：**在第一个出现清晰效应的层，Llama-70B 的注意力贡献 0.91 个 logit，MLP 只有 −0.17；Qwen-72B 对应为 2.34 与 −0.04。** **头级别的定位（发现集 + 确认集）里，Qwen 有 8/10 个头、Llama 有 7/15 个头在 Holm 校正后依然显著，而配对对照效应始终接近 0。** **最关键的一问：这些头是「时间专用」吗？论文发现，**同一批头也参与普通的日期比较、以及非时间的阈值判断**——**于是它倾向于认为：时间适用性调用的，是一套**更通用的「比较—决策」机制**，而不是一条时间专属回路。** **这带来一个乐观的推论：**能力已经在了，缺的是「把有效性信息稳定地接进信任判断」这一环。**

**RQ5——指令压力会放大投毒，而且「识别出过期」并不等于「不照做」。** **在一个 2×2 实验里，论文同时改动「文档表头」和「是否明确要求模型遵循检索证据」**：**在中性表头下，加上「请遵循」指令，就把 Qwen 的投毒率从 0.37 抬到 0.75（n = 51，OR = 4.92，95% CI [2.59,9.34]），把 Llama 从 0.30 抬到 0.66（n = 53，OR = 4.50，[2.46,8.23]）**。 **而且**「19 条项
目变错、却没有一条变对」（精确 McNemar p = 3.8×10⁻⁶）。 **一个细节特别值得记：**一旦「请遵循」指令在场，再把文档表头标成「最新」，也**加不出可检测的额外效应**——**也就是说，真正在拉高投毒的是「服从压力」，而不是「最最新」这个标签。** **跨领域看，八个「模型 × 领域」组合里，「显式遵循」的投毒全都高于「只给文档」**：**非医学领域里，Qwen-7B 出现 28 处「变错」对 12 处「变对」（p = 0.0166），Llama-8B 出现 23 对 6（p = 0.0023）。** **更微妙的一段是：模型有时会**认出**证据「已被取代或不确定」，**却依然照着它答**——**论文把这单独列出来，因为它说明「识别过期」和「不服从过期」是两步，而中间那一步经常断掉。**

**RQ6——检索侧能救吗？能救一点，但前提是时间元数据得是真的。** **在「日期准确」的条件下，这个固定的重排器把下游投毒降低了 4.6–10.0 个百分点**（**Qwen-7B 与 GPT-4o × 医学与法律四个格子，其中三个达到 p < 0.05**），**例如法律 / Qwen-7B 从 0.640 降到 0.540（p = 0.0129）、医学 / GPT-4o 从 0.621 降到 0.529（p = 0.0215）**。 **但**——**「日期缺失」时，四个格子里三个只改善了 1.0–4.0 个百分点、都不显著，还有一个反而恶化了 1.1 个百分点**；**而「日期错误」时，重排器选中「现行有效文档」的比例在每个领域都**掉到零**，甚至**低于「不做重排」的稠密检索基线**。** **论文给的结论很冷静：**时间元数据可信时，时效信息能改善检索；可「更新」本身，根本推不出「仍然适用」。** **它甚至给出一个理想化的「上界」**：**当现行有效文档带着**正确的日期**时，一条时效规则能把 GPT-4o 的投毒从 16/66 打到 0/66、把 Claude 的从 27/77 打到 0/77（精确 McNemar p ≤ 6×10⁻⁵）**——**可论文立刻提醒：那组「零投毒」**不是现实中的防御估计**，它依赖于「日期永远正确」这个理想前提。**

## 四、技术启示与发展方向

**第一，这一篇最该被记住的一层：把「发布时间」和「适用性」当成两种不同的元数据。** **论文说得非常干净：知道一份文档**写于何时**，并不能告诉系统它的推荐**从何时起不再适用**。** **所以可靠的检索系统，应当尽可能**显式地**表示时间有效性——**生效日期、取代关系、有效性区间**——**并且模型要能在「是否该让这份证据改变答案」时用上它。** **它不是要系统「偏好更新的文档」，而是要系统**知道「这份证据是否还算数」**。

**第二，把「选择性信任」写成一条可执行的判据。** **本文的每个实验都在往同一句话上收：模型应当「在证据仍然适用时服从、在证据已被取代时拒绝」**——**而现状是：它对**有效证据**服从得很到位（97%–100%），对**过期证据**却几乎不设防。** **这条不对称，是整篇论文所有数字的共同根。** **对任何一个把 RAG 接入问答、助理、合规、医疗或法务场景的系统，这句话都能直接翻译成一条护栏：**别让「检索到了」自动等于「该采纳」。

**第三，一条安静但很重的评测盲区：检索的「两个方向」都要评。** **论文明确提出：检索应当在两个方向上被评测**——**一是「有效证据能不能纠正过时的模型」，二是「被取代的证据会不会伤害一个本来正确的模型」。** **主流的 RAG 评测几乎只测前者**（**能不能把欠知的补上**），**而本文证明后者同样致命，甚至更隐蔽**：**因为被伤害的，恰恰是那些「本来答对」的答案——你甚至会以为系统「检索得很成功」。** **「信息更多不一定更好；可靠的 RAG，需要控制「哪条信息还配得上认知权威」。**

**第四，检索侧的缓解有用，但有天花板，且天花板高度取决于元数据质量。** **重排器在日期准确时能把投毒压低几个百分点，却会在日期缺失时几乎归零、在日期错误时**倒退**。** **显式的有效性边界，对有能力的模型是更强的行为信号——**可它同样依赖可信的来源与元数据。** **论文由此把更大的挑战命名为**「有效性感知的证据仲裁（validity-aware evidence arbitration）」**：**在允许一份证据去推翻一个本来正确的答案之前，先判断它「是否仍然适用」，而不只是「是否相关」。

**第五，一条带乐观色彩的内部机制结论。** **因果实验显示，大模型的内部**已经**有一条能使用「有效性信息」的通路**，**而且它借用的是一套**通用的「比较—决策」机制**（**同一批注意力头也参与普通日期比较和非时间阈值判断**）。** **这意味着：**能力不是从零搭起，缺的是「把明确的有效性信息稳定地接进信任判断」这一环。** **论文的方向也很具体：**从「发布日期」走向「有效性区间、取代关系」，并**训练模型去对这类元数据做推理**。** **它对大模型能力的判断也很克制：**70B / 72B 的强表现说明，「可靠的适用性推理」会随能力涌现，且对「时间信息怎么呈现」依然敏感。** 

**边界也要说清。** **论文明确自限**：**「定案 vs. 近期」的对比仅限医学、且用的是不同题目，所以「近期效应」无法和「题目难度」完全分开**；**因果分析每个大模型只用 20 条「行为合格」的条目、且是带显式选项的答案 logit 任务——它证明了在这套受控设定下的因果影响，但**不等于**同样的组件能支配自由生成或线上部署的 RAG**；**头级别特异性在每模型 10 条确认集上评估，应当读作「定位证据」，而非完整回路说明**。 **它也没有把投毒归因于「后训练」——**因为它在同一模型族内部变更指令强度，所以「后训练是否制造了这个脆弱性」，本文不下结论。**

## 五、总结

这一篇，把本系列一路追问的那根柱子又往下敲了一节：**你手里这条证据，到底「算不算数」？** 9/13 讲的是**「真值探针读到 0 分，不代表模型把真相藏了起来」**；9/15 讲的是**「分数干净，不等于证据在场」**；9/23 讲的是**「JSON 一个错都没有，答案却反了」**；9/24 讲的是**「输出干净、格式合规，机密却从残差流溜走」**；9/25 讲的是**「监控所依赖的轨迹，正攥在被监控者自己手里」**；9/26 讲的是**「把图换成噪点，那些『铁证』分数照样逼近 1.0」**；9/27 讲的是**「一张排行榜，唯一站得稳的只有倒数第一」**。 **它们问的始终是同一件事——证据的可信，必须先于证据的解读。而今天这篇，把镜头对准了 RAG 里最理所当然的那一环：检索回来的东西。**

**得到的是一幅「投毒」的解剖图。** **一份**不造假、不篡改**的旧文档，只因为它「过期了」，就能把一个本来答对的答案改错**：**中性检索下 30%（Llama）/37%（Qwen）被翻盘，加上一句「请遵循」升到 66% / 75%**；**格式相同的「现行有效」文档却被 97%–100% 照单全收**；**把证据逐字冻结、只改一个评估日期，大模型几乎不动（差距 0.04–0.12）**，**可把「何时失效」讲明白，72B / 70B 几乎 100% 切对**；**因果上，这条信息真能改写答案（23.08 / 7.82 个 logit），且走的是一套通用的比较机制**；**检索侧重排在日期准确时能压低 4.6–10.0 个百分点，日期一错却比不重排更糟**。 **这六组数字连起来，讲的是一个和「模型强不强」关系不大的故事——它讲的是：一个检索系统，可以在证据完全真实、没有任何人作恶的前提下，仅凭「证据已经过期」这一点，就让一个本来正确的答案，变得比不检索时更不可信。**

**也留下一条冷静的前提。** 论文的落点是**机制性的、而非谴责性的**：**它给出的不是「RAG 没用」，而是「RAG 需要判断证据还配不配拥有认知权威」**。 **当「检索到最新信息」越来越多地被写进问答、助理、合规、医疗、法务系统时，那个被默认为「更准」的动作，恰恰可能是最容易被一份**合规却失效**的旧文档悄悄带偏的一环。** **真正的「它更可靠」，也许从来不在「你检索到了什么」，而在「你还敢不敢，让这份证据推翻你已经答对的答案」——这一层，9/13 是「读到 0 分不等于藏起来」，9/15 是「分数干净不等于证据在场」，9/26 是「分数高不等于在看图」，9/27 是「名次稳不等于结论稳」，今天则是：**证据在场，不等于证据还有效。**
