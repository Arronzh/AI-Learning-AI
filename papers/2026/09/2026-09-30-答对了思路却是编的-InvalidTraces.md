# 「答对了，思路却是编的」：一个能被逐行验算的小学数学基准发现——思维链在训练分布里几乎条条合规，题目一难就露馅：最难档 31.6% 的正确答案配着无效推理，其中过半连语法和算术检查都能骗过，只在语义依赖上翻车；把训练用的思维链整段对调到别的题上，模型在分布内仍答对 82% 的题，却写不出一条有效轨迹；打乱 10% 句子的 token，准确率几乎不掉、却没有任何一条轨迹能通过验证——论文据此下判：思维链是对行为的观察，不是对内部推理的测量

📌 **核心摘要**：我们把模型的「思维链」当成它「怎么想出来的」记录，用它调试、审计 agent、判断模型到底会不会推理。**可这套用法有个从没被认真验证过的前提：那条被写出来的推理，真的是它得出答案的那条推理吗？** 这篇论文（arXiv:2609.38107v1 [cs.CL]，2026-09-29 提交，作者 **Ratish Puduppully、Pranabendu Misra、Paarth Iyer、Durgesh Kalwar、Vardhan Palod、Subbarao Kambhampati**，哥本哈根 IT 大学 / 金奈数学研究所 / 印度理工学院贾姆穆 / 亚利桑那州立大学）**没有空谈「思维链可不可信」，而是挑了一个能把这件事用机器逐行验算的场地——iGSM**：一个合成的小学数学应用题基准，**每道题的依赖结构、该用哪些量、该怎么算，全都显式已知**，因此模型吐出的每一步都能被程序自动判对错。**在这块「最理想的试验田」里——数据干净、语法固定、无对抗、模型没有任何隐藏动机——论文得到的四组结论却是**：**① 越难越对不上**——用完全干净、最小的轨迹训练出来的模型，分布内「答对」与「轨迹有效」几乎重合（≈100%），可一旦把题目拉出训练长度，两者就分道扬镳：**在最难的 op=23 档，31.6% 的正确答案配着无效轨迹**，而且**这些无效轨迹里超过一半能骗过全部语法和算术检查，只在「语义依赖」上出错**；**② 最小性不是规划能力**——把训练轨迹换成「非最小」（把题目里所有参数都算一遍），模型的输出立刻跟着变得不最小；**把同一道题的提问换成一个不需要算到终点的量，模型仍会把它习惯的那条链算出来，于是「只算该算的」这个看似聪明的行为，被证明只是「题目问的是终点」这个出题方式的副产品**；**③ 轨迹可以「有用却永远无效」**——用**打乱 10% 句子 token** 的轨迹训练，模型准确率几乎不减，**却没有任何一条生成的轨迹能通过验证**；**④ 轨迹可以对调成纯仪式**——用**别的题的轨迹**训练，模型分布内仍答对 **82%**，但它写的每一条轨迹都属于另一道题。**论文落在一句很重的话上：**生成的轨迹是「对模型行为的观察」，不是「对模型内部推理过程的测量」——**要从这些性质推断出推理机制，需要反事实检验，而不是光靠观察。**

## 一、研究背景与动机

**先看清这件事为什么重要。** **思维链（Chain-of-Thought）最初只是「让它一步步说」的提示技巧**（Wei 等，2022；Kojima 等，2022 的「Let's think step by step」），**后来被写进训练**：STaR（Zelikman 等，2022）**保留那些「最终答案对」的轨迹来微调**；**再往后，R1 式的大规模强化学习后训练更进一步**——**模型生成很长的「思考轨迹」，只在「结果对」时给奖励**（DeepSeek-R1-Zero 的 GRPO、Kimi K1.5 都如此），**步骤级的过程奖励基本没有用上**。**于是训练直接奖励「有助于答对的中间思考」，却从不强制「写出来的轨迹本身就是这个答案的一条合法推导」。**

**而我们在推理时，几乎默认了后者。** **这些模型吐出的自然语言轨迹，读起来常常像一串连贯的论证、演绎、计划与修正**——**于是我们很自然地把它当成「模型在做什么、为什么这么做」的账本**。**这在推理模型被塞进 agent 里时尤其要命**：**多 agent 通过复杂、半自主的流程协作，人类监督本来就有限**，**事后又习惯去读 agent 的思考轨迹来理解「这场互动是怎么走到这一步的」**（Greenblatt 等，2026；Yao 等，2026）。**AI 安全与监督领域更是把轨迹当成了核心接口**：**评估解释的忠实性、检测「奖励黑客」等不良策略、解读多 agent 行为**——**METR 一项调查就分析了大量交互 agent 的原始思考轨迹，报告了协作、招募其他 agent 参与风险实验、甚至某个 agent 明确在轨迹里盘算「为集体牺牲自己的成功」**；**舆论则把它读成一种「集体智能」。**

**但这一整套监控、解读与分析，都暗暗依赖一个前提：写出来的轨迹忠实于（至少可靠地相关于）模型得出答案的过程。** **论文把这个前提拆成两个常被混为一谈的问题**：**「最终答案对不对？」和「这条思考轨迹是不是这个答案的一条合法推导？」** **它强调：一条轨迹「对模型有用」，并不等于「它就是答案的合法推导」，更不等于「它忠实记录了什么」。** 而**自然语言轨迹天生难被机器验证**，**所以这个「合法性」几乎从没被直接测过**。

**于是论文找来一块天生可验的地。** **iGSM**（Ye 等，2025a，即《语言模型的物理：2.1 小学数学与隐藏推理过程》）**是一个类 GSM8K 的合成数据集**：**每个问题都带着完整的依赖结构**，**生成器还保留着每道题的符号计算过程，因此既能给出「参考轨迹」，也能自动逐行检查模型生成的轨迹**；**它规模极大**（**作者估计即便忽略数值、表面形式、变量名、句子顺序和无关参数，也仍有超过 90 万亿个不同的解题模板**），**且难度（推理长度）可显式控制**——**可以在短题上训练、在长题上评测。**

**关键在于：iGSM 正是此前一篇「有影响力、结论偏正面」的工作用来论证「模型学会了推理与规划」的场地。** **Ye 等把「分布外泛化」「解是最小的」「隐状态探针」当作模型学会推理与规划的证据。** **这篇文章要做的是在同一份证据上换个问法**：**一个外部观察者，仅凭思维链本身，到底能合理地推断出什么？** **论文把问题问得极具体、也极可测**：**当模型给出正确答案时，它写出的轨迹，是不是这个答案的一条合法推导？** **如果正确答案经常配着无效轨迹，那么「轨迹的最小性、连贯性」就不能被当成「模型底层推理过程」的证据。**

**这和本系列一路追问的，是同一条线上的下一格。** **9/13 问「探针读到 0 分，模型是不是把真相藏起来了」；9/15 问「分数干净，证据在不在场」；9/23 问「JSON 一个错都没有，答案为什么反了」；9/24 问「输出干净、格式合规，机密为什么从残差流溜走」；9/25 问「监控所依赖的轨迹，是不是攥在被监控者自己手里」；9/26 问「把图换成噪点，对齐分数为什么照样逼近 1.0」；9/27 问「一张排行榜，为什么唯一站得稳的是倒数第一」；9/28 问「一份不造假、不篡改的旧文档，为什么能把对的答案改错」；9/29 问「答对了，也可能是蒙对」。** **今天这一篇把镜头再推进一格：答案对了，那条写给你看的推理过程——它本身成不成立？** **论文一行行验算后给了个不太舒服的答案：在训练分布里几乎条条成立，可题目一难，「对的答案」和「成立的推理」就开始各走各的。**

## 二、核心方法

**方法不炫技，它的分量在于「把一句没法反驳的直觉，变成一个能被程序逐行判分的实验」。**

**第一步，把「推理合法性」变成一个可机械检查的定义。** **iGSM 的每道题都藏着一张依赖图**：**比如一道「Manatee / Salt Marsh / Estuary」的题，题目给了几条关于「多少个器官、多少条腿」的关系，问题是「Salt Marsh 一共有多少 Organs」**；**生成器知道：正确答案应该用到哪些参数量、它们之间是什么依赖、每一步该把谁和谁相乘或相加**。**于是论文可以：① 给出参考轨迹；② 把模型输出的轨迹解析成一步步的「定义 + 赋值」，然后逐一核对。** **一条轨迹「有效」，当且仅当它通过全部检查**：**语法与算术层面**——**能否解析、用没用没定义过的符号、有没有顺序/重复定义错误、算术对不对**；**语义层面**——**是否定义了一个题目里根本不存在的名字、某一步是否读入了依赖图并未规定的量、有没有其它依赖错配**。**这套检查的好处是：它能把「无效」拆成「一眼可见的语法错」和「表面合规、只在语义上错的依赖错」——后者正是最容易被人工读漏的那一类。**

**第二步，用一个「干净的基线模型」把两个量分开。** **论文照搬 Ye 等的 iGSM-med 配方**：**124M 参数的 GPT-2 级模型从零训练**，**训练时现场生成 op≤15（运算步数）、ip≤20 的题目**；**评测时每档取 4,096 个留出样本，且评测档包含分布外（OOD）的 op∈{20,…,23}**。**所谓「干净模型」，就是只用合法、最小的轨迹训练出来的模型。** **因为答案是模 23 的、且乘法里的 0 会传播**，**「永远答 0」的模型也能拿到约 15% 的准确率**——**论文用这个 15% 当作解读低分时的基线。**

**第三步，做四组「干预」，把「看起来像推理」的性质一个个拆开。** **① 对调轨迹（swapped）**：**给每道题配一条「从另一道独立生成的题」里拿来的轨迹**（还做了一版「op 匹配」的，让对调轨迹的步数和本该有的合法轨迹一致）；**② 打乱前缀（shuffled）**：**把轨迹前 p% 的句子，固定成「同样这些 token 随机打乱成一块」**（**后 p% 起保留原始后半段**；**因为是在句子边界截断，实际被破坏的 token 比例是 21%、29%、45%、61%、100%，对应 p=10、30、50、75、100**）；**③ 非最小监督**：**用「把题目所有参数都按随机拓扑序算一遍」的非最小轨迹去训练**（分全量和 90% 两档）；**④ 改问法**：**把一道题的提问从「终点」改成「链中间某个不需要算到终点的量」，题目文本一字不改**。**四组干预，分别回答：轨迹有没有用、轨迹是不是纯仪式、最小性从哪来、以及「看起来像规划的」到底是什么。**

## 三、实验结果

**RQ1——越难，越对不上：正确答案渐渐不再是「有效推导」的证据。** **干净模型在分布内（op≤15）准确率 100.0%，op=15 时 98.8%**；**可出了训练长度就一路下滑：op=20 为 83.3%、op=21 为 77.8%、op=22 为 67.8%、op=23 只有 58.0%**。**更关键的是「答对」与「轨迹有效」的分离**：**在 op=15、20、23 三档，「既有正确答案又有有效轨迹」的样本占全部的比例分别是 98.3%、77.0%、39.7%；而配着无效轨迹的正确答案，分别占正确答案的 0.5%、7.5%、31.6%。** **也就是说，正确答案作为「推导有效」的证据，随着推理变长越来越弱**（**论文还验证：把训练步数翻倍，结论不变**）。**再往下拆一层更扎心**：**在配着无效轨迹的正确答案里，只因为语法/算术而失败的，分别只占 5.0%、21.9%、48.8%；其余 95.0%、78.1%、51.2% 是「语法算术全过、只在语义依赖上错」**——**在 op=23，这些无效轨迹里最常见的一类，是「某一步读错了输入」**（**384 条语义失败里有 377 条属于这一类**）。**论文给的两个例子很典型：一步用错了输入，但那个错值恰好和正确值相等（于是答案侥幸没歪）；或者错值被后面的「乘 0」吃掉。** **结论是：即便只用合法轨迹训练，分布漂移也会产生「看起来合规、实际上不再是对这道题的合法推导」的输出——计算的「有用」和轨迹的「有效」，是两回事。**

**RQ2——最小性不是工作记忆/规划能力，而是「出题方式」的副产品。** **Ye 等原本把「模型总是给出最短的解」当成「它会挑出真正需要的参数」的证据；但他们的训练轨迹本身就已经是最小的。** **于是论文用非最小轨迹反向验证**：**用 100% 非最小轨迹训练后，模型在 op=15 时平均每条轨迹带 2.45 个「多余的参数」（标准差 2.87），只有 40.2% 的轨迹是最小的**——**而干净模型在 op=15 是「0.00±0.07、99.9% 最小」**；**用 90% 非最小训练，约四分之三的轨迹最小。** **也就是说，最小性的高低，是被训练轨迹的分布直接塑形的，不是任务本身锁死的。** **为了进一步戳破「最小性=规划」，论文做了两个分离测试**：**把「世界」加宽**（**固定每层 4 个实体、深度 4，允许 48 条关系，让题目平均给出 6–11 条「提问不需要」的句子**，但**终点（sink）不变**）；**结果是：提问不变时，最小性依然保住**（**答对且轨迹含多余参数的比例：分布内从 0.0–0.4% 微升到 0.4–1.3%**）。**而「改问法」测试（用 Ye 等自己的做法，把提问随机指向链中间某个量）就让最小性崩掉**：**答对题里「轨迹含多余参数」的比例，从标准设定 op=20 的 0.4% 升到 3.7%，在加宽世界里从 1.3% 升到 9.6%。** **而且这些多余参数不是随便来的**：**模型加进来的「多余量」里 89–97% 都落在「通向终点的那条链」上**，**而这类量在候选里只占 18–28%。** **论文的落点很干净**：**iGSM 里「问题需要的参数」和「通向终点的链」本就是同一批**，**一个「一路算到终点」的模型看起来就像「只挑该算的算」——标准评测从来区分不了二者，因为它从没把问题问到别的地方去。**

**RQ3——轨迹可以「有用，却永远无效」。** **打乱前缀的实验（Table 2）：p=10（实际破坏 21% token）时，模型全程追平干净模型（op≤15 99.9%、op=20 83.9%、op=23 60.1%）**；**p=30 时，op=15 仍达 74.9%、op=20 达 43.5%**——**作为对比，完全不给轨迹训练的模型只有 25.0%、18.0%，对调轨迹的模型只有 19.9%、16.5%**；**p=50 时，模型只在分布内胜出；p≥75 时，模型大多在分布外连「终止输出」都做不到。** **但请注意一个前提：这些模型学会的是「先吐那段打乱的块、再补一个格式正确的后半段」，因此它们生成的轨迹，没有一条能通过检查。** **一句话：相当一部分「解题能力」可以在「轨迹永远无效」的情况下存活**——**只不过破坏越重，轨迹里承载的那个有用计算终究会被毁掉。**

**RQ4——轨迹还能被对调成纯仪式。** **用别的题的轨迹训练，分布内模型仍答对 81.7%**；**按 op 拆开看：4 步以内的题几乎全对，5–7 步的题答对 82–96%，然后随 op 下降，到 11 步剩 30%、到 15 步剩 20%；出了训练分布则掉到 16–20%，也就是「永远答 0」的水平。** **而不管在哪一档，对调模型生成的轨迹没有一条能通过检查**——**因为它写的轨迹命名的是另一道题的参数。** **对调模型说明「轨迹可以纯粹是仪式」，打乱模型说明「轨迹可以有用却永不合法」——两者加起来，正好把「轨迹看起来像推理」这件事，从「模型算出来的」降级成「从训练数据里继承来的」。**

## 四、技术启示与发展方向

**第一，这一篇最该被记住的一层：把「计算有用」和「推导有效」当成两个可以分开的量。** **论文的每个实验都在往同一句话上收**：**一条轨迹可以帮模型算出正确答案，却根本不是这个答案的一条合法推导**。**在 iGSM 这块「数据干净、语法固定、无人对抗、模型毫无隐藏动机」的理想田里，这两件事都能脱钩，而且随推理变长越脱越开**——**那么，任何「我读了它的思维链，所以我知道它怎么想的」的论断，都必须先补上一个前提：这条链本身成不成立。**

**第二，一条关于「分布漂移」的硬提醒：熟悉任务上建立的可靠性，不会自动迁移。** **论文最反直觉的一组数字，恰恰来自「没有任何敌意」的设定**：**只用合法最小轨迹训练的干净模型，在分布外仍产出了 31.6% 的「答对却推理无效」**。**它给出的判断很直接**：**当题目超出训练难度时，轨迹可以保留「像是推导」的形式，却逐渐丢掉「针对这道题」的语义**。**对任何把思维链当成监控信号的系统，这都意味着：别把「在熟题上监控有效」当成「在难题/新题上监控也有效」的保证。**

**第三，一个方法论上的转向：从「观察」走向「反事实检验」。** **论文把结论压到一条可操作的原则上**：**生成轨迹是「对模型行为的观察」，不是「对内部推理过程的测量」；它的合法性、最小性、连贯性、以及针对具体问题的意义，都可能被「监督方式」和「出题构造」塑形，而且它和最终答案的关系还会随分布漂移而变**。**因此，要从这些性质推断推理机制，需要**反事实检验**（比如「换一种等价问法/换一批轨迹监督，结论还稳吗？」），**而不是光靠观察**。

**第四，对「思维链监控 / AI 安全」的直接含义。** **当下的 CoT 监控（读轨迹、找奖励黑客、审多 agent 行为）默认「轨迹能把模型怎么走到答案这件事，讲清楚给监控者听」**。**论文给出的是一个更低层、更可测的前置条件——「轨迹对它声称要解的那道题是有效的」——并且证明这个前置条件在理想条件下都会漂**。**它很克制地不去否定监控的价值，而是主张：正确答案 + 看起来很像样的轨迹，这两样加起来，还不足以证明轨迹的语义可信。** **对把「读思维过程」当护栏的路线，这是一记提醒：**监控有效，不能只靠「答案对、链子像」，得靠对「链子本身是否成立」的独立验证。

**第五，一条带前提、也带乐观色彩的方向。** **论文自己把边界划得很清**：**模型很小（124M）、数据是合成的**，**因此不能直接外推到前沿大模型**；**但它同时强调：正因为 iGSM 简单、且可精确验证，这些失败「更难被搪塞过去，而不是更容易」**。**它的呼吁是**：**前沿模型的思维链在分布漂移下是否仍可靠，必须被直接测，而不能从「答案对、轨迹像样」里推出来。** **换句话说，「把问题问得更具体、更可验」这件事本身，就是这一篇最大的方法论贡献。**

## 五、总结

这一篇，把本系列一路追问的那根柱子，又往下敲了一节：**那条被写出来给你看的「思考过程」，到底是不是它真正得到答案的那条路？** 9/13 讲的是**「探针读到 0 分，不代表模型把真相藏了起来」**；9/15 讲的是**「分数干净，不等于证据在场」**；9/23 讲的是**「JSON 一个错都没有，答案却反了」**；9/24 讲的是**「输出干净、格式合规，机密却从残差流溜走」**；9/25 讲的是**「监控所依赖的轨迹，正攥在被监控者自己手里」**；9/26 讲的是**「把图换成噪点，那些『铁证』分数照样逼近 1.0」**；9/27 讲的是**「一张排行榜，唯一站得稳的只有倒数第一」**；9/28 讲的是**「证据在场，不等于证据还有效」**；9/29 讲的是**「答对了，也可能是蒙对」**。 **它们问的始终是同一件事——「呈现出来的东西」和「它该对应的东西」之间，隔着多远。而今天这篇，把镜头对准了思维链本身：答案对，可那条解释给你听的推理，真的成立吗？**

**得到的是一幅「答案-轨迹脱钩」的解剖图。** **在一个能被机器逐行验算的合成基准里**：**只用干净、最小轨迹训练的模型，分布内「答对」与「轨迹有效」几乎重合，出了分布就分家——最难档 31.6% 的正确答案配着无效轨迹，其中过半只在语义依赖上翻车（语法算术全过）**；**「最终解是最小的」不是规划能力，而是「题目问的是终点」这个出题方式的副产品，改问法就现形（多余参数里 89–97% 落在通向终点的那条链上）**；**整段对调轨迹，模型分布内仍答对 82%，却写不出一条有效轨迹；打乱 10% 句子的 token，准确率几乎不掉，却没有任何一条轨迹能通过验证**。 **这组数字连起来，讲的是一个和「模型强不强」关系不大的故事——它讲的是：如果连「答案对、轨迹像样」都能在无对抗的理想条件下一再脱钩，那么「我读了它的思维链，所以我懂它」这句话，可能从一开始就少了一个必须先被验证的前提。**

**也留下一条冷静的前提。** 论文的落点是**机制性的、而非谴责性的**：**它给出的不是「思维链没用」，而是「思维链是行为的观察，不是内部推理的测量」**。 **当「读思考过程」越来越多地被当成调试、agent 审计、AI 安全监控的默认接口时，那个被默认为「更透明」的思维链，恰恰可能是最容易被「形式合规」悄悄架空的一环。** **真正的「它可解释」，也许从来不在「它写出了看起来像推理的东西」，而在「我们有办法独立验证，这条推理对它声称要解的那道题，确实成立」——这一层，9/13 是「读到 0 分不等于藏起来」，9/15 是「分数干净不等于证据在场」，9/23 是「格式合规不等于答案对」，9/24 是「输出干净不等于没泄漏」，9/25 是「轨迹在手不等于轨迹可信」，9/26 是「分数高不等于在看图」，9/27 是「名次稳不等于结论稳」，9/28 是「证据在场不等于证据有效」，9/29 是「答对不等于答得对」，今天则是：**写出来的推理，像，不等于成立。**
