3️⃣ ReliableTableQA：GRPO 仅在 SFT 欠训练时提供可测量收益——一旦 SFT 达到 200 样本以上，RL 微调不再带来提升。

一、研究背景与动机

MKB：为什么需要统一科学多模态模型

科学研究正从单一学科走向跨域推理。理解基因组变异如何导致疾病，需要整合遗传学、转录组学、蛋白质生物学和分子药理学等多维度证据。然而现有 AI 系统要么是特化专家模型（如 ESM、GNN），要么主要通过文本序列化统一科学数据（如 Intern-S1-Pro）。前者无法跨域组合，后者受限于文本中心机制——对于稠密大气场、高分辨率医学图像这类"模态原生"输出，文本序列化本身就是有损的。

Muon Grokking：一个"顿悟"优化器的黑盒之谜

Muon 优化器因在模运算任务上比 AdamW 更快达到"顿悟"而备受关注。但先前工作将其加速归因于"谱范数约束 + 正交化动量"两个成分的组合，并未分离各自的贡献。更关键的是，"更快"本身可能是个误导——如果只用首次达到精度阈值的时间来衡量，会忽略优化器在阈值附近的震荡行为。

ReliableTableQA：到底需要多少监督？

企业数据分析中，一条语法正确的 SQL 可能返回基于 3 行样本算出的平均值、经多重比较后不再显著的排序、或因空值静默排除 15% 行的聚合结果。现有系统对所有这些情况自信作答。ReliableTableQA 提出了一个正交问题：如何让 LLM 标注统计可靠性，以及——做这件事到底需要多少标注？

二、核心方法

MKB：共享骨干 + 模态适配的三段式架构

MKB 基于 Qwen3-VL-8B 共享 Transformer 骨干，通过模态定制编码器 + 适配器 + 解码器覆盖六大领域：

  • 生物序列（DNA/RNA/蛋白质）：Perceiver-style 重采样器 + 模态投影器，将变长序列压缩为固定长度潜在 token
  • 小分子：分子图编码 + 图神经网络处理几何结构
  • 地球系统数据：保留密集经纬度 token 网格，直接处理物理场的空间结构
  • 医学图像：视觉编码器适配 + 分割解码器

训练采用 二阶段"模态优先-语言微调"课程：Stage 1 冻结骨干冻结，对齐各模态组件；Stage 2 联合巩固模态组件与语言骨干，同时限制通用能力退化。

Muon Grokking 消融：锁定"有效成分"

研究团队设计了 2×2 消融实验：

变体正交化谱缩放vs AdamW
M0（完整 Muon）✅✅显著更快
M1（仅正交化）✅❌匹配 M0
M2（仅谱缩放）❌✅不显著
M3（AdamW）❌❌基线

关键结论：正交化是唯一有效成分，谱缩放可安全移除。机制分析还发现，正交化优化器在顿悟时达到的谱范数约为 AdamW 的 1/3，控制嵌入更新量后仍成立——说明 Muon 找到了真正不同的低范数解。

ReliableTableQA：一个数据效率问题的严谨解剖

框架贡献三大组件：

  1. R1-R10 可靠性分类体系：涵盖小样本聚合、置信区间过宽、多重比较膨胀、缺失数据偏倚、Simpson 悖论等十大统计陷阱
  2. 程序优先数据管道：用上下文无关文法生成 SQL → 确定性标注 → 3B LLM 生成自然语言问题
  3. 系统控制实验：在 5 个数据集上变化 SFT 样本量（50~1000），每级比较 SFT 与 SFT+GRPO

值得注意的是，MKB 的 11B 参数与 Intern-S1-Pro 的约 1T 参数之间相差 两个数量级。

Muon Grokking：速度-稳定性前沿

  • 单次 Newton-Schulz 迭代（ns=1）最快但 6/8 种子瞬态坍缩（精度降至 0.23-0.38）
  • 五次迭代（ns=5）在所有学习率下鲁棒
  • Lean-Muon：移除谱缩放 + 5 次迭代 = 计算量减少且无性能损失
  • 关键方法论贡献：首次区分"首次达到"和"稳定保持"，发现两者可反转优化器排名

四、技术启示与发展方向

科学 AI 的范式转换

MKB 的成功验证了"共享骨干 + 模态适配组件"足以覆盖异质科学领域。未来科学 AI 可能不再需要"为每个领域造一个专用大模型"，而是在通用骨干上挂载新模态适配器。MKB 在中期气象预报上超越 HRES——一个自 2016 年运行的黄金标准系统——是特别引人注目的信号。

优化器研究的正确评估方式

Muon 消融研究的方法学贡献可能比直接优化加速更有价值：首次达到阈值与稳定保持的排名可能反转。这一洞见适用于其它优化器、学习率调度、正则化方法的比较——如果你的"更快"只是"碰巧更快但旋即崩溃"，那它就是测量伪影。

GRPO 什么时候值得用？

ReliableTableQA 给出一个被干净验证的零结果：当 SFT 数据充足时，GRPO 不带来额外收益。结合此前 Anthropic（预训练质量 > RLHF 量）、Google（SFT+推理计算 > RL 微调）等发现，RL 在 LLM 训练管线中的 真实贡献正在被更精确地界定。
